# 这次怎么逃

随机技能 + 独立伙伴操作 + 有限背包的二维房间越狱原型。R01/R02使用「会聊天」「会撬锁」「大力气」，R03/R04加入被动「会收纳」。搬货、交易、技能与道具组合开路，在默认三整天期限内争取三人全部逃脱。技能允许重复，不作任意随机配置的通关保证。

## 运行

使用 **Godot 4.7.2** 打开根目录 `project.godot`，等待素材导入后按 **F5**。主场景为 `scenes/main.tscn`，默认R04「监区生活层」，在右上暂停菜单可切换R01「双通路」、R02「门边掩护」、R03「仓库交易所」。工程包含完整运行素材，无需 GameCreator 或协作凭证即可试玩。

## 操作

- 轻点伙伴或左下卡片选人，轻点空地下达移动命令；伙伴各自行动。主地图单指拖动只移动视野，超过12单位视为拖动，松手不会误下令。电脑左键可预览同样操作，右键移动继续支持。
- `1 / 2 / 3` 切换伙伴，`E` 执行鼠标所在或最近可见互动（持续操作优先停止），`S` 停止当前伙伴。
- 靠近可用目标时出现互动图标，点击或按 `E` 聊天、撬锁、推箱。进行中的图标可再次点击停止聊天/撬锁。
- 大力气伙伴也可右键移动接触重箱自动推箱；切换伙伴不会停止别人正在进行的操作。
- `R` 重抽技能并重开。三人均到出口后结算，被抓只返回该伙伴。
- 左下三伙伴卡收缩为124×84，提示位于屏幕底部中央；右下背包展开时仍避开提示。
- 左上「日常表」按08–12、12–14、14–18、18–20、20–24给三位伙伴分别安排待命、工作、休息、自由活动，点击「应用今日安排」执行。每个新白天08点清空昨天的表并提示重新安排；休息回本人home，白天自由活动去大厅、20点后留寝区。R04有三个车间岗位，旧图未配置工作岗位会禁用工作选项。
- 正常按表赴岗/活动和到岗时，狱警、警犬不会把人当逃跑；有效手动移动、停止、技能、拾取/背包操作及交易接管当前时段，恢复原警戒判断。日常表「恢复选中伙伴」可恢复当前安排，下一时段按表继续。待命不授予日常活动许可；路线受阻不穿墙、不传送，不推箱，需开路或改安排。本轮没有劳动收益、生产物品或新的工作动画。
- 点左上时钟或`N`查看每日作息：08–12劳动、12–14吃饭休息、14–18劳动、18–20自由活动、20–24寝室区自由活动、00–08锁寝睡觉与警卫查房。默认从第1天08:00到第4天08:00共72虚拟小时；午夜不结算失败。每24小时在1×时压缩为180/180/240/300现实秒（R01–R04），三天总540/540/720/900秒。
- 右上暂停菜单收纳关卡切换、声音、日程、重开、开发设置；菜单冻结时钟和AI，继续无时间跃迁。日程、交易和开发面板保持时间流逝。地图占满整个游戏视口，HUD为浮动纸卡，适配横屏16:9/20:9。
- 开发者设置可调流速0–16×及逃脱期限1–10天；0×只暂停时钟。人物、技能和警卫保持原速，改流速不会跳时间，偏好在重开/换图/下次启动保留。改期限不改变当前时间，缩短到已经用完则在下一行动帧超时。
- 20:00室外伙伴沿正常寻路归寝，受阻不传送，玩家可覆盖指令；寝室公共区内可自由活动，室外进入155距离360度夜间警戒，商人收摊。午夜R04三个寝室铁门上锁，玩家仍可控制人物。警卫靠近门持钥匙开门、进入房间巡视、离开后关门；睡觉者不被抓，醒着活动会被发现。
- 伙伴在本人寝室初始休息位28单位内、无移动指令且停止技能时自动休息（Zz/卡片显示）。全部未逃出的伙伴休息后，可点左上「跳过夜晚」到08:00；不跳过仍能行动。跳夜只推进日程，库存、钱包、箱子和开锁进度跨天保留，人物不传送；早晨寝室门打开，警卫沿通路返回正常巡视。
- 警犬在18:00自由活动开始后出动，追踪附近10秒内留下的移动气味；近距离无遮挡确认伙伴后犬吠，狱警前往示警位置调查，再按自己的真实视野追击。警犬不直接抓回，不能进入安全区；小地图橙色方块为活动警犬。
- 左侧寝室区在08–24为安全区，虚线标出监管边界；午夜查房阶段警卫才可以进房。R01–R03沿用共享起始房间，没有新增独立寝室门，警卫仍需实际通路，主出口锁不自动开启。
- 大地图右上有小地图：点击或拖动查看远处，白框表示当前视野，青点为伙伴、红点为狱警、绿色区域为出口、黄点为商人/物品。小地图下方有「定位」「收起」按钮，停止行动在右下背包旁。没有鼠标边缘自动滚屏；视野不能超出地图。商店打开时暂时隐藏小地图，关闭后恢复。电脑也可中键或空格+左键拖动、方向键平移、F定位。
- 选中伙伴后镜头平滑跟随该人移动；切换伙伴会切换跟随目标。拖动主图、操作小地图或方向键平移会暂停跟随，重新选择伙伴或点击「定位伙伴」/按F恢复；小房间仍固定全图。连点移动即时更新目标，固定寻路网格与局部动态障碍复用。
- 普通伙伴1格物品栏，「会收纳」3格，每格1件实物。靠近物品点击拾取；右下点击物品，再使用、放下或交接（两伙伴40单位内且无遮挡）。满包不会自动覆盖。
- R03/R04安全区有商人：靠近100单位点击交易，出售右侧背包所选物品或购买店内所选。旧零件卖3元，钥匙买9元、门边即时开门；工具买6元、门边启动6秒撬锁，启动即消耗，中断保留门进度。钱包共享、只在本局使用，交易和查看日程时计时与巡逻继续。弹窗遮挡地图输入，商店保留右侧背包选择，ESC关闭普通弹窗。
- 被抓保留物品与钱；逃脱后该人的物品锁定为带出，三人全员逃脱显示带出数量和余额，重开/换关清空。

## 工程结构

全屏UI及原生触摸验证见 `docs/dev/p33-fullscreen-ui.md`；三天作息/锁寝/跳夜见 `docs/dev/p35-multiday.md`；紧凑HUD/每日活动安排见 `docs/dev/p36-daily-routine.md`。

细竖墙移动闪烁修复、GPU对照与缓存成本见 `docs/dev/p32-wall-stability.md`（v0.9.2）。

- `scripts/`：核心流程、移动、技能、狱警与表现。
- `data/rooms/`、`data/skills/`、`data/items/`：房间、技能、物品价格与作用配置。
- `art/`、`audio/`：运行素材与来源说明；`data/presentation/active.json` 控制美术版本。
- `tests/`、`docs/tests/`：自动验证脚本、报告及实际 Godot 截图。
- `docs/gamecreator/`、`gamecreator/`：正式设计与任务的生成上下文。部分历史证据使用开发机器绝对路径，运行资源均使用 `res://`。

内附 Godot AI 开发插件及其许可证，普通运行不依赖 MCP 连接。`.godot`、本机同步备份与个人凭证不会提交。既有素材版本保留用于回退；素材来源与字体许可见 `docs/art/`、`art/fonts/`。
