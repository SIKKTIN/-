# 这次怎么逃

随机技能 + 独立伙伴操作 + 有限背包的二维房间越狱原型。R01/R02使用「会聊天」「会撬锁」「大力气」，R03/R04加入被动「会收纳」。搬货、交易、技能与道具组合开路，在封监前争取三人全部逃脱。技能允许重复，不作任意随机配置的通关保证。

## 运行

使用 **Godot 4.7.2** 打开根目录 `project.godot`，等待素材导入后按 **F5**。主场景为 `scenes/main.tscn`，默认R04「监区生活层」，右上可切换R01「双通路」、R02「门边掩护」、R03「仓库交易所」。工程包含完整运行素材，无需 GameCreator 或协作凭证即可试玩。

## 操作

- 轻点伙伴或右侧卡片选人，轻点空地下达移动命令；伙伴各自行动。主地图单指拖动只移动视野，超过12单位视为拖动，松手不会误下令。电脑左键可预览同样操作，右键移动继续支持。
- `1 / 2 / 3` 切换伙伴，`E` 执行鼠标所在或最近可见互动（持续操作优先停止），`S` 停止当前伙伴。
- 靠近可用目标时出现互动图标，点击或按 `E` 聊天、撬锁、推箱。进行中的图标可再次点击停止聊天/撬锁。
- 大力气伙伴也可右键移动接触重箱自动推箱；切换伙伴不会停止别人正在进行的操作。
- `R` 重抽技能并重开。三人均到出口后结算，被抓只返回该伙伴。
- `N` 或右上「日程」查看安排：16:00劳动、18:00放风、20:00熄灯巡查、22:00封监。R01/R02限时3分钟、R03限时4分钟、R04限时5分钟；时钟与剩余时间显示在顶部，超时未全部逃出则失败。昼夜自动随日程变化，狱警白天发现距离210、夜晚155，真实手电光束受墙/门/箱遮挡。
- 警犬在放风后出动，追踪附近10秒内留下的移动气味；近距离无遮挡确认伙伴后犬吠，狱警前往示警位置调查，再按自己的真实视野追击。警犬不直接抓回，不能进入安全区；小地图橙色方块为活动警犬。
- 左侧起始区域为安全房间，虚线标出监管边界；狱警不能进入，不会发现或抓回其中的伙伴，回房立即解除针对该伙伴的追击。
- 大地图右上有小地图：点击或拖动查看远处，白框表示当前视野，青点为伙伴、红点为狱警、绿色区域为出口、黄点为商人/物品。小地图下方有「定位伙伴」「停止行动」触屏按钮。没有鼠标边缘自动滚屏；视野不能超出地图。商店打开时暂时隐藏小地图，关闭后恢复。电脑也可中键或空格+左键拖动、方向键平移、F定位。
- 选中伙伴后镜头平滑跟随该人移动；切换伙伴会切换跟随目标。拖动主图、操作小地图或方向键平移会暂停跟随，重新选择伙伴或点击「定位伙伴」/按F恢复；小房间仍固定全图。连点移动即时更新目标，固定寻路网格与局部动态障碍复用。
- 普通伙伴1格物品栏，「会收纳」3格，每格1件实物。靠近物品点击拾取；右侧点击物品，再使用、放下或交接（两伙伴40单位内且无遮挡）。满包不会自动覆盖。
- R03/R04安全区有商人：靠近100单位点击交易，出售右侧背包所选物品或购买店内所选。旧零件卖3元，钥匙买9元、门边即时开门；工具买6元、门边启动6秒撬锁，启动即消耗，中断保留门进度。钱包共享、只在本局使用，交易和查看日程时计时与巡逻继续。弹窗遮挡地图输入，商店保留右侧背包选择，ESC关闭普通弹窗。
- 被抓保留物品与钱；逃脱后该人的物品锁定为带出，三人全员逃脱显示带出数量和余额，重开/换关清空。

## 工程结构

- `scripts/`：核心流程、移动、技能、狱警与表现。
- `data/rooms/`、`data/skills/`、`data/items/`：房间、技能、物品价格与作用配置。
- `art/`、`audio/`：运行素材与来源说明；`data/presentation/active.json` 控制美术版本。
- `tests/`、`docs/tests/`：自动验证脚本、报告及实际 Godot 截图。
- `docs/gamecreator/`、`gamecreator/`：正式设计与任务的生成上下文。部分历史证据使用开发机器绝对路径，运行资源均使用 `res://`。

内附 Godot AI 开发插件及其许可证，普通运行不依赖 MCP 连接。`.godot`、本机同步备份与个人凭证不会提交。既有素材版本保留用于回退；素材来源与字体许可见 `docs/art/`、`art/fonts/`。
