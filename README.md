# 这次怎么逃

随机技能 + 独立伙伴操作的二维房间越狱原型。三个伙伴分别随机获得「会聊天」「会撬锁」「大力气」，利用通用规则协作逃出房间。技能允许重复，暂不保证每局一定有解。

## 运行

使用 **Godot 4.7.2** 打开根目录 `project.godot`，等待素材导入后按 **F5**。主场景为 `scenes/main.tscn`，右上可选择 R01「双通路」与 R02「门边掩护」。工程包含完整运行素材，无需 GameCreator 或协作凭证即可试玩。

## 操作

- 左键选中伙伴，右键地面下达移动命令；伙伴各自行动。
- `1 / 2 / 3` 切换伙伴，`E` 使用或停止技能，`S` 停止当前伙伴。
- 大力气伙伴接触重箱时自动推箱；切换伙伴不会停止别人正在进行的操作。
- `R` 重抽技能并重开。三人均到出口后结算，被抓只返回该伙伴。
- `N` 或右上「白天 / 夜晚」按钮切换昼夜；灯光受到墙、锁门与重箱遮挡。本版昼夜影响画面，狱警仍按固定警戒范围检测。

## 工程结构

- `scripts/`：核心流程、移动、技能、狱警与表现。
- `data/rooms/`、`data/skills/`：房间与技能配置。
- `art/`、`audio/`：运行素材与来源说明；`data/presentation/active.json` 控制美术版本。
- `tests/`、`docs/tests/`：自动验证脚本、报告及实际 Godot 截图。
- `docs/gamecreator/`、`gamecreator/`：正式设计与任务的生成上下文。部分历史证据使用开发机器绝对路径，运行资源均使用 `res://`。

内附 Godot AI 开发插件及其许可证，普通运行不依赖 MCP 连接。`.godot`、本机同步备份与个人凭证不会提交。既有素材版本保留用于回退；素材来源与字体许可见 `docs/art/`、`art/fonts/`。
