资产：art-v01-20261004-a8676014f0d4。

## 试玩顺序

1. R01观察人物卡和狱警巡逻，自行选择开门或推箱通路。当前运行界面预置聊天/撬锁/力量；F5重新启动则正常随机。
2. R02观察门边操作点与狱警的位置，自行安排三人。可比较与R01的区别。
3. R重抽一个随机配置，记录遇到重复技能时是否调整路线/行动顺序，以及何时选择重开。

三次可以由同一人完成，记录是否参与设计，尽量追加一位未参与设计者。每次尝试失败也有效；不要求强制通关。先记录实际行为和原话，再作保留/修改/放弃判断。

## 每次记录

- 参与者代称、是否参与设计、时间、构建、房间、三个技能或种子。
- 是否先看卡片；第一个操作是谁、要做什么；随后改变了什么。
- 技能切换、移动中断、聊天朝向、即时追击和抓回保留是否被读懂。
- 卡住的位置、实际动作、玩家原话；是否重抽，以及理由。
- 结果与用时可选，声音/字号/拖动的感受可单独记录。

不得把预设路线替玩家执行，也不把未验证配置当作玩家失误。P10只有在P09获得真实观察之后开始，修正项需关联具体记录。
