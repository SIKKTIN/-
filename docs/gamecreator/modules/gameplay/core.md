## 玩法核心

> 从游戏入口逐层展开玩法循环。流程允许回环与持续经营，不要求每个循环有结束节点。

### 房间逃脱核心循环

- 循环图 ID：root
- 说明：观察随机技能与固定房间，独立操作伙伴，安排分工与掩护，根据结果调整，全员逃脱后重新开始。

  - 说明：重置环境，每位伙伴随机装备一项技能。
  - 关联玩法：随机技能房间逃脱 [玩法 ID：a4539d92-4c10-4137-8796-ce73a71e21e5]
- 观察与规划 [活动；节点 ID：5b3a40cd-177e-4644-9ac5-42b8ccc4744b]
  - 说明：查看技能、门、箱子、巡逻路线和视野，决定行动顺序。
  - 关联玩法：随机技能房间逃脱 [玩法 ID：a4539d92-4c10-4137-8796-ce73a71e21e5]
- 独立行动与分工 [活动；节点 ID：f01af56b-7d95-46f2-8a9f-3d09666dedd6]
  - 说明：移动一人或启动技能，留下伙伴操作，再切换其他人。

  - 说明：局部被抓、操作中断或通路改变时继续调整；全员逃脱才完成。
