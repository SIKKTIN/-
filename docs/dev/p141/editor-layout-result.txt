P141 地图编辑器布局、建筑框选与旋转
完成日期：2026-10-12

界面
- 顶部压缩为文件栏和工具栏；重读、另存为放入“文件”，角色/物品预览放入“预览”。
- 左侧素材改三列，可通过“素材 ◀”收起。分类、搜索、对象列表和随机墙体款式保留。
- 右侧“属性 / 图层”分成标签页。建筑属性使用成对坐标和尺寸显示。
- 选区显示青绿色虚线、四角标记和中心轴；底部提供旋转、复制、删除、取消选择。
- 支持 960×640、1200×760、1600×960；原始概念稿：docs/concepts/map-editor-building-selection-v01.png。

使用
1. 点击“框选建筑”（快捷键 M），左键拖出矩形，完整包住墙、门和家具。
2. 默认框选墙、门、家具以及房间范围；人物、可拾取物品、日常活动点可自行勾选。
3. 在选区内按住左键整体移动。空白处拖出新选区；Esc 取消拖动或清空选择。
4. R 右转 90°，Shift+R 左转 90°；右侧也提供左转/右转按钮。
5. Ctrl+Z / Ctrl+Y 撤销与重做。每次整体拖动、旋转、复制、删除是一笔事务。

接入
- editor_theme.gd：编辑器专用浅色主题。
- map_canvas.gd：框选手势、选区覆盖层、整体拖动预览、旋转入口。
- map_transform.gd：对象快照、关联地面/房间/门禁坐标、局部墙碰撞区域的统一变换。
- spatial_transform.gd：运行时与编辑器共用的四分之一圈几何运算。
- architecture_preview.gd：拖动时只偏移选中的保留绘制节点，松手后更新地图一次。
- world_volume.gd：墙与摆设保留相同旋转；支持普通贴图及 assembly_patches。
- doorway_geometry.gd / doorway_view.gd：门框投影与自定义门贴图随旋转更新。
- map_document.gd：移动已经旋转的物体时保留尺寸和投影锚点；墙体换款式保留旋转碰撞。
- 未旋转的旧地图继续使用原有绘制分支。地图不自动写入；仍通过保存和原有磁盘冲突检查落盘。

保护
- 锁定图层受保护；隐藏的可见场景层不参与框选。
- 房间范围是建筑依赖数据，默认随建筑变换，即使它的辅助线没有显示；锁定后受保护。
- 坐标越界会阻止旋转/移动。
- 出生归属、禁闭归属、唯一生产/作息配置受复制或删除保护。
- 整体删除普通建筑时，同时删除其完全包含的地面和辅助空间数据。
- 框选是当前临时选区，不新增持久建筑分组格式。旋转按90度执行。
