## 门禁

食堂每天12:00准时开，14:00关闭。关闭时真实导航/移动受阻；门图从A17关闭/打开配对切换，小地图与门口文字同步。时间门不能被撬锁或钥匙绕过。

14:00先疏散室内伙伴和NPC，再关闭门碰撞；伙伴取消用餐、技能和移动，放在门外可站立处，互不重叠。食堂不再兼作全天自由活动区，中间独立活动走廊承接自由活动。商人继续遵循已有12–14/18–20营业日程，办公室、车间、休息点同步新的通路。

## 被捕

R04被捕后取消当前动作，送到该伙伴的禁闭室；关闭实心门，保留技能、物品、钱及已开主门等局内成果。以日程绝对分钟计时，默认120游戏分钟，跨午夜有效，跟随开发者时间流速、暂停和晨间安排。角色可切换、可在禁闭室内走动，不能越过所属范围，也不能从内侧撬门。

到期自动打开对应门并送至门外；另一个会撬锁的伙伴靠近门外操作点，可按原技能按钮操作，保留分门进度、可切换其他角色，撬开后立即救出。钥匙和撬锁工具也复用当前门目标。救援不改变主出口门进度。再次被捕重锁并重新计时。被关押的人不被重复捕获，也不会作为查寝缺员触发警报；此前已触发的全厂警报持续。禁闭期间不能安排工作，也不能跳过需要全员归床的夜晚。

无`confinement`/`access_doors`的R01–R03保持原捕获回出生点行为。技能控制器分开累计主门/各禁闭门，不另建重复的撬锁系统。

## 数据、资源和编辑器

新增`access_doors`数组：`id/name/kind/rect`；timed含`hours`、`room_rect`、`evacuation`；confinement由捕获和释放驱动。运行时`closed/progress`不写地图文件。`confinement`对象含`duration_minutes`和按伙伴顺序排列的三个`cells`，各有`rect/spawn/release/door_id`。

动态门摆设用`access_id/closed_asset/open_asset`绑定规则，不再用静态摆设自带阻挡重复关闭已开的门。门图注册与碰撞门槛对应；A17布告板加载为`prison_notice_board`，旧`notice_board`保留。新增统一`prop_catalog.gd`读取旧三清单及A17/A19，编辑器和运行时共用；v01/v02编辑器图标增量合并。墙挂道具不绘地面接触影、不阻挡地面。

编辑器可从“对象”页选择管制门/禁闭范围，分别属于墙门机关层/区域寝室层。可调整门几何和开关分钟、禁闭范围/关押点/释放点；门几何同步配对视觉与食堂入口。禁闭范围和墙是分别配置，移动范围后仍需手工核对围墙与出生/释放位置。校验包括分钟顺序、三间归属、有效门引用、关押点和释放点可站立。新增素材全有独立图标，门的“外观”卡片仅是摆设，不会自动生成管制规则。
