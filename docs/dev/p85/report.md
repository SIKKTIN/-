# P85 平齐门框资源与自由通行入口

用户批准“侧门不内凹、墙线对齐”的概念图，要求制作自由通行门和铁门两套美术素材，并将截图寝室入口接入自由通行款。

内置imagegen分别生成 `art/architecture/doorways_v49/free.png` 和 `grille.png`，均保留原始RGBA透明PNG。manifest只选取有效图案区域；完整生成提示、源图和参考路径保存在generation.json。自由通行资源包含磨损灰钢门槛与深灰端框/铜铆钉，铁门资源使用同族端框、栅栏和小锁扣。采用端部/中段切片，避免横门、侧门整张拉伸后铆钉变形。已在真实原生画面检查进入前后和铁门开关。

寝室1 `dorm-0` 配置 `kind: open`，门框和门槛始终显示，无门扇、无开关或锁扣，夜间关闭寝室的更新也不会堵住这个入口。世界保留寝室门的配置字段，渲染器读取该类型。只改变这个寝室的通行种类；其他寝室、车间、食堂、禁闭和上锁门保留原有管制状态。现有独立上锁钢门继续使用v48。自由通行及铁门端部均限制在门洞内部，不向室内凹进、不压住下一间寝室墙线；20×40侧门和原有碰撞投影不变。

90项不同检查通过：原生门/边界61项（最终无头复核61项）、原生编辑器预览16项、两日默认NPC日程13项。覆盖实际NPC六个侧门往返、自由寝室夜间通行、其他铁门关闭阻挡、开关状态、脚底半径8、钥匙和撬锁、禁闭落点、墙体碰撞、原有地图兼容；三人用餐各20分钟，NPC13:30返工。日程测试使用免疫捕获的测试对象，实际游戏的抓捕规则未改。

纹理经现有TextureLoader预载并缓存，门开关局部重绘。房间遮挡切换不重绘自由门、不重建墙体和寻路。未进行新的FPS基准，不据此声称帧率保证。

当前工作区含其他地图/美术/玩法WIP。本任务对地图的语义变更仅为寝室1的kind字段，已与开工地图对比；提交对地图仅添加这一行，对prison_world仅提交寝室元数据及开放门两处增量，其他WIP保留未暂存。
