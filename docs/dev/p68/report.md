# P68 默认日程与单角色操控

用户明确确认“主角一人逃出即可获胜”。固定囚徒1为玩家角色；囚徒2、3是自动NPC，不可切换控制。新局和每个新一天，为三人生成互相独立的默认日程：08–12工作、12–14取餐用餐与休息、14–18工作、18–20自由活动、20–24寝区自由活动；午夜按原系统锁寝睡觉。没有工作岗位/食堂的旧地图分别回寝室休息、在寝室进食。

主角可以用摇杆或键盘接管，也可编辑自己的日常表、恢复日程。NPC的卡片标记自动日程，日常表只读；人物点击、数字键、摇杆非法选择、手动寻路、技能、背包购买等入口拒绝接管NPC。系统日程/归寝/禁闭调度仍可驱动NPC；禁闭暂停自动安排，到期放出后恢复。三人仍计算体力、饱腹和工作工资，NPC工资继续按原共有钱包规则发放。

逃脱计数及结算为0/1→1/1，主角出出口即可胜利，不再切换到NPC，也不要求三人离场。保留原夜间铁门规则：主角避开白天双守卫，可在夜间独自开门逃走；移除已经不适用的换伙伴操作提示。
