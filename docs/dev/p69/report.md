# P69 封闭生产车间与混混监工

R04补齐车间左墙与南面围墙，只保留180宽铁门。08–12 / 14–18为强制劳动；入场宽限60游戏分钟，全员进场可提前锁门。12点、18点立即开门。关闭门不会被囚徒靠近自动打开；工作人员接近使用钥匙通行，监工追查缺岗时也会开门。

监工使用已存在的混混动画，巡查工位，330范围及真实墙体遮挡。正常上班、正在工作和禁闭中不会查岗；连续被看到偷懒累计8实际秒，或入场宽限结束后点名缺岗，会追捕。实际接触并有视线才抓捕，沿用关押120游戏分钟的禁闭室。释放提供返岗宽限。右侧“工作”互动可回自己工位，重新工作清除警告/追捕。日常表说明强制劳动规则。

仅囚徒1可手动操作，2/3默认自动工作/午餐/归寝，其他地区白天普通巡逻仍不抓人。监工停工后退出，地图切换、重开移除旧视觉，不留下重复节点。暂停日常表不累计警告。
