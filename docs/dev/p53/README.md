用户在主美聊天确认 `scene-concept-v21r2.png` 并要求按此制作，已核实聊天原话。A21/A22概念和A23生产素材分别由制作人验收；本人开发任务 `p53-architecture-render-20261006` 单独提交运行证据并验收。

复用：R04及原地图/对象ID、围墙几何、门禁日程、120分钟关押、撬门/钥匙救援、角色技能物品与A17/A19道具。修改：食堂两侧北墙物理厚度统一31.5、显示高度110；门从宽度推算高度改为独立110高；禁闭室外立面门/通风口/灯位置与封顶表现；重复标签删除。新增：A23材质与嵌墙门、配套编辑器v03图标、可选建筑配置和不透明屋顶节点。归档：无；旧资产保留，R01–R03无新配置沿用原显示和捕获行为。

## 空间与规则

禁闭室屋顶为不透明深灰材质，完整盖住室内地面、床、便器及人物；外部屋顶前缘12单位压顶和8单位檐口、外侧铁门/通风口/标识保留。屋顶宽板320×240，仅是纹理绘制尺度。屋顶和前立面在原房间平面范围装配，避免将屋顶向走廊或其他房间投影；室内人物/物品的额外信息层也遵守遮挡。门外人物可见，门口状态显示关押者与剩余时间，释放后人物恢复显示。屋顶始终不透明，打开铁门不会打开屋顶；角色可进入开放房间，但屋内人物仍不可见。

食堂北门两侧使用同一110高度、31.5物理厚度、浅灰墙面及压顶，门180×110与墙基座齐平。开态栅栏靠左，右侧透明通道；闭态封住门洞。禁闭门160×110嵌在对应暗色外立面。门图与逻辑分开：`access_doors`决定碰撞、视线和日程，PNG只消费状态，不按alpha推断障碍。12:00开食堂、14:00先疏散再关门，120分钟自动释放和伙伴救援不变。

## 配置与兼容

R04 `architecture.wall_surfaces[]` 以 `wall_index/height/front/top` 绑定真实围墙。房间内 `confinement.cells[].building` 包含 `roofed/height/roof/front/top/roof_tile_size`，房屋范围复用cell.rect、门引用复用door_id，不建立另一套碰撞。共享 `PropCatalog`加载A23，world textures保留Atlas裁切及mipmap过滤。墙/屋顶静态绘制命令保持缓存，不随摄像机移动重新离散取整。

编辑器中选墙可设置显示高度和两种墙材质，选禁闭区可开关完整封顶/调整建筑高度；材质图标用于属性栏，门图标用于摆设卡片。物理墙宽高仍独立编辑。删除/复制墙同步材质索引，撤销和保存保留建筑字段。旧地图无architecture/building时兼容。建筑范围与实体墙的组合由制图者核对，不自动移动全部墙/门/关押点。默认编辑总览隐去屋顶下的家具，碰撞模式可查看并编辑。
