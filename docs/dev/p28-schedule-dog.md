# v0.9 日程、警犬与弹窗层级

2026-10-05。对应用户截图的交易按钮盖住商店问题，以及限时越狱、日程、警犬请求。制作人承担P28/P29/P30，主美A08独立交付警犬素材并由制作人验收后接入。此前八帧人物、稳定相机与纹理采样继续保留。

## 当前规则

16:00劳动（狱警巡逻、警犬休息）→18:00放风（警犬出动）→20:00熄灯巡查（自动夜晚）→22:00封监。六个虚拟小时按地图总时限匀速压缩：R01/R02 180秒、R03 240秒、R04 300秒。配置入口data/schedule.json，时钟、剩余秒数与当前阶段在顶部，右上按钮/N查看日程。生产不再手动切昼夜；底层set_period保留作灯光接口与测试。

全员在时限内进出口成功；最后有效移动步完成全员撤离优先成功，未完成则超时失败。单帧delta钳制剩余时间，杜绝低帧率时多走一段；终局清理移动与持续技能、停止时钟/AI、显示带出人数/物品。原抓回仍是局部受挫，不重置日程或延长时限。重开与换图重置；终局遮罩上方保留关卡下拉。商店/日程不暂停，因此查看安排也需要时间。

警犬与狱警共用监管区域、碰撞和静态导航缓存，逆向沿原巡逻点行走；遇家具/箱子寻路，巡逻点长期堵塞跳过。警犬不推箱，也不直接抓回。每0.4秒记录有效移动伙伴的地面踪迹，保留10秒，最多约75条；附近180单位内且无遮挡的地面踪迹可被嗅探。循踪只使用该踪迹的位置，不读墙后伙伴当前坐标。90单位内无遮挡可直接确认伙伴，犬吠每4秒最多一次；显示示警圆环与提示。狱警收到位置后调查最多6秒，只有正常前方120度视野确认才转为追击；既有追击优先，不被犬吠重置。白天210/夜晚155只影响狱警，警犬鼻嗅范围日夜相同。伙伴回安全房间/免疫/已逃脱时清除其迹与犬目标；警犬不能越过安全边界。

素材为A08 German Shepherd，44世界单位、1待机+4不同步态、10fps。各帧区域单独裁切生成mipmap，idle/walk共用scale_height380，足底锚点注册；身体镜像朝左、文字独立。小地图用棕/橙方形区别狱警红圆点。A08生成来源、RGBA/资源检查、18文件SHA全部可核对；入口active.json仅在素材独立验收后启用。
