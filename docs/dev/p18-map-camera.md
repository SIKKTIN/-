# P18 大地图与 RTS 视野

Camera2D 在固定地图窗口 `[74,114,922,560]` 内显示局部，保留1:1世界比例。中键或空格+左键拖动平移，F定位当前伙伴；相机夹在地图边界，切小关卡恢复原视野。HUD CanvasLayer固定，纸框遮住地图窗外世界，世界提示随投影并在屏外隐藏，不拖动人物。

导航区域从 `bounds.merge(exit)` 动态构建，仍20单位网格。友军/守卫查询叠加身体与监管区约束后恢复共享网格；所有遍历按region定位。地板、出口提示和出口判定使用房间数据：旧两关越过东侧边界的出口保持原行为，R03内置出口使用收缩17单位区域。

右键屏幕点经世界canvas逆变换下令，HUD不成为移动目标。物品、商人、机关都在世界坐标，互动按钮使用屏幕投影；灯具与物理遮挡继续跟随世界。

`tests/p18_camera_check.gd` / `docs/tests/p18-camera.json` 验证大图导航、监管区、相机夹制/定位、坐标逆变换、HUD/角色不随拖动改变以及旧/新出口兼容。原生GUI与实际R03配置另在P19/P20验证。
