# P55 食堂墙体返修与运行 FPS

用户反馈的竖墙此前重复使用正面石柱图，横墙的低透明度黑点又被不透明核心着色器放大。这轮由主美 A25 制作真正的纵向墙顶与 L 形接点，制作人 P55 接入实际地图并添加运行帧率。

## 最终接点

R04 原有墙、门和碰撞坐标不变。墙 7/8 的外柱分别裁去 80 世界单位，厨房隔墙 12/13 的相交段按实际 20 宽对应裁去 66.667。新接点使用同一原图的 12 个源区注册到 80×150，保持连续浅色顶面和窄暗侧面；左右接点通过正尺寸四边形的 UV 镜像绘制。素材与配套编辑器图标分别在 art/architecture/v25 和 art/editor/v05。

接点原点 Y=1147.776232618；逻辑北墙脚 Y=1261.5；后续纵顶从 Y=1297.776232618 接出。新模块可见墙脚与旧北翼原图一致，实际 2 倍相机像素检查中两者基座分界都在世界 Y=1224。纵墙南端仅一次 90 高正面端头，不再重复柱帽、正面柱脚。

WorldTexture 已在生成 mipmap 前裁取源区，所以模块的绝对 source 坐标必须减去裁区原点 (42,287)；AtlasTexture 回退则取完整原图，使用绝对坐标。实际窗口复核发现并修正了此差异。另一轮右角复核发现负目标矩形与区域裁切无法稳定镜像，已用显式 UV 反射替代。早期错误截图不作为最终验收证据。

## 透明边缘与 FPS

safe_edges_v25 保留原始透明度，低 alpha 仅衰减，不再放大成不透明碎点；仅高透明度核心区域恢复实体。A24 原图、禁闭屋顶和旧着色器均未改写。实际 GPU 对照显示横墙顶端边缘对比降低；正常轮廓墨线保留。该 ROI 包括抗锯齿过渡，不代表所有零散源像素被逐个删除。

FPS 位于逃脱人数下方，读取 Engine.get_frames_per_second()，按实际墙钟每 250ms 更新，节点 PROCESS_MODE_ALWAYS，日程暂停或时间流速为 0 时仍更新。显示忽略点击，位于日常表等模态窗口下面，1200×720 与 960×540 都处于安全区域且不覆盖小地图。采图时的冷启动和 GPU 同步读回会影响显示数值，这些图不是正常游玩性能基准。
