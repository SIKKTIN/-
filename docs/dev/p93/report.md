# P93 移除日常表入口

HUD不再显示日常表按钮，起床与教程结束也不再自动打开日程安排面板。旧调用入口保持关闭，不会暂停游戏。左上角时钟继续提供作息说明，NPC继续遵循已有日程。

监管提示栏从时钟右边开始布局，按钮自定义布局也释放了原日常表占位；作息说明中删除了日常表暂停的旧提示。

沿用现有教程完整流程检查，29项流程检查与86项双分辨率对白布局检查通过。既有检查更新为正式日直接开始、不弹出安排表；正式时钟已开始前进，期限检查允许完成淡出后测试驱动推进的一帧（0.05秒）。未新增针对低影响界面变化的测试。

运行游戏重新加载源代码后进行实机确认。保留其他地图、美术、编辑器和主逻辑未提交改动。
