# P102：NPC 姓名、关系、记忆与行为评分

第一版在现有作息和移动系统上接入社交状态。林川为玩家，周大勇、许文斌为两位同伴；教官、监工、门岗、商人和增援看守都有独立姓名。角色配置在 `data/social_characters.json`，逻辑在 `scripts/core/social_world.gd`。

## 可玩的行为

- 聊天显示姓名、情绪、好感和信任。初次打开不奖励好感；真实闲聊最多每 45 秒增长一次。角色会根据恐惧、烦躁、欠人情和重要记忆回应。教程讲述人和相关文本使用同一套姓名。
- 同伴求助比较帮助、分享情报和拒绝。帮助可分出口粮或借出 2 块钱；口粮增加玩家饱腹 12，同时减少赠与者饱腹 12。资金从 NPC 本人扣除，劳动所得也进入本人余额。每次求助冷却 30 秒，每位 NPC 每个游戏日最多一次资源帮助，归还人情不重开额度。
- 成功送礼和归还人情增加好感、信任并留下记忆。成功购买提高商人的信任，失败交易不改变关系。分享的监管消息可通过“再说说你上次的消息”复查。
- 好友可在自由活动时主动帮助附近饥饿的玩家。同伴站在一起、有空且无移动命令时会短暂交谈，形成彼此的关系，随后恢复作息。
- 亲眼看到玩家离岗或宵禁违规时，同伴比较提醒、报告和不介入。报告要求现场视线、报告人与玩家距离不超过 180、与巡逻看守距离不超过 240 且无遮挡。看守调查报告位置，之后仍按原有视线、追击和抓捕规则行动。
- 附近亲眼看到抓捕的角色留下记忆并增加恐惧。情绪随实际经过时间逐渐恢复。每人最多 12 条记忆，先淘汰普通闲聊，保留重要事件。新一轮清空状态；本版没有跨存档持久化。

## 评分

先检查行为是否可执行，再计算：

`S = 30×自身收益 + 35×关系系数×玩家影响 + 22×性格契合 + 12×情绪倾向 + 8×作息契合 − 35×谨慎×风险概率×损失 − 8×成本`

收益、契合与情绪项归一化到 -1～1；风险、损失与成本为 0～1。关系系数为 `0.6×好感/100 + 0.4×(信任−50)/100`。玩家影响按下表加权，玩家饱腹低于 40 时身体影响权重翻倍，再归一化。

| 影响类别 | 权重 | 示例 |
| --- | ---: | --- |
| 身体 | 0.25 | 分出口粮、补充饱腹 |
| 资源 | 0.20 | 借钱、交易 |
| 自由 | 0.20 | 报告违规后可能被追捕 |
| 安全 | 0.20 | 提醒风险、暴露位置 |
| 信息 | 0.10 | 分享监管规则 |
| 关系 | 0.05 | 帮忙、拒绝、欠人情 |

同一决策情境保留 8 秒承诺；新方案领先不足 6 分时保留原方案，减少反复切换。`social.snapshot()` 包含每个候选行为的分数、分项、影响预测、关系和记忆，方便调参。影响表描述预期后果；资源与抓捕后果由实际执行逻辑兑现。

自主判断每秒一次，不增加逐帧寻路；姓名显示每秒重绘五次并剔除画面外与屋顶下的角色。暂停、非游玩状态和入监日教程期间暂停自主社交，保留教程现场演出。看守的作息、执法、钥匙与聊天技能仍有原来的硬约束，好感不会免除违规处罚。此版优先实现社交行为，未将所有日常行动替换为评分选择。
