# P104：玩家手动操作，NPC 独立生活

玩家不再参加自动日程。初始、换时段、换天、停止动作和旧日程面板的“恢复”都不会替玩家下达生活指令。09 点站在工位不自动开工，12 点不自动取餐，13:30 不自动返工，20 点和午夜不自动归寝；关闭管制房间只提示玩家自行离开，并保留原有门禁规则。玩家的手动移动命令不会被宵禁覆盖。

主动点击“工作”或“取餐”仍可完成一次交互，包括就位、领取午餐和前往餐桌。这些记录标记为 `player_action`，移动来源为 `interaction`，不能来自自动日程。吃满 20 分钟后留在餐桌原地，停止劳动后不会恢复劳动，下班停止工资结算但不会把玩家送去下一活动。睡觉跳过夜晚、禁闭处罚和正常执法继续保留。

NPC 使用 `scripts/core/npc_life.gd` 的独立状态，每人保存意图、当前目标、需求、阶段、下一次判断时间和行为评分。生活判断每秒检查，空闲选择承诺约 25～35 个游戏分钟，阶段变化立即响应。角色姓名上方显示实际活动，包括工作、取餐、用餐、回寝休息、散步、找人交谈、查岗、守门与交接。

| NPC 类型 | 生活逻辑 |
| --- | --- |
| 囚徒 | 按岗位规则提前到工位、劳动、独立取餐用餐和归寝；空闲时根据个人疲劳、情绪、性格及附近关系，在休息、散步与交谈之间评分选择。疲劳或恐惧高时更愿意休息，重情义的人更愿意找人交谈，不主动找恶劣关系的人。 |
| 巡逻教官、监工、门岗与增援 | 各自岗位控制器继续执行上岗、下岗、巡逻、查岗、查寝、追捕与搜查；生活状态绑定到本人实际岗位、目标与现场状态。 |
| 商人 | 本人的工作、通勤、营业与休息逻辑继续运行；生活状态使用真实目标和营业状态。 |

玩家不在 NPC 生活名册中。NPC 通过现有碰撞和寻路真实步行，不需要玩家替它们安排日程。旧日程面板写入接口安全拒绝。没有工作点的旧房间会选合法的休息活动，避免生成不存在的工位目标。教程保留现场演出及 NPC 编排，玩家仍亲自完成指令。
