# P88 室外移动监工追捕掉帧

用户报告08:39寝室门外追捕时FPS30。P87覆盖的是监工仍在室内的触发时刻；本轮补测监工真实沿室外走廊移动、显示警戒区域的连续追逐。

## 原因与改动

附近视线遮挡物超过64个后，GuardWarning从GPU绘制切换到CPU视野多边形：每个矩形四角生成三条射线，每条再遍历遮挡物。监工每次移动均触发重建，单个警戒区域平均约29毫秒。本次不是寻路峰值（实测路径最长约2毫秒）。

保持原有64以内的uniform路径；密集区域改用RGBA32浮点数据纹理提供全部遮挡矩形，由同一shader裁剪。纹理按需扩容、普通移动重复更新原纹理；不再调用每帧CPU多边形与网格构建。没有截断遮挡物，也未降低AI检测、路径更新、视野范围或抓捕频率。代码仅改guard_warning.gd与guard_warning.gdshader。

## 本机原生渲染实测

Godot4.7.2，Forward+ / D3D12，RTX4050 Laptop，1200×720，无垂直同步。主角以120px/s沿走廊移动；真实监工AI在第15帧通过监管告警进入追击，其余NPC和表现正常更新。每档记录3秒固定模拟步长；所有采样均包含初次密集数据上传。旧CPU分支用QA历史副本同路线运行；生产代码保持新分支。未同时运行其他QA性能负载。

## 验证

D3D12和OpenGL各16项原生绘制检查通过：稀疏uniform/texture逐像素一致、第65和第265个遮挡物实际挡住警戒区域、动态遮挡更新、扩容与复用、密集转稀疏、夜间扇形、屋顶隐藏和信息开关。实际游戏11项检查通过：60/90档不改变时钟与物理步长、耗尽路径预算仍即时检测、四名门岗劳动追击、监工实际抓捕和第三次禁闭失败。
