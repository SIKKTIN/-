新开 R04 后，第1天为入监日。玩家跟随现有看守实际走到车间，亲自完成工作、警告恢复、20分钟用餐、NPC聊天、返回工位和回床任务。六章共29个步骤覆盖7:20起床、8:00关门、12:00吃饭与自由活动、13:30返回、14:00劳动、18:00收工、夜间查寝，以及门型、禁闭、背包、技能和属性说明。

演出使用现有角色的步行动画、镜头平滑跟随、逐字对白、目标指示和隔夜淡入淡出。人物在同一天内沿真实路线移动。讲解暂停作息；工作和用餐练习按正常时间推进；下一时段由玩家继续讲解后进入。教程期不消耗正式逃脱期限，示范被抓不累计禁闭次数。完成或跳过后进入第2天07:20，保留完整三天期限，清空演练的金币、警戒和处罚状态。暂停菜单可以重玩教程。
