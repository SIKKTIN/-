# v0.10 全屏浮动 UI 实装

2026-10-05，用户确认A09概念后开始执行。主美本人完成A10资源，制作人承担P33程序、P34整合；新多天规则单独列P35。

## 布局与交互

世界占满游戏视口，移除原页头、右侧永久栏与页面边框。左上为真实时钟、日期、每日时间轴和剩余虚拟时长；右上为全员目标、共享钱包、暂停和可收起的小地图。左下三伙伴卡使用固定身份肖像，技能图标按本局抽签显示；右下为当前伙伴背包、停止及按需展开的物品操作。普通1格、会收纳3格，肖像不会随技能变化。通知短暂出现，避开底部卡片。

暂停菜单统一放继续、关卡、声音、日程、重开、开发设置，实际SceneTree.paused冻结AI与时钟；控件PROCESS_MODE_ALWAYS仍可关闭，恢复不累加暂停时间。日程/交易/开发为普通活跃面板。模态遮罩覆盖动态视口，场景互动与小地图隐藏，商店仍能选右下物品出售。普通ESC关闭面板，其他时候打开暂停菜单。

MapCamera.view_rect及world_view_rect使用实际视口，跟随目标为动态中心、边界按每轴判断；小房间整体居中，大房间局部查看。地板以世界原点注册，仅绘制可见格子，外部补同色背景但不扩展游戏可走区域。地图点击/拖动、原RTS独立命令保持，无边缘滚屏。采用A10 Theme、可编辑SVG、AtlasTexture肖像，保留P25解析跟随、P26纹理mipmap及P32细墙AA/静态命令缓存。

横屏布局按安全矩形响应尺寸。移动端将系统物理safe_area转换到画布，桌面使用16/20单位边距。原生按钮主热区48单位以上、背包56×62。并未强制桌面操作系统独占全屏；此处全屏指游戏场景铺满窗口。未验证手机真机安全区。

## 验证

qa/p33_fullscreen_ui.gd在Windows D3D12原生窗口1200×720、1280×720、1600×720、960×540各46项通过，共184项；960×540的实际逻辑画布1280×720由既有canvas_items/expand设置决定。跨帧ScreenTouch实际触发选择、移动、停止、小地图收起/定位、菜单暂停/恢复、日程继续计时、买卖/背包选取、交接/放下/拾取/消耗工具、开发调速、成功与失败弹窗、重开换图。终局成功为隔离状态fixture，不伪称新完整逃脱路线。布局1/3格、初始人物不被时钟覆盖、四图加载、头像身份独立验证通过。

每尺寸8张真实帧截图（day/three-slots/menu/schedule/shop/item-actions/night/small-room）及JSON保存在docs/tests/p33-native-*。实际查看1200白天/菜单/商店、1600白天、960物品展开/小房间；夜晚另见P35。主美资源加载23项、原生24项，见docs/art/a10-*。
