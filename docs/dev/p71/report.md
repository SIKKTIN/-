# P71 提前起床、晨班准时锁门与白天圆形警戒

07:20开始新的一天（原08:00），寝室解锁，自动打开并暂停人员日常表；关闭/应用安排后按默认日程前往工作岗位。07:20–08:00是准备期，到岗位显示“到岗待命”，08:00才工作、消耗劳动体力和计工资。睡眠截止07:20、夜晚跳过和新一天边界同步提前，16倍时间也准确停在07:20等待安排。

晨班08:00关门，取消原到09:00的初次到岗宽限。关门瞬间门缝内的身体只移到所处门口一侧，避免卡门；不传送到工作岗位。禁闭释放返岗宽限、午间开门、下午既有入场规则和工作人员钥匙通行保留。监工必须实际接近门才会用钥匙，发现外出不再远程开门。40游戏分钟在默认压缩时钟中只有8.33秒，准备期步行速度为普通2倍并消耗完整路径节点预算，手动与自动一致，加速时钟也能实际走到工位。默认自由日程在19:20提前启程回寝区，保证20点前抵达，避免正常NPC被误抓；手动接管仍自由行动。

劳动期间外围巡逻与门岗显示劳动警戒。所有白天看守（巡逻、门岗、监工、增援）使用360度实际视野，受范围、距离、墙体遮挡与违规规则限制；午餐/自由时间仍不误抓。圆形不随朝向转动。可见警戒轮廓和填充共享精确裁切后的视野；仅夜间使用灯光阴影，白天使用缓存三角扇网格，不做每看守实时灯光。视野角点只使用半径内真实视线障碍物，避免无关远处摆设放大射线开销。
