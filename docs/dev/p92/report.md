# P92 场景内角色主持入监日

教程由持续存在的陈教官主持。使用原有巡逻看守角色担任带队教官，不创建会突然出现或消失的替身。教官真实走进寝室迎接，跟随玩家参观；说话前必须走到玩家145像素以内、视线畅通且角色已可见。监工老周亲自说明监管、下午劳动；商人在摊位旁介绍工具。

原来的大段系统讲解改写为43句角色口吻对白，分布在15段面对面交谈中。对白气泡跟随真实说话人的脚底坐标和镜头，双方转身相对；底部保留较小的任务条。对白逐字出现，继续按钮先补全文字、再进入下一句，不能跳过尚未到位的说话人。讲解期间停止前一帧的移动采样，避免角色在原地继续走路。

演出继续使用真实的带队行走、监工靠近、劳动和取餐动作、教官开关禁闭门、夜间走到床位点名。下午入场时等待教官和讲解角色实际进入后才演示14点关门，避免较慢的角色被关在外面。教程与正式三天期限、示范处罚隔离规则保持一致。

- 43句对白分别在1200×720、960×540检查，共86项全部通过：气泡、文字和按钮在界面内，气泡避开玩家和说话人的身体。原生截图人工检查寝室、监工、饭后和商人交谈。
- 正式模式回归：3秒警告与缓慢恢复30项、游戏规则11项、NPC两日作息13项通过。
- 合计169项不同检查；两种运行方式重复的检查不重复计数。逐帧真实行动：0.05秒步长下教官最大5.00012像素、玩家最大13.00034像素，均符合原有100/260像素每秒速度。
