# P64 同源连续墙体

用户指出上部 T 接口仍是正面柱石，下部是窄墙顶与侧影，属于投影、材质与石缝尺度不一致。此前局部判断不足，本轮按完整上下墙复核。

A31 的 T20/T24 直接复用冻结 V24 图集及 V27 纵墙同一取样窗，无新 PNG。接触桥取上一周期末 3 world，主 stub 从 local24 开始；下段 tile_origin_y=1170.48，clip 仍在1226.48，周期连续。R04 保留原横墙顶，front replace_ranges 从30.48开始，reuse_cap 只画 stem，避免叠新横臂。右墙沿用相同镜像侧影。旧 T30 保留历史加载，但新建分类使用 T31，配套 V11 MeshTexture 图标。

共享绘制器增加前面局部挖空并提取矩形裁剪；旧两值区间和默认调用保持行为。物理边界、门禁规则、家具与 NPC 数据未变。

实际 D3D12 GPU 原生验证：1200/960 两尺寸整墙22×2、分类与选放20×2、独立组件12、编辑器共享绘制/选取/拖动/撤销15，共111通过。门禁、禁闭、救援与逃脱73通过。左右 stub/bridge 对真实 V27 向上连续外推参考的采样 RGB 最大差均0。旧22个美术文件SHA不变。实际完整墙图确认顶面、侧影、石缝连续，顶部接触带没有暗断带；末端保持既有朝向变化。技术检查不等于用户审美批准。
