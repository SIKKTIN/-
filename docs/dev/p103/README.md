# P103：放慢时间并缩短劳动时段

默认 24 个游戏小时对应 900 秒，即现实 15 分钟。所有房间统一使用此流速；当前工厂原来为 300 秒一天，现为原来三分之一流速。默认正式期限仍为三天，合计 45 分钟的时钟预算；回床跳过睡眠仍会消耗对应的游戏时间。开发者设置中的倍速仍是相对此基础流速的倍率。

| 时间 | 活动 |
| --- | --- |
| 08:00–09:00 | 起床、准备、前往车间 |
| 09:00–12:00 | 上午劳动 |
| 12:00–14:00 | 吃饭与自由活动 |
| 14:00–17:00 | 下午劳动 |
| 17:00–20:00 | 自由活动 |
| 20:00–24:00 | 寝区自由活动 |
| 00:00–08:00 | 睡眠、锁寝与查房 |

每天劳动由八小时减到六小时。窗口饭吃 20 个游戏分钟、13:30 NPC 步行返工、20:00 宵禁、午夜查寝继续按原有规则执行。商人晚间营业提前到 17:00；员工到岗与离岗也跟随新时间。监工三秒警告与技能执行仍按真实秒计时，体力、饥饿与工资按游戏分钟结算。

`prison_schedule.work_window()` 从日程配置读取劳动区间，门禁、执法、工资和体力消耗共同使用此区间。避免界面已显示下班，内部仍使用旧的 18 点结束值。旧日程表、睡眠跳过提示、警报解除提示、普通聊天说明、地图编辑器标签与入监日教程均同步更新。教程和正式次日从 08:00 开始。
