# P80 连排房间墙边与屋顶衔接

按用户认可的连排概念实施。保留现有屋顶覆盖范围和四方向出入口，移除当前模块墙建筑的独立屋顶细边框。固定墙边直接复用地图现有墙体的绘制片段、纹理、着色器和坐标；外角与共墙T接口来自原石墙，并且始终保留。每间屋顶面与通风帽独立淡出，邻室保持覆盖。

实现新增 RetainedRoofWallEdges：地图加载时裁剪并缓存每块原墙体需要露出的顶部/纵向石边，合并重复裁剪区；共墙只记录一次固定墙边。边缘独立于屋顶透明度，并保存纹理/几何快照，不持有可能在家具刷新时释放的原墙节点。重新载入地图释放旧边缘并重新生成。非模块墙老地图沿用旧屋顶修边。

验证：24项原生墙边/连接/独立显隐/重载检查、53项遮挡回归、8组墙边像素对照全部通过，共85项；另有200个碰撞位置对照。寝室、禁闭室、食堂、车间各昼夜进入前后，采样固定石墙内部40,639–52,398像素，差异为0。采样排除了裁剪边界外侧2像素，不宣称整幅截图一致。屋顶范围及R04文件哈希保持不变。

原生1200×900反复进出120次：墙边绘制重建0次，房间透明度/家具同步CPU中位1.888ms、P95 2.195ms、最大2.398ms。Godot在重新显示屋顶CanvasItem时仍调用屋顶_draw，记录少量原有四边形，没有重新生成墙体或读取纹理。

原生1200×720、D3D12、RTX4050、60模式六场巡逻/追捕/夜间压力测试，每场7秒、前1.5秒暖机排除。平均59.68–60.00FPS；P95帧间隔16.718–17.018ms，最大偶发32.54ms，不能以均值宣称每一帧全程锁60。90模式和其他设备未在本次重新测量；保留P79帧率设置行为。

运行：主场景 res://scenes/main.tscn。证据见 performance.json、docs/tests/p80-connected-native.json、p80-wall-pixel-parity.json、p80-roofs-headless.json、p80-stable-60.json 与昼夜对照截图。qa/p80_connected_roofs.gd、qa/p80_roof_regression.gd 和 qa/p80_wall_pixel_parity.py 可复现本次验收。地图、美术以及编辑器中的外部未提交修改保留。
