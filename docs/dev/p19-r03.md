# P19 仓库交易所灰盒

R03 活动1800×1100，旧房间约3.8倍。安全房间有固定中立商人，中央监管仓库放6件旧零件、两组货架、一名巡逻狱警；右侧锁门和下方重箱两通路，区域内东侧出口。四技能随机池允许重复，不加保底。默认钱0；3件零件卖得9元，可买一把钥匙，2件可买6元工具；钥匙1、工具2件固定初始库存。R01/R02保持旧配置。

边界/净空已落到配置：重箱[1512,1076,94,92]，隔断下端1044、地图底1200，上下各32，小于人物直径34；普通伙伴不能直接钻过，力量者可推动。出口[1790,590,90,220]在地图边界内。guard_zone始终限制狱警，不进入起点房间/东侧走廊。

初始直冲脚本不是解法：白天撬锁伙伴被抓；搬货开门和推箱后最后一人分别在返程巡逻附近被抓。完整失败快照保存在 `docs/tests/p19-initial-route-failures.json`，未删除或写成成功。

观察实际巡逻窗口后，7条完整路线通过，均0抓回：撬锁技能开门（昼/夜各66.35秒）、卖货买钥匙（昼/夜各58.8秒）、力量推箱（昼/夜各81.12秒）、无扩容的三人全聊天队伍由同一普通角色分3趟搬货买钥匙（夜129.6秒）。算法只下达合法移动、拾取/交易/技能命令，守卫与60Hz游戏逻辑持续执行；在安全房间等待巡逻抵达适合的区域，没有瞬移、暂停AI或修改狱警状态。

实际运输对照：同三件零件，3格角色一趟、1格角色三趟，均能筹9元并全员逃脱。路径距离与到款时间在每条路线 `transport` 字段记录；这验证扩容提高效率，普通角色仍可做到，不宣称这些参数已经平衡。
