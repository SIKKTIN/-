# P67 运行时帧率优化

当前 R04 原生窗口 1200×720，NVIDIA RTX 4050 Laptop，Godot 4.7.2，Forward+ / D3D12，VSync 保持启用。帧率来自墙钟逐渲染帧统计，另记录 Engine FPS。Performance.TIME_PROCESS 是引擎原始监控值，不解释成独立 CPU 耗时。每种情况预热 1 秒、采样 5 秒；诊断隐藏信息层采样 3 秒，不参与最终性能结论。时间流速为 0，角色、移动、镜头、AI和动画保持正常运行。

| 场景 | 优化前平均FPS | 优化后平均FPS | 优化后P95帧耗时ms |
|---|---:|---:|---:|
| day_stationary | 11.7 | 89.7 | 14.02 |
| day_moving | 15.9 | 118.8 | 9.89 |
| night_inspection | 5.0 | 92.7 | 13.71 |
| night_full_alert | 1.4 | 56.1 | 20.27 |

对照使用临时隔离工程，同一实时地图/美术及导入缓存、相同渲染设置，替换为优化前代码；不覆盖主工程未提交编辑。两个报告地图 SHA256 均为 `1866813692bc8154632c63599c7a4b968cf786a4adbedf23497922cecf3e61f3`。全员警戒额外部署 2 名搜查者（与原规则一致）。测试窗口正常呈现、无无头渲染/人为帧延迟/关闭VSync。样本短且AI路线在实时推进，数值代表本机自动化场景，不是手机实测或稳定60FPS承诺。

## 修改

- 视野轮廓保留原有全部角度和准确遮挡，用距离筛除不可能命中的远墙。按位置、朝向、半径、警戒范围、障碍版本和箱子状态缓存；屏幕外轮廓不计算。看守发现/追捕逻辑原样保留。重算由约30.62ms降至约0.86ms，重复读取约0.07ms。
- 墙、家具、门和箱子保留Godot绘制命令，改变位置/资源/布局时才更新；门的开闭资源参与缓存键。
- 静态区域底色及墙体投影独立缓存层；箱子、门、地图变化即时失效。人物阴影、灯光、动画及相机继续逐帧更新，保留原画质与采样/抗闪烁方案。
- 背包内容和卡片样式按实际变化刷新；HUD保留事件即时更新，主循环和HUD节点不再重复整套更新。
- 小地图每次绘制只计算一次坐标变换，输入定位仍实时换算。

## 验证

原生渲染回归25/25：1000个射线相交样本、12组昼夜/寝室/门边视野（对原轮廓最大误差0），静态绘制保留、镜头移动不重建、门开闭及阴影失效、箱子移动、背包容量/拾取、钱数、小地图定位、日程暂停/恢复。规则回归73/73：工作/取餐路线、12–14门禁、禁闭2小时、同伴救援、看守聊天/通行、三人逃脱等。临时详细计时插桩已恢复，不进入交付代码。
