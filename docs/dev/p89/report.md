# P89 脚部移动与全身门洞通行

用户批准保留脚部碰撞，并让门洞检查整个人。原寝室侧门可见口40px高，人物美术60–64px高，脚能穿过而头部压在墙上。

新增独立的DOOR_BODY矩形，脚底原点偏移(-18,-64)，尺寸36×68；原8px脚部圈、选择圈、检测及抓捕距离保持。全身框只参与门框及门扇，不用于普通家具/墙壁移动碰撞。侧门可见投影最小96px（净口80px），原寝室门从(680,400,20,40)变为(680,344,20,96)，下端仍440，与相邻石墙接缝固定。复用已有自由门、铁栅及锁门素材，不改地图文件。

DoorPassage统一读取绘制使用的门口及端框，预计算全身框对门框/关闭门扇的禁入脚底区域（矩形Minkowski差）。脚部放置、实际分步移动、连续扫掠、两套寻路采样及动态门更新都使用同一组约束；检查警卫持钥匙规划仍可穿过锁寝门，但端框全身净空保持。门状态改变后更新缓存；入房、出房不会重新建门或导航。

进入房间时，只有穿过合法门洞的身体部分进入才提前揭开屋顶，普通墙上的头部重叠不会揭开。离开等全身清除边界后再盖回。普通门关闭等待身体清除，已有联动门同时检查两侧，避免另一侧夹人；强制禁闭保留即时关门并落位的规则。定时门撤离检查也从脚部改为全身重叠。
