# P90 监管3秒倒计时与缓慢恢复

用户要求发现偷懒后3秒追捕、UI显示剩余时间，且短暂工作不能立即清空，避免反复切换工作刷新倒计时。

车间内第一次被看到才开始警告；已启动的倒计时继续按实际游戏运行秒数推进，不因离开视线、遮挡、聊天或监工换岗而冻结。车间外被看守看到仍立即追捕。r04的warning_seconds从8改为3，其他地图无监管时不添加此机制。

warnings值现在表示0到3秒的警戒积累。实际劳动每秒降低0.5秒警戒，最高需要持续劳动6秒解除。只点工作、走向工位、使用技能或停工不算恢复；停工保留积累，重新继续倒计时。已触发追捕时也不因点工作瞬间解除，需消退到0。暂停不积累、不恢复；收工、被抓、合法释放/重开清理，避免次日继承。

HUD顶部显示一位小数的“秒后追捕”，红色进度条积累；实际工作时显示“还需工作多久”和绿色消退进度。主角卡片和头顶标签同源，不维护另一套计时器。1200×720及960×540检查通过。警戒条不拦截触摸输入。
