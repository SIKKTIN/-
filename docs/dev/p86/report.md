# P86 门框在实际画面中的辨识度

用户试玩确认P85端框缺乏辨识度。根因是侧门端框被缩到3世界单位，源图的圆形铜铆钉横向压成小于1像素的细线。

现有素材不改动。端部切片从3增加到8单位；仍完全位于20×40门洞内。增加端框的深色描边、顶部钢边高光和正常游戏尺寸的铜铆钉绘制，避免细节经大幅缩小后消失。横门端部上限由7增加到9，其余比例和中央门槛、铁门收起行为不变。装饰仅属于缓存绘制命令，不参与碰撞或寻路。端框切片没有向侧面凹进，没有修改门洞或墙体。

1200×720原生、1倍缩放实际截图已检查，端框及四个铆钉现在可读，进入前后保持一致。10项针对检查全部通过：自由门类型/尺寸、端部范围、实际穿越路径、遮挡切换缓存、墙体/寻路不重建、自由入口夜间畅通、铁门开关阻挡、地图SHA和原始PNG一致。检查不包含FPS基准或新的帧率保证。
