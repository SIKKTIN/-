# P94 单主角 HUD 与背包

依据用户确认的 approved-concept.png，把左上状态卡、时钟、背包抽屉、能力/互动按钮和教程任务条改为同一套搪瓷、金属与帆布配色。状态卡仅显示主角，不再显示角色切换编号与勾选标记。

背包按真实能力显示 1 或 3 格，使用现有库存实例、容量、拾取、钥匙、6 秒撬锁、丢弃和交易逻辑。选择物品显示大图标、名称、用途和使用条件。未加入重量、装备、稀有度、制作或售卖机制。旧的伙伴转交按钮始终隐藏。

打开背包收起小地图并关闭它的触摸输入；暂停、对话与结束界面优先。背包和商店分别显示，地图与物品详情不重叠。保留已有自定义按键位置设置，隐藏的旧 HUD 元素不阻挡拖动位置判定。

教程条高度由 164 缩至 92，小屏显示简短任务提示，完整说明保留在工具提示和教官演出中；教官走路、面对面讲话、任务条件与惩罚规则不变。

验证：

- `qa/p94_single_player_ui.gd`：原生 D3D12 窗口，960×540、1200×720、1440×900。检查物品详情、边界与顶部区域、全部教程任务文字、1/3 格容量、真正拾取/丢弃/钥匙开门/撬锁、暂停与恢复，以及商店并排布局。
- `docs/tests/p94-single-player-ui.json` 和 p94 系列 PNG：本次 UI 结果。商店 PNG 使用布局夹具，不代表交易流程截图。
- `docs/tests/p94-tutorial-regression.json`：既有 P92 完整教程回归在本次 UI 上通过，29 项流程检查与 86 项演出/页面布局记录。随后补充全部任务条文字和旧转交按钮检查。
- `docs/tests/p94-live-tutorial.png`：编辑器启动主场景，陈教官开场演出。当前原生帧率读数为 60 FPS；这不是全场景性能保证。

新位图素材和生成提示词见 `art/ui/single_player_v01/manifest.md`。面板使用缓存 StyleBox 和 Godot 原生绘制，AtlasTexture 边界只在初始化计算。
