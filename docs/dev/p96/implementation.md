# P96 教官带路与通用 UI 性能

本次针对用户截图中“跟随陈教官到车间入口”的性能反馈。未稳定复现持续 38 FPS，但原生采样记录到自动囚徒寻路尖峰及帧耗时波动。

修改：

- 所有角色的路径平滑都从相邻转折点开始做精确检测，停止在第一段被挡的路线，避免普通囚徒从远端反复向整张地图投射碰撞射线。
- 最近导航格先检测数学上最近的候选点。不可用时仍执行原有完整邻域扫描；保留脚部碰撞、门口全身判定、动态人物及箱体阻挡。
- HUD 根据实际显示数据变化重绘时钟、状态卡、操作按钮；缓存背包按钮样式，隐藏的 NPC 状态卡不再申请重绘。
- 教程条仅在安全区、按键位置或按钮状态变化时重新布局；任务文案表为常量。气泡尾巴仅在坐标变化时重绘。
- HUD 初始化时等待属性与警报对象创建，避免首次配置读取未初始化依赖。

RTX 4050 Laptop / D3D12 / 1200×720 / 原有 60 FPS 预设，窗口逐帧采样，两个场景分别 360 帧；同一地图 SHA256。没有调整模拟速度、角色数量、画面质量或帧率读数。

| 场景与指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 带路等待：帧耗时 P99 | 25.196 ms | 16.774 ms |
| 带路等待：游戏更新最大耗时 | 11.366 ms | 6.049 ms |
| 带路等待：自动囚徒寻路最大耗时 | 8.155 ms | 2.311 ms |
| 跟随移动：帧耗时 P99 | 22.176 ms | 16.773 ms |
| 跟随移动：游戏更新最大耗时 | 11.138 ms | 8.546 ms |

移动样本仍记录了一次 36.946 ms 的最长帧；分位数改善不代表设备在所有场景都绝对逐帧 60 FPS。冷启动样本包含首次窗口/渲染初始化的长帧，不与稳定运行样本混用。中间实现的初始化错误已修复，最终原生测量和回归日志无脚本错误。

重启编辑器主场景，通过真实气泡回调走完开场，到达截图对应的 follow_work 阶段后采样 180 帧：FPS 60，P99 16.818 ms，最大 16.832 ms。见 p96-live-follow.json/png。

验证：完整教程 29 项流程与 86 项对话布局检查通过；原生鼠标/触摸、暂停/恢复、章节更新、跳过教程等 18 项通过；两天 NPC 作息 13 项通过，包括开工、20 分钟午餐、13:30 返工、工资、归寝和无瞬移/误捕。

结果：docs/tests/p96-tutorial-before.json、p96-tutorial-final.json、p96-tutorial-headless.json、p96-dialogue-input.json、p96-npc-two-day-cycle.json。性能脚本单独记录更新分段和寻路耗时，测试夹具仅用于复现，未接入生产场景。

世界脚本只提交本次两个寻路优化位置，其余地图/逃脱路线修改保持原工作区状态。
