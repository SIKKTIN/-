# P75 看守从正门步行进出

按用户确认的路线，监工12点、18点结束工作后先穿过车间门，再经过右侧厂区铁门，走到地图外才退场。7点、13点提前从厂区铁门进入，经车间门返岗。上下岗步行速度215世界单位/秒，不修改主角移动速度或游戏时间倍率；原有走路动画实时跟随实际位移，头顶显示“前往岗位”“离岗 · 前往正门”。

门岗20点步行撤离，7点步行回岗。查寝报警的两名增援创建在地图外并走入；晨间警戒立即解除，人物随后实际走出。两名增援保留身份复用，撤离途中再次报警会从当前位置折返，人数不会叠加，场内不会直接删除或重新摆位。永久巡逻看守照常巡逻。

看守接近真实门禁时用钥匙临时开门，穿过后恢复门禁；门框有身体时延迟关门，玩家永久解锁不被回锁。地图外通道只供登记且正在进出的看守使用。路径被阻挡时等待并限频重试，暂停时停止；无传送补位。监工劳动时段追捕和所有看守的劳动违规侦测仍保留。
