# P84 脚底小范围碰撞

用户要求人物碰撞缩到脚部。新增actor_footprint.RADIUS=8，替换原17半径；继续以既有注册的脚底世界锚点为中心。角色贴墙余量从17缩到8，图形身体可以自然重叠墙面表现，脚底实际碰撞仍阻挡。人物图形、身体选取范围、23半径选中圈、视线及抓捕距离保持。

世界逐步移动、推箱接触、人与人间距、线段移动测试与两套缓存寻路均使用同一脚底半径。移动订单目标验证、看守与警犬可站立检查、寝室判定、工作区到岗、禁闭落点及编辑器出生点检查同步使用8，避免能走到而不能下令或NPC仍按旧尺寸绕路。墙边、门材质和地图几何未改动。

64项通过：51项原生脚底/实际贴墙/移动目标/六侧门NPC往返/门开关/钥匙撬锁/落点/缓存检查，13项两日免疫捕获的默认通勤检查。可以站在离墙9单位的位置而旧17半径不能站立，脚底进入距墙5单位仍被挡住。寝室墙y440前实际移动停在脚底y429–432范围，食堂墙y1300前停在y1289–1292范围；允许3单位分步移动的离散余量。三人实际用餐各20分钟，NPC13:30返工并按日程入睡。

初次脚底测试的寝室1NPC入口断言被测试主角占位阻挡（新增移动订单验证将主角停在NPC目标旁）；将测试主角停到远处后通过，没有放宽通行碰撞规则。未进行新的FPS基准。
