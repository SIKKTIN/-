# P76 房间内部可见性

主角脚底进入房间才揭顶；离开重新遮住。进入内侧4单位触发，离开保留6单位门槛缓冲，屋顶0.2秒过渡。其他NPC经过、门打开、镜头或小地图移动不揭顶。出生寝室立即可见，走廊及室外正常显示；已探索位置保留记忆，不保留实时室内情况，新一局重置。

当前R04扩建布局按原有数据兼容派生11间房：三间寝室、车间、食堂、三间禁闭室、仓库、洗衣房、设备间。独立visibility_rooms可覆盖默认派生范围。复用已存在的屋顶与石墙压顶纹理，保持外墙和门的原有深度；进入禁闭室时揭掉原建筑壳，并恢复室内墙和摆设。屋顶有不透明底色，避免贴图透明像素露底。

人物身体、阴影、工作/吃饭提示、物品和商人信息、室内灯光及看守警戒使用同一可见性查询；小地图只保留不可见房间区域，过滤动态人物和物品点。隐藏NPC不在聊天和交易/拾取目标中，离开房间后关闭仍指向室内的聊天。主角危险警告照常显示，碰撞、门禁、巡逻、劳动、追捕和NPC日程仍运行。未增加门缝窥视或窗口观察。

编辑器完整显示场景，新增独立“房间可见范围”图层和放置工具，支持名称/ID、矩形移动缩放、关联多扇门、隐藏/独显/锁定、撤销重做、保存重读和试跑。旧图打开时兼容生成范围，保存后写入显式配置；本轮未改写用户的R04地图文件。校验范围宽高、ID和门引用。

189项检查通过：55项无渲染及57项实际渲染房间/编辑器检查（包含小地图像素验证），33项劳动执法、23项午餐/工资、16项两天日程、5项完整编辑器UI；另外100组碰撞对照一致。实际截图验证屋顶遮住室内，进入揭开，离开复盖及自己的禁闭室内部显示。两天四班监工到岗，NPC午餐20分钟、13:30返工，未出现误抓或传送。
