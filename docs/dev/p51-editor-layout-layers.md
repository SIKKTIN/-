# P51 · 操作、素材与图层分区

2026-10-06。用户要求操作工具与可摆放物分开、后续美术必须配套编辑器图标、分类查看巡逻/物品等标记。A18主美制作图标与长期交付规范，P51制作人接入界面和图层交互。两项独立验收，均通过CLI执行。

## 界面布局

- 顶部第一行：地图、名称、重读、保存、另存、地图检查与试玩。
- 顶部第二行：选择V、平移H、绘墙B，随后撤销/重做、复制/删除、全图、吸附与碰撞开关。只放操作工具，当前放置模式以文字显示。
- 左侧“素材”页：家具设施、食堂设施、杂物摆设、人物NPC、可拾取物品、规则日常点、区域寝室门七个分类；两列48px图标卡片，中文名与提示。点击卡片立即激活对应放置，点击地图放置，V或Esc取消；不再依赖旧“摆设”工具加下拉框的组合操作。
- 左侧“对象”页：已有对象列表，可按图层筛选、点击定位。隐藏层不显示，锁定层有标注且禁止选中。
- 中间：地图布局、当前可见标记及巡逻路线。总览只画淡色大格，放大后显示细格，吸附仍为20单位。
- 右侧：分类图层在上、对象属性在下。“图层”按钮可折叠图层区，让出属性编辑空间；属性区单独滚动，小窗口也能编辑完整字段。

## 图层行为

七层为墙门机关、场景摆设、人物NPC、巡逻搜查、可拾取物品、日常活动点、区域寝室。显示与锁定独立。

默认“场景”显示墙门机关、摆设、人物、物品，隐藏巡逻/日常/范围标记；“全部”打开全部层；“独显”仅显示选中对象或当前放置对象所在层，未选中时为墙门机关。可逐层勾选眼睛或锁定。

隐藏层会同时隐藏对象、标签、巡逻连线和范围，不能从地图或对象列表选中。锁定层继续显示，禁止点选、移动、复制、删除与放置。隐藏或锁定已选对象会清理选中；隐藏/锁定当前放置层会结束放置模式。选择规则素材时自动显示相应层，但不会自动解除锁定。

这是编辑器视图状态，不写入地图JSON，不删除真实对象，不影响游戏内运行规则；当前窗口换图会保留图层状态，新窗口默认“场景”。撤销/重做继续管理文档修改。地图边界从对象页选择，不再因点击空白区域误选边界。

## 美术与图标接口

`art/editor/v01/manifest.json` 使用 `{schema:1,assets:[{id,name,category,editor_icon}],tools:[{id,name,icon}]}`；P51的 `editor_catalog.gd` 读取独立图标清单与已有世界manifest，素材ID保持一致。图标只用于编辑界面，尺寸不驱动世界占位/碰撞。

A18提供14项摆设AtlasTexture和26个工具/逻辑符号（25个SVG文件，门岗/巡逻看守共用一个）。旧PNG字节不改；AtlasTexture裁框与虚拟正方形透明边距独立定义。逻辑点、实际物品、工具、显示/锁定有专用符号。没有独立图标的旧素材仍可缩略图回退，后续新美术的完整交付必须有 `editor_icon` 与小尺寸QA。

长期规范在 `docs/art/editor-icon-standard.md`。已通过正式内容流程应用到GameCreator美术模块：`productionDocs/@editor-icon-production-standard-v01`，方案名“地图编辑器图标 · 美术配套交付规范 v1”。保留历史风格基准revision3，不改变世界资源或规则。提交草稿存于同目录 `p51-icon-standard-draft.json`。

锁门/开门“外观”卡片仍是静态摆设；真实主门、寝室门及出口从对象列表或规则标记编辑，图标不增加新的游戏机关类型。

## 入口

Godot顶部“关卡编辑”页，或运行 `E:/Project/Godot/这次怎么逃/scripts/editor/open_editor.ps1`。新独立窗口标题带“分类图层”，旧窗口的未保存草稿不会被本任务强行关闭或保存。保存、备份、外部文件冲突保护和未保存草稿试玩/F10返回沿用P50。
