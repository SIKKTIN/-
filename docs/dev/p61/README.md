# P61 编辑器实景建筑预览

问题：素材面板已使用新建筑图标，但 MapCanvas 仍直接画墙体和封顶色块，画布无法预览实际建筑。

修改：以纯几何 PreviewGeometry 适配器复用游戏 WorldVolume 和 RoofBuilding，读取当前 v03 表现配置及完整建筑资源。墙体、门、箱、设施与禁闭室壳体/屋顶采用游戏绘制；地面使用同源地砖。原生前景覆盖层保留选中框、标记、巡逻线和碰撞显示。贴图墙面可直接选中；锁定或隐藏图层不能命中。几何拖动复用绘制节点与纹理，更新集中在文档变化时，摄像机仅更新变换，不启动游戏模拟、寻路或 NPC。

验证：1200×720、960×640 两种原生窗口，各 15 项建筑操作和 15 项素材分类检查，60/60 通过。实际鼠标拖动、吸附、撤销、可见墙面命中、图层隐藏恢复、锁定、表面参数修改及碰撞覆盖层通过。目视检查全图及食堂石墙放大截图，墙体有实际立面、直纵墙和完整 L 角，禁闭室显示屋顶与门。R04 文件 SHA 不变。

地图数据、运行时绘制实现和历史美术资产未改；用户已有 project.godot 改动未纳入。编辑器预览初始门状态，不推进日程和灯光。
