# P74 多巡逻NPC性能优化

相同R04地图、1200×720、RTX4050、Forward+/D3D12，采用同一脚本每场景预热1秒并采样4秒，关闭VSync与帧率上限。匹配测试移除其他运行游戏后顺序执行优化前后版本。16名看守池在白天全部参与，夜间正常退岗后13名警戒在岗；压力测试冻结日程时钟并免除被抓，AI仍按实际帧间隔逐帧巡逻。正常日程另外使用实际游戏主循环验证。

| 场景 | 优化前FPS | 优化后FPS | 提升 | P95帧耗时前→后 |
| --- | ---: | ---: | ---: | ---: |
| 白天4名看守 | 95.45 | 137.48 | 44.0% | 12.272→8.284ms |
| 白天16名看守 | 53.80 | 83.40 | 55.0% | 20.889→14.064ms |
| 夜间16名看守池 | 64.25 | 80.77 | 25.7% | 17.582→14.069ms |

定位发现警戒轮廓随移动逐帧发射大量CPU射线、创建ArrayMesh、绘制复杂边线；夜间叠加阴影灯光。普通碰撞逐次遍历全地图。16名白天看守的额外AI从2.040ms降为1.139ms，绘制调用均值从1324.65降为1198.43。第一组独立对照也测得白天75.47→117.69FPS；绝对帧率会随当前运行负载变化，不作为每次运行的固定承诺。

警戒显示改为每名看守一个保留的四边形，GPU实时按附近遮挡矩形和活动边界裁切圆形/扇形；保留颜色、半径和昼夜规则，超过64个附近遮挡时回到原来的完整精确网格，避免丢遮挡。没有减少人数或冻结屏外AI，没有对实际侦测和抓捕降频。屏外角色身体/提示/阴影不再反复绘制，夜间屏外手电暂时不提交光照，返回镜头后自动恢复。碰撞按128世界单位做宽阶段空间索引，再用原来的精确圆与矩形判断；门改变使缓存失效，箱子始终动态判断。不可达巡逻路线遵守原有0.35秒重试间隔，避免每帧重新寻路。

181项检查通过：10000组空间索引与原遍历结果完全一致（普通/查寝碰撞、不同半径、角色、箱子），3582个实际GPU像素样本验证圆形及墙后遮挡；门变化、箱子移动、屏外继续巡逻/侦测、身体与灯光恢复、密集地图回退均通过。3次禁闭、查房报警/清晨解除、劳动抓捕、全NPC对白、独立工资和20分钟午餐、13:30步行返工及两天日程回归通过。正常主循环123.19FPS，聊天154.70FPS，无误抓。

八份最终验证日志无错误。全部34路径外部内容保留，world仅提交本轮空间索引改动，地图、美术、编辑器WIP未纳入提交。这是程序自测与制作人自验收，未宣称本轮包含真人体验验收。
