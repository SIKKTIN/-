# P54：按概念还原建筑体块

用户以 `art/concepts/prison-roof-v21/scene-concept-v21r2.png` 为目标，指出 P53 的禁闭室失去立体感、门墙衔接生硬。P54 使用主美 A24 原始建筑 PNG 和同源模块返修 R04，功能通过和视觉对照分别记录。

## 实际改动

- 禁闭室恢复完整矩形深灰屋顶、厚屋檐、檐下阴影、石墙基座、宽石门柱、窄钢门、通风口与门牌。旧独立门框/通风口保留对象 ID，隐藏重复绘制。
- 按概念的比例将顶面与立面分别投影为 189 / 109 世界单位。采样主美原图，不用程序矩形补画建筑。整个建筑占约 456 × 298；门脚按实际源图锚点对齐物理门。
- 禁闭门物理宽度由 160 收窄为 90，保留中心 x=400；两边围墙相应填齐，门口仍有大于角色直径的可通行空间。门外释放点、2 游戏小时关押、撬门/钥匙救援规则保持。
- CLOSED 立面、矩形屋顶保持固定；OPEN 只替换同一门口的局部。开门不会换屋顶纹理、改变轮廓或露出屋内人员。
- 食堂整体南移 30，门洞 180 × 90，顶厚 31.5。北墙由同源手绘左翼、右门柱、连续中段、末端角柱构成，门楣挂在实际门的绘制节点；墙脚与转角使用同源石材。不再把独立装饰摆设当作物理墙，也不把中段硬拉宽。
- 北墙表现直接读取实际 `world.walls` 的位置、尺寸、墙高；门楣直接读取实际门位置。纵墙在北墙柱脚下开始绘制，不遮盖新柱头。重复区域标签已取消。
- 新建筑 PNG 原始像素保持不变；A24 opaque-core shader 将实体核心变为不透明，保留真透明开口和轮廓。裁切先生成独立 mipmaps，延续原有平滑镜头方案。
- 新增的素材配套 v04 地图编辑器图标已导入并验证。旧地图无新配置时走原渲染路径。

## 源图配准

禁闭 CLOSED 原图中的 `[60,530,1430,343]` 立面绘到建筑局部 `[0,189,456,109]`；矩形屋顶原图的 `[54,93,1440,438]` 绘到 `[-1.913287,0,459.188811,189]`。整体偏移为 `[-1.342657,1.906706]`，使原图门底 y=867 对齐逻辑门底 y=298。

OPEN 原图 Atlas 内 `[808,467,277,305]` 绘到 `[257.655944,199.169096,88.330070,96.924198]`，门口约 90 × 97。源图、完整模块定义和主美配准建议见 `art/architecture/v24/manifest.json`、`assembly.json` 和 `docs/art/architecture-v24/projection-recommendation.json`。

完整建筑采用受控的美术模块比例。其 `building.render_size`、立面/屋顶区域和门锚点需要成组调整；普通墙的旧材质参数不用于重新拼接这栋完整建筑。画面按同一体块、比例和光影还原，石材裂纹和物件位置并非概念图的逐像素复制。

## 验证与实际图

最终功能验证共 345 / 345：无头建筑 47、原生 1200/1600/960 各 49、门禁与关押 73、编辑器 78。实际 GPU 输出检查了屋顶遮挡、开门屋顶像素不变、门禁开放通行、午夜与两小时释放、旧关卡兼容及图标加载。最终六组运行日志无脚本或 shader 错误，汇总为 `docs/tests/p54-summary.json`。

早期集成发现 shader 使用保留标识符 `source_color`，主美已修正并实际渲染验证。早期加载检查不作为最终 GPU 编译证据，最终原生日志已替换为修正后的运行结果。

视觉证据为 `docs/tests/p54-1200-concept-unobscured.png`、`p54-1200-concept-hud.png`、`p54-1200-open-unobscured.png`、`p54-1600-concept-unobscured.png`；可打开 [对照页](comparison.html) 同时查看概念和实际运行图。主美的最终对照审校见 `docs/art/architecture-v24/`，制作人验收以这组实际图为准。
