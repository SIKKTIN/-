# P48 · 时间表下方人物栏与无辜被困者背景

2026-10-06，制作人任务 `p48-hud-story-premise-20261006`。

用户要求人物栏固定在左上时间表正下方。三张卡左边与时钟对齐，上方间隔12画布单位，卡间8；1200×720高82，960×540高77，体力和饱腹条随高度内收。人物栏不再从摇杆位置推算，编辑摇杆位置不会移动人物栏。

背景正式更正为三位无辜普通人被小混混抓到封闭黑工厂强迫劳动，玩家合作带他们逃出去。房间、锁门、寝室、食堂、加工车间、午夜查点和缺员搜查保留，含义是非法拘禁场所；橙色服装作为被迫发放的工作服使用。看守为小混混，现有警犬称看门犬。内部 `guard` / `prison_*` 标识保留，显示文案已统一为看守、混混和厂区，未更改捕获/视线/碰撞/日程规则。

开局状态提示明确“我们是被抓来干活的无辜人”，暂停菜单注明“无辜被困 · 合作逃出黑工厂”。R04显示名称为“黑工厂生活区”，区域牌为“加工车间”。技能提示、昼夜日程、缺员警报、失败文案使用新背景。游戏目标仍为期限内三人一起逃出，默认三天。
