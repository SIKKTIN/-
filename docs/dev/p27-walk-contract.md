# P27 多帧走路接口与接入检查点

用户要求扩增移动动画。旧资源三伙伴/狱警各两帧，0.32秒一帧，完整周期0.64秒。本轮目标每人8帧/12fps，周期约0.667秒，增加真实姿态过渡，步频保持相近。

A07由主美制作与校验真实PNG，制作人P27维护播放/集成；资源修正期间独立准备和检查代码接口，正式进度与发布等待A07技术交付通过。资产接口为art/characters/manifest-v09.json：schema=1，actors数组固定actor_id=0/1/2/guard，walk_animation包含texture、fps=12和frames，每帧id、region=[x,y,w,h]、anchor=[脚底x,脚底y]。单角色统一画布、高度和脚底；可选scale_height为跨帧统一实际身体标尺。原manifest-v03及idle不改，友军60/狱警72世界高继续使用。

最终允许逐帧干净region和局部anchor不同，统一scale_height与世界脚底。共享大裁框会裁入邻帧时，优先像素隔离；不以裁框尺寸相同替代实际身体尺度稳定。

播放接入读取可选走路清单，按真实移动moved_this_frame推进实际delta秒数，以循环时间索引8帧，帧率独立于渲染速度。实际位移为0立刻idle，暂停冻结当前姿态，逃脱隐藏。水平翻转只影响人物身体，信息符号不镜像。换关/重开重新idle；旧v01/v02没有新数据时回退原两帧。PNG是表现资源，不改变位置、移动速度、碰撞和镜头。

资源验收检查不同姿态/左右脚交替、脚底与头身尺寸、循环接缝和旧idle切换。集成测试检查四人每个8帧完整循环、12fps计时在30/60/120Hz等价、零位移/暂停/逃脱、左右方向和旧资源回退；再用原生实际移动检查角色、守卫和跟随，昼夜及手机窗口尺度截图。只记录技术证据，不宣称真人或Android/iOS已测试。
