# P83 固定墙边碰撞

按用户认可的模式，将原有28高横向墙顶和20宽纵向墙边作为永久物理边界。RoofGeometry.wall_edge_clips统一供RetainedRoofWallEdges原材质绘制、世界碰撞与编辑器红色预览使用。只对真实、可见的模块墙片生成碰撞，共468个片段，门口缺口从固定墙碰撞中扣除，房间显隐不改变或重建墙碰撞。原墙脚阻挡继续保留。

门的实际阻挡采用与当前薄门样式一致的投影位置；开放时去掉该门的阻挡，关闭时在可见门处阻挡。寝室及禁闭室六个40/60长侧入口可以真实往返。钥匙、撬锁及内侧门闩的操作点随投影平移，并在加载时避开家具占位，关闭延期和只出不进规则使用同一门矩形。

普通家具过道保留半格寻路采样，窄侧门使用另一套以墙接缝为中心的缓存网格；按起终点选用，不可达时尝试另一网格。加载/重开时预热，开关门仅刷新相关格点。自由活动标记原来落在食堂北墙顶的点，在运行期解析到走廊一侧并缓存，必要联动增加daily_routine._target调用，未修改地图文件。

针对新增墙边使夜间回房路线绕行的情况，守卫的路径平滑改为依次验证连续可见转角，避免每个转角反复对迷宫最远端做长射线；囚徒保留原捷径平滑，保证用餐通勤时间。目标夜间追捕诊断中长路线查找由约72ms降至约10ms；不是所有场景帧率保证。原生60试跑平均约59.85FPS，P95帧间隔18.907ms、最大28.773ms。90试跑与新版可玩窗口启动重叠，存在资源争用，不作为稳定90的证据；未宣称逐帧锁60或90。完整数据见performance.json。

94项验收检查全部通过：46项实际墙边阻挡、两种空间索引、六侧门NPC移动、门禁、钥匙/撬锁、释放和60次房间切换缓存检查；14项编辑器材质/入口/红色碰撞预览检查；13项两日自动日程检查；21项监工和增援实体进出与主门开关检查。日程测试为免疫捕获的通勤场景，验证3人用餐各20分钟、13:30返工、无到点传送及只累计主角收入，不作为抓捕规则测试。实体追捕另用原生性能场景；玩家和巡查守卫均不能忽略固定墙边。

旧staff测试以x越过bounds作为离场判定，已适配当前北门staff_exterior/exit_area端点与完成步行到达的状态；已保留原有无传送、先车间后厂门、召回同一人员的断言。旧两日不免疫场景在改动前已有主角被抓及禁闭传送失败；通勤验收单独免疫捕获，未更改实际游戏捕获。

本次测试基于真实工作区，其他关卡/美术/玩法WIP保留。地图SHA与P83开工基线一致。提交隔离本任务变更；含必要墙瓦片碰撞、薄门操作点和门闩接入，其他共享源文件外部改动未整体提交，index-audit.json记录隔离方式。未宣称干净检出包含全部未交付美术/关卡素材。
