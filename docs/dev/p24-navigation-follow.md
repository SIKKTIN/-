# v0.8.1 连点寻路与跟随镜头

2026-10-05，用户反馈连续点击寻路卡顿，并要求选中伙伴后镜头跟随。P24由制作人维护核心程序，本轮不改素材、地图布局或project.godot用户本机改动。

原实现每个避让人物/监管区查询遍历整图7600余格，每格再扫描全部实体；长线段四单位逐点采样，路径平滑反复执行同一检查。新实现保留20单位寻路粒度和即时命令：两份静态AStarGrid分别保存友军可行区域与警卫监管边界，墙/门/摆设按局部占地栅格化。查询只临时覆盖箱子和他人附近格子，再恢复；典型56格。开门/重开重新构建静态网格，推箱只更新动态覆盖与实体版本，旧nav_dirty接口保留。静态碰撞/视线集合缓存，直接修改箱子位置也更新动态缓存。

直线检查改为连续圆形扫掠与矩形相交，保留圆角几何，检测长线段穿过薄墙；另检查伙伴圆形碰撞、警卫边界与旧图外置出口的接缝。被抓回重叠起点允许单调分离。路径继续从最远可安全到达的点开始，连续新指令不先倒退到格子中心；未增加延迟排队或修改移动速度。

选中人物启动跟随，摄像机以1-exp(-10*delta)平滑靠近其地面位置，并钳制地图边界。手指/鼠标按住主图输入期间暂停镜头更新，避免点击坐标在按下和松开间漂移。主图拖动、小地图查看、方向键/中键/空格拖动暂停跟随；重新选中任意伙伴（含当前伙伴）或定位按钮/F恢复。切人不取消其他人的命令；商店打开、失焦、暂停时不更新视野。小图仍固定全图，HUD固定，无鼠标边缘滚屏。
