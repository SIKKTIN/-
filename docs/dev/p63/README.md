# P63 批准概念的自然石墙接口替换

用户批准 approved-wall-junction-concept.png 并授权生成、替换原来的覆盖感接口。主美A30用批准图重绘V30普通砌块T，去除V29整片大T轮廓、密斑和45度肩部；以中央常规头石与两块纵石续接，保留原横墙、V27纵墙与外围L。

集成注册V30与v10图标；编辑白名单从T29移到T30，二级分类仍为建筑瓦片·T形连接。T29定义和图标保留给历史存图，旧ID在属性中保持原选择，不静默替换。R04两个T20资产ID换新，右节点整体镜像。逻辑尺寸132/136×80、stemx56、宽20/24、纵接口80不变。

第一轮actual发现横臂有效下沿较旧H低3世界单位。主美只重注册同一新PNG：bar源y278..438包括透明尾带，逻辑深24、可见约21；stem从y438续接。地图两厨房cap_cutouts由30.48调为27.48，保留原H底沿；外围L裁口仍30.48。像素源与原H均未涂改，未用全局shader调色。

目视复核实际左右runtime、960编辑器及独立T，对照批准概念：连续普通石块、清楚石缝、同墙厚的横顶与中央纵向支墙，横臂下沿与直墙衔接。新石块仍有细微色/石缝差异，不承诺概念图逐像素复制。

验证：两窗口1200×720/960×640各13项T几何与GPU内空、20项分类与真实卡片选放/新MeshTexture图标/历史T29兼容，独立20/24组件12项，共78项原生通过。门禁、禁闭、救援、全员逃脱73项通过。源地图除architecture之外逐值一致，原20项建筑PNG/manifest SHA保持。只对本轮改动做回归，没有重复全量建筑交互测试。

A30先独立美术验收；P63随后证据/本人程序自验收分别记录。用户既有project.godot改动未纳入。运行时与编辑器使用同一绘制与素材，无新模拟逻辑。
