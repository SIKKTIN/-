# P17 物品与双向商人

2026-10-05，用户授权执行。实例与背包沿用 P16。配置 `data/items/library.json`：旧零件买入3/卖出5，钥匙4/9，工具2/6。价格为首轮参数。

房间 `merchants` 配置中立固定 NPC 的 id/name/position/stock；重开清空并重建实例库存。`game.trade.try_buy/try_sell(actor_id, merchant_id, item_id)` 重新校验距离100、遮挡、角色、实例所有权、余额和格子，再同步提交。库存存实例 ID；转售和回购同一件物品保留 ID；卖价高于收购价。共享钱包不占格。

钥匙在门左操作点55单位内成功才消耗，立即开门。工具在同一范围启动时消耗、6秒完成；持续操作独立于个人技能，离开/移动/抓回会中断、门进度保留。已有操作时不允许再用道具浪费；已开门/过远/遮挡不消耗。

右侧背包点击选物品，再用/放下/交给另一伙伴；交接仍40单位且无遮挡。靠近地面物品和商人显示可点击提示，E执行鼠标所在提示或最近提示，持续技能优先停止。商店出售右侧所选物品，只出售当前伙伴的实例。模拟持续运行，切人/离开/抓回/离场/重开关闭。

商人和地面物品使用代码占位；A05 新资源 manifest 接口 `docs/art/inventory-assets-v07.json` 已可读取。暂未完成大地图/R03，留给 P18/P19。

测试：`tests/p17_trade_check.gd` / `docs/tests/p17-trade.json`，26项通过，含资金/容量拒绝、不复制、回购、价格回环亏损、钥匙/工具时长/中断和面板关闭。真实地图/巡逻策略另验。
