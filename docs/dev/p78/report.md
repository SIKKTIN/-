# P78 过门揭顶瞬间卡顿

已复现并修复进出房间导致的单帧停顿。原生 1200×720、D3D12、RTX 4050，同 R04 地图，在白天和夜间分别对车间、食堂、仓库做 5 轮进出（60 次跨门）。基线每次跨门触发全场静态地面/墙影重画，单帧中位约195–210ms，静态层重画中位171ms。

## 修改

- 房间可见性切换不再使静态地面失效。地面仍按真实障碍/门/箱子变化失效。
- 去掉切换时额外的全场 volume 遍历，沿用本帧后续的 presentation 同步；可见性逻辑仍即时改变，人物、UI、聊天和拾取信息不泄露。
- 静态墙体不再按每次可见性 revision 重算显隐；家具仍依赖当前可见房间。
- 真正需要重建静态地面时，Rect2 索引替代逐墙扫描全部对象，查找从平方复杂度降到线性。
- 室内家具软阴影在载入地图时准备相同几何，按房间成员分批保存渲染命令。跨门只切换批次显隐，不再裁剪多边形、三角化和重新提交整层命令。多个可见范围重叠时仍按任一当前范围显示；换图/摆设版本/边界变化重建，场景退出释放 RID。

## 证据

最终 12 组进出场景跨门帧中位11.20–13.17ms，最大14.12ms；静态地面重画60次→0次，家具阴影重画60次→0次。常规帧中位9.95ms。测试冻结AI以单独定位揭顶耗时，结果不代表整局始终固定帧率。

106项房间遮挡回归通过，200个碰撞点切换前后一致。昼夜8组屏幕与原版 SoftShadow 接口的逐字节对照，差异均为0；开门会正确刷新静态缓存，不重建家具阴影；重开仍有可用批次。合计117项检查通过。最终日志无脚本错误。
