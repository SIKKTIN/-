# v0.8.4 八帧走路动画

2026-10-05，用户要求扩增移动动画。主美A07制作四角色各8个不同姿态，制作人P27维护播放与主干接入。FINAL-WARM-01身份和旧idle保留，移动、碰撞、镜头及用户project.godot不改。

## 行为与资源

旧版每人walk_a/walk_b两帧，每0.32秒一帧。新版walk_0…walk_7，12fps，每帧约83ms，周期约0.667秒；旧周期0.64秒，步频相近。32姿态含两步的落脚、下沉、经过、抬脚。初稿第二步关系不清，主美用内置imagegen逐角色修正。原始及修正PNG、提示词、来源与SHA留存；生产只使用walk_v09/*_walk8_v09.png，draft为历史。

data/presentation/active.json显式启用manifest-v09.json；旧v01/v02继续两帧回退。按实际moved_this_frame推进循环时间，与渲染帧率分离；零位移立刻回旧idle，暂停冻结当前姿态，逃脱隐藏，换关/重开恢复idle。左右只镜像身体，编号、技能、选中与朝向提示保持世界方向。

按各帧干净region裁切后生成mipmap并缓存，各帧使用统一scale_height换算比例，anchor注册世界脚底。透明裁框可不同尺寸，人物实际比例不随裁框高变化。早期共享大框混入上一行鞋底，帽上产生碎片；改成单帧干净范围，检查32帧邻帧核心像素为0，正式接触图v09r3无碎片。角色高度波动1.44/3.38/3.28/3.13%，中位高度与旧idle一致。未通过复制旧帧、溶图或整人旋转冒充新增动作。
