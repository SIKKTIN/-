# P81 三类俯视门型与食堂入口

用户认可三类门概念后实装。自由通行口只保留薄金属端帽和门槛；食堂、车间、寝室与后勤联动门使用薄铁栅及状态指示；禁闭室、检修门与厂区主门使用带黄铜锁具的实心钢门。横门厚24、纵门厚20，保持原通道净宽、门碰撞与日程/钥匙/撬锁规则。当前R04有26个入口视图，8处旧的永久开启铁栅摆设也替换为自由通行端帽。没有新增可操控角色或改变逃脱规则。

食堂北门从旧100高的立面改为与墙顶对齐的薄层门体。屋顶入口只留40深的地面缺口，门开启后叶片收起，端帽留在墙端。门跨越横向/纵向入口时使用同一图集。旧非阻挡门楣从门口裁掉，避免横梁横穿缺口；固定墙边、屋顶整体范围与原墙材质保持。门状态文字与撬锁进度也对齐新的门体位置。门体按碰撞状态直接切换，未新增滑动动画。

新增RetainedDoorways，在加载时读取图集、记录节点和几何；房间显隐/守卫巡逻不重建门，只在障碍状态变化时刷新。编辑器调用同一入口几何及绘制器，并以真实薄门位置进行选取。门型目前由既有门禁类型映射，未新增手动双向开关或新的钥匙规则；已存在后勤内侧开闩、定时控制、钥匙和撬锁均维持原逻辑。

验证：37项原生门型/日程/实际移动/钥匙与撬锁/释放/保留节点检查、53项遮挡回归、9项原生编辑预览与选取检查、6项R01–R03兼容冒烟全部通过，共105项。120次进出房间门节点和绘制命令重建0次，200个碰撞采样一致。9张昼夜食堂/车间/禁闭室/检修门/自由口实际截图及编辑器截图见docs/tests/p81-*。

原生1200×720 D3D12 RTX4050，60模式六种巡逻/追捕/夜间场景，每场7秒，排除前1.5秒暖机；平均59.90–60.04FPS，P95帧间隔16.769–17.318ms，最长偶发36.625ms。仅寝室追捕、持续监工追捕、持续夜间追捕三场记录实际持续追捕帧，其余三场不宣称全程追捕。没有重测90模式及其他设备，不宣称每帧锁60。
