# P47 · 自定义摇杆与交互按键位置

2026-10-06。制作人程序与HUD集成任务 `p47-custom-mobile-layout-20261006`。按用户要求复用P46表现，加入位置编辑，不更改美术素材、角色控制和游戏规则。

## 使用

暂停按钮 → 按键布局。游戏暂停，拖动“移动摇杆、互动、技能、背包、换目标”五个框调整位置。保存后返回暂停菜单，继续行动即可使用。取消还原已保存布局；恢复默认先预览，点击保存才覆盖偏好。

默认互动键额外离安全区右边40、底边32画布单位，两个辅助键同步内收；摇杆底边内收12。伙伴栏仍竖排，移动摇杆不会搬动伙伴栏。

位置存入 `user://button-layout.cfg`，使用安全区内的归一化坐标，保留跨回合与游戏重新启动的布局。适配画面大小和手机安全区；拖动不能超出可编辑区域或覆盖固定HUD/其他按键。切换为较小屏幕后，若原布局无法避免遮挡，临时使用默认布局，保存的比例不丢失；切回原尺寸恢复。背包面板限制在屏幕内，提示条避让控制键。

编辑层在暂停菜单之上，遮罩拦截触屏/鼠标/游戏操作，触摸模拟鼠标不重复派发。只允许一个拖动指针，松手、取消触摸和失焦清理输入，尺寸变化终止旧拖动。保存失败仍停留预览，不误报成功。
