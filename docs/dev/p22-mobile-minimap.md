# P22 手机小地图与手势 / v0.7.2

2026-10-05。用户明确主要平台是手机，并否定P21边缘滚屏。本轮删除边缘滚动代码与当前说明，改为地图右上小地图。P21实现与报告保留为历史，不代表当前行为。

小地图按房间边界保持比例绘制实体、门、重箱、出口、地面货物、商人、友军和狱警，白框显示实际可见区域。点击/拖动小地图定位Camera2D，拖出小地图仍跟踪当前手指并钳制世界边界；定位伙伴和停止行动采用44逻辑单位高的按钮。旧小房间白框覆盖全图，相机固定。商店打开时小地图隐藏并阻断视野操作，关闭后恢复。

主地图轻点人物选中、轻点空地移动；单指拖动视野，与拖动小地图都不下人物命令。12逻辑单位区分轻点与拖动，抬手位移也复核；取消触摸不下令，额外手指不夺取主地图手势。Godot原生ScreenTouch/ScreenDrag处理世界手势，触摸模拟鼠标保留用于GUI；世界输入过滤模拟鼠标，避免重复执行。GUI优先，卡片与互动图标不会同时触发地面命令。桌面左键可预览同样手势，右键移动、中键/空格拖动、方向键与F仍兼容；不再依赖右键或键盘完成基本操作。

修复原有互动图标每帧先隐藏再显示而重置按下状态的问题：保持仍有效的按钮可见，只隐藏失效目标。实际触摸按下和抬起间刷新多个帧时，拾取、交易、聊天启停各触发一次。未更改技能、巡逻、容量、经济和房间布局。

## 验证

Godot 4.7.2 Windows原生D3D12窗口1280×720与960×540，小地图/触屏各38项全部通过；包括实际Input.parse_input_event ScreenTouch/ScreenDrag与触摸模拟鼠标、GUI派发、点击/拖动小地图、视野框、主图拖动、额外手指/取消/快速滑动、交互按住跨帧、两个旧关、持续人物命令，以及鼠标停在五个边缘位置不滚屏。截图已按两尺寸检查。

从P20原生GUI脚本派生P22回归脚本，保留历史报告；背包选择、交易买卖、交接、放下拾取、灯光、HUD、中键/F，两尺寸各22项通过。P18原相机/导航15项回归通过。本轮合计135项；大部分使用冻结玩法的GUI夹具，持续命令案例运行实际游戏帧。不当作完整v0.7通关重新验证或真人趣味性观察。
