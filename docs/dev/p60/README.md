# P60 单一建筑瓦片套装

用户要求移除多套没用的建筑瓦片并统一。新建地图素材库只开放当前R04石材组合：V24原横墙/门翼/柱楣，V27同源直纵/端面，V28专门完整L角；命名为“石墙 · 用途/方向/厚度”。保留完整禁闭建筑的开/闭两种状态。同材质的24/20截面是墙厚规格，左右是侧面方向，并非四套材质。

建筑可放置部件18个：横墙/门翼3，纵墙4，L角4，端面2，柱楣3，禁闭建筑2，明细authoring-set.json。旧V25角/端、V26整套、V27旧角、原图参考、辅助屋顶覆盖片和旧尾柱退出所有素材分类及属性面板的新选项。二级菜单自动去掉空类型。配套图标沿用，名称/素材ID搜索继续兼容。

旧交付原图与注册定义仍用于已保存地图的引用加载。旧对象被选中时，属性面板仅额外保留其原ID并标记“旧地图引用”，不会默默切换为第一项；其他已退出部件不重新出现。此轮清理的是当前编辑器的可用套装，未擦除冻结历史、破坏旧草稿或重画场景。

原生1200×720和960×640各15项通过：只4个新L角、统一建筑18部件、所有分类和属性排除旧套装、旧地图当前ID保持且纹理仍可加载、二级/搜索/真鼠标卡片匹配放置与撤销/锁层、R04源SHA不变，共30项。实际图p60-{1200,960}-corners.png和报告p60-{1200,960}-native.json位于docs/tests。原地图、玩法、资产和用户project.godot修改保持。
