# P105：门洞与墙体碰撞对齐

侧门旧可见高度为 96，扣除两端门框和角色 68 高的投影身体后，脚部可穿过的竖向范围只有约 12。绘制开口也没有切除原地图上重叠的侧墙碰撞。现在侧门向上扩到 128，底边仍止于本房间横墙；开放区与门框全身判定、墙体裁切使用同一门洞矩形。普通移动仍使用半径 8 的脚部碰撞，门洞额外检查 36×68 的全身投影，头部与鞋子不能穿过门框，关闭门扇继续阻挡。

模块墙过去常只定义底部 20 高的碰撞，允许玩家进入其上方 100 高的可见墙面。现在具有实体碰撞的可见模块墙使用完整墙体矩形，并减去真实门洞。无碰撞的装饰门楣保持通畅。移动、扫掠检查及两套寻路格使用统一墙体；旧房间的非模块墙规则保持兼容。
