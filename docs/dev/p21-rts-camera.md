# P21 RTS相机补充 / v0.7.1

2026-10-05。根据用户反馈补齐地图窗口的RTS视野操作，不更改房间、角色速度、技能、经济或巡逻规则。

鼠标进入地图窗口内侧24单位边缘自动滚屏，四角斜向移动；方向键平移，速度520世界单位/秒，斜向归一化。保留中键与空格+左键拖动、F定位。Camera2D只改变视野；HUD固定，独立人物命令继续，右键从当前画面逆变换为世界坐标。视野钳制于地图边界，旧小房间保持固定画面。

窗口失焦、商店打开、拖动中停止自动滚屏；左/右键按住或悬停互动控件时暂停鼠标边缘滚动。鼠标在边栏、地图外或中央不会触发边缘滚动。方向键按事件消耗，避免同时移动GUI焦点。
