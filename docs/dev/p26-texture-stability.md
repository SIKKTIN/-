# v0.8.3 栏杆与静态世界贴图的移动闪烁

2026-10-05。用户复测P25仍有问题，并澄清「有明显闪烁，抖动现象，特别是铁栏杆最明显」。本轮转向静态纹理缩小采样，对照中复现了亮度随分数像素平移波动的原因，不把镜头数学通过等同于解决所有画面问题。

## 实现

栏杆源区域1643×585，实际两种绘制宽度151.10/98.72单位，原PNG导入不生成mipmap，原线性滤波仍会跳过大量源细节。WorldTexture对静态环境和摆设先截出清单区域，再生成缩小预滤波层，避免图集相邻内容混入；按路径及区域缓存，六个栏杆实例和再次换关复用。WorldVolume与地板启用LINEAR_WITH_MIPMAPS_ANISOTROPIC，改善不同轴缩放比例的采样。

PNG与导入设置保持原样，运行时生成纹理；绘制尺寸、脚底注册、碰撞和遮挡不变。角色、图标原纹理没有mipmap，继续原线性采样。P25平滑相机、跟随顺序和按住轻点规则保留。本轮没有相机取整、关跟随、限帧、改变显示后端或替换美术。静态微小细节稍柔和是稳定采样的代价，初次载入生成缩小层，后续重用缓存。生成失败回退到原区域纹理。

## 证据

`p26-bar-sampling.json/.png`：原生GPU渲染两种真实栏杆尺寸，分别测试1与0.75屏幕比例，每组17次对角分数像素平移。隔离栏杆、冻结游戏，无地板/光源变化；亮度跨度分别150.247→19.111、108.916→10.773、139.938→16.138、77.044→2.374，降低87%～97%；列亮度时间二阶差降低86%～92%。四组均满足两个指标降至原来的40%以下。图片每行左原线性、右裁切mipmap，正常截图已人工检查构图与栏杆可辨性。指标仅表示这个受控采样夹具的改善，不量化完整游戏、物理显示或真人感受。

`p26-native-follow-1280x720.json`及`960x540.json`：各31项真实原生帧检查通过，合计62项。持续游戏/警卫下执行30右键及30跨帧触屏移动，覆盖按住轻点继续跟随、切人/独立命令、主图拖动、小地图、定位、边界和当前帧互动图标。附加区域尺寸、mipmap、缓存复用与生产滤波检查。最后冻结同一场景对照昼夜帧缓冲，夜/昼亮度约0.667；10盏阴影灯、18遮挡器与警卫手电阴影保留。昼夜PNG均检查。

`p26-frame-pacing-d3d12.json/.png`仅诊断：最终代码D3D12/Forward+，165Hz屏且VSYNC已开，180帧无上限P95约9.95ms，55fps约19.20ms；改变帧节奏未能证明消除栏杆采样混叠，生产不限帧且保留原VSYNC。用户澄清后不继续原先假设的Vulkan/Compatibility实验，不声称这些后端通过或需要切换。

初版采样夹具用Control，位置会被GUI取整，且拼图因图像格式不一致报错；改成实际世界同类Node2D绘制并统一拼图格式后重新运行，最终证据来自修正后的无错误版本。

源与证据哈希见`p26-build.json`。未确认用户屏幕观感，也未Android/iOS真机验证；仍有闪烁需按具体场景继续定位。用户原先未提交的project.godot配置保留，不纳入提交。
