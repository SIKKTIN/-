# v0.10 多天逃脱与午夜锁寝

2026-10-05，P35制作人程序任务。按用户要求将单日22点封监改为多天期限、20–24寝室区自由活动、午夜门锁住但可继续操作或跳过夜晚。

## 当前规则

默认第1天08:00开始，到第4天08:00共72虚拟小时；开发设置可改1–10天。一天24小时，1×压缩为180/180/240/300现实秒（R01–R04）。默认三天总540/540/720/900秒。日期按午夜增加，HUD显示日期、每日时间轴、剩余虚拟天/小时。期限耗尽才失败，午夜不失败。

日程每天循环：08–12劳动、12–14吃饭休息、14–18劳动、18–20自由活动、20–24寝室区自由、00–08睡觉查寝。18点警犬出动，20点夜间灯光、商人收摊、室外155距离360度警戒。20点对室外伙伴下达普通归寝命令，左侧公共寝区内不要求留在本人牢房；玩家可覆盖命令，堵路不会传送。

午夜再次引导未休息伙伴回本人home，同时R04三间寝室门实体上锁。新增rect=[266,350/640/930,120,12]与原铁栏缺口对齐。人物寻路与圆形碰撞阻挡，铁栏门允许视线通过。玩家仍可选人、在门内行动和使用现有操作。警卫持钥匙，距门中心85单位以内打开、远离关闭，行走遵守实际门状态；其规划使用独立查寝网格可安排将来开门的路线，而移动时不忽略闭门碰撞。

查寝路线为三个休息位旁65单位，避开睡者身体；扩展移动/搜索权限到地图bounds，墙、柜与箱仍遮挡，夜155范围保持。未逃出的伙伴在本人寝室home休息位28单位内且无移动命令、idle时自动睡觉，Zz和卡片显示；睡者不被狱警发现，移动/操作立即醒来。警犬始终限制在原室外监管区。08点门打开、搜索权限回原安全区规则；房内警卫可沿物理通路退出，返程不发现安全区伙伴。

全部未逃出者休息后，左上或日程面板的跳夜按钮可用；不符合条件则禁用并在方法再次检查。跳夜只修改clock_elapsed到08点，elapsed/动作计时不跳，人物不传送；钱包、物品、商店库存、出口锁、箱、技能和已逃出伙伴保留。到最后期限的早晨仍按正常超时结算，不延长期限。即使0×时钟暂停，玩家也能主动跳夜。

R01–R03是旧共享起始区域，没有额外三间牢房门。午夜守卫使用现有物理通路去检查，主出口锁不会因查房自动解锁；开锁/推箱条件仍生效。午夜新增实体门完整实现重点是R04。白天劳动/吃饭仍为阶段与普通巡视，没有新劳动/食堂岗位AI。
