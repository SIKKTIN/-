## 打开与操作

Godot重新打开工程后，点击顶部“关卡编辑”。需要较大的制作空间时，可开启Godot专注模式，或运行独立编辑窗口：

```powershell
& 'E:\Project\Godot\这次怎么逃\scripts\editor\open_editor.ps1'
```

左侧选择工具或地图对象，中间编辑布局，右侧调整属性。地图对象列表点击即可定位。

- 选择工具：左键选择、拖动位置；右侧输入X/Y、宽高。
- 墙工具：左键拖出墙体；摆设、巡逻点、门岗、商人、物品、区域和日常点：点击放置。
- 鼠标滚轮缩放；中键或空格+左键拖动视野；F或“全图”恢复总览。20格吸附可以关闭。
- 复制、删除和Ctrl+D/Delete；Ctrl+Z撤销、Ctrl+Y或Ctrl+Shift+Z重做；Ctrl+S保存。
- 巡逻点前移/后移调整路线顺序；摆设可以切换样式及移动/视线碰撞。
- 伙伴出生点与寝室范围固定对应伙伴1/2/3，可移动与调整大小；寝室门可调整归属。主锁门、推箱、出口和看守范围从对象列表选择修改。
- “检查地图”报告越界、非法尺寸、被阻挡的出生点、重复ID、寝室归属和操作点提示；提示不证明一定可通关。

## 保存与试玩

修改默认保留在内存。保存会验证并写回 `data/rooms/<id>.json`，更新已有文件前写 `.bak`。发现磁盘文件被其他人改过会拒绝覆盖，允许重读或另存为。切图和关闭独立窗口会确认未保存修改；Godot关闭通过EditorPlugin的未保存提示与外部资源保存回调处理。禁用/重载插件时另留一份 `user://map-editor-preview-*.json` 恢复草稿，可手动拷贝进地图目录后打开。

另存为使用新的小写字母、数字或下划线文件名，文件名成为地图ID；不会覆盖已存在的另一张地图。另存成功后清空原地图撤销历史，避免旧记录把旧ID恢复进新文件。正常保存保留当前撤销历史。

“试玩草稿”不要求先保存，会把当前草稿写成临时JSON，启动真实 `main.tscn`。F10、“返回编辑”或关闭试玩窗口返回编辑；草稿、选中对象和撤销记录保留，临时副本清理。试玩仍有晨间安排、技能、寻路、日程、看守与物品逻辑。返回按钮在日常表等模态面板打开时隐藏，F10始终可返回。试玩使用独立开发设置/按键布局文件。

新另存地图可从编辑器立即试玩。正式游戏的关卡选择仍保留R01–R04；将新关卡加入正式关卡列表属于后续发布配置。

## 数据与兼容

`map_document.gd` 保留原地图所有未暴露字段。地图4原来位于全局日程配置的三间寝室范围，在编辑数据中合并为地图自身的 `dormitories` 数组，保存时一同写入；运行时优先使用地图自身范围，旧地图继续使用全局配置与原回退。原R04未被制作或测试改写。

摆设尺寸与碰撞优先继承当前地图中同类摆设，缺少模板时读取已验收素材定义。餐盘保持不阻挡移动；带绝对 `draw_depth` 的桌面摆设移动、复制和放置时同步调整绘制深度。商人营业位置移动时，原营业及过渡点同步移动，工作/休息位置保留。

第一版复用已有美术，采用地图布局与规则点显示，不模拟正式游戏的灯光和地板透视效果。工作点/取餐点/用餐点/活动点可以新增、移动与删除；更深层的商人时间表、餐厅标牌和新技能逻辑仍由原数据文件控制。现有主门规则数量保持不变。

Godot插件关闭与保存接口依据[官方EditorPlugin文档](https://docs.godotengine.org/en/stable/classes/class_editorplugin.html#class-editorplugin-private-method-get-unsaved-status)。测试与实际试玩使用CLI，未使用MCP修改场景。
