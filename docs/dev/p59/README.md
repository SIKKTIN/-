# P59 编辑器素材二级分类

用户指出建筑瓦片混在家具/设施长列表难找。主分类保持，增加二级用途菜单：家具摆设、建筑瓦片（横墙、纵墙、转角、端面、门柱/门楣、压顶）、完整建筑、门窗/门禁、墙面设施等。食堂按取餐/回收、餐盘和围栏细分，规则按巡逻路线和日常活动细分。

默认家具/设施仅显示家具摆设；切换主分类记住上次二级选择。搜索在当前二级分类匹配名称或素材ID，选择全部类型可搜索整个主分类，结果数和空结果提示可见。建筑瓦片分类将现有较新资源排在前，原图标沿用，素材ID/图层锁定/放置和撤销保持。旧资产没有隐藏或删除，地图数据和项目配置均未改。

原生1200×720与960×640验证，每尺寸10项：默认无建筑污染、完整L四个资源可找到、转角中无家具、搜索ID得到4个v28、真实鼠标点击匹配asset_id、放置与撤销、分类记忆、空结果提示、图层锁定、原地图SHA不变，共20项通过。截图docs/tests/p59-{1200,960}-{furniture,corners,search}.png及报告p59-{1200,960}-native.json。
