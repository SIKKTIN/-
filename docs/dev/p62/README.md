# P62 T形墙体连接

厨房两条内部纵墙与贯通横墙交会，使用L转角会丢失另一侧横臂。新增主美A29完整向下T素材20/24两种厚度及独立编辑图标，注册为家具/设施下的建筑瓦片·T形连接二级分类。保持统一石墙套装，旧定义兼容。

R04北墙8的两个厨房接点改为T20：左offset114,6.48；右754,6.48并镜像；尺寸132×80，stem x56，世界纵墙1270/1910精准相接。对应压顶裁去132×30.48，墙身仅保留既有stem20空隙，其他横墙身/外侧L/门柱/纵墙源与周期原样保留。没有修改物理墙、门禁、日程或家具布局。

新T瓦片放置显式写render_size，保留132/136×80，避免通用摆设默认立面高度额外拉伸。

验证：1200×720与960×640各13项T原生GPU对照、20项分类与卡片选放、15项建筑操作，共96/96；两规格游戏独立组件GPU对照12/12（精确尺寸、双横臂、stem、双内空）；单次门禁/禁闭/救援/全员逃脱73/73。T移除前后同画面对照：左右横臂及中央纵臂都绘制，两内凹空区不填；runtime/editor实际截图一致。物理字段逐值相等，旧18项建筑PNG/manifest SHA保持。主美复核actual后独立A29验收，P62分别提交证据/本人程序自验收。

本轮只提供向下T20/24，编辑图标也显示该方向。未增加其他旋转形态。实际放大图中的两端石缝为模块接口，内部两转折属于同一新生成T主图。
