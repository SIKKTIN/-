已登记的 14 套人物原始 PNG 全部位于项目 `art/characters/`，共 126 个站立/行走姿势、17,147,047 字节。三张概念图保留在 `docs/art/factory-cast-v47/`、`factory-occupations-v48/` 和 `factory-antagonists-v49/`。原图哈希及姿势区域检查通过。最新四人反派概念仍为审评稿，没有提前替换现有角色。

人物库入口集中于 `data/presentation/character_libraries.json`，使用和保存方式见 `art/characters/README.md`。

## 加载优化

- 每种形象按需准备站立与行走纹理，同一形象的多个角色和编辑器缩略图共用缓存。
- 每张人物图批量取帧时读取和解码一次源图，保留帧纹理后释放整图资源。
- 站立姿势使用对应帧纹理，避免仅为一帧而持续保留整张大图。姿势区域、脚底锚点、镜像和显示比例保持原规则。
- 站立帧沿用原有清晰过滤，行走帧沿用原有裁切 mipmap，避免优化后的小尺寸人物变糊。
- 原始 PNG、透明背景和导入尺寸没有修改。

`before.json` 中全 14 种形象的站立纹理原始 RGBA 面积为 88,060,896 字节；取对应姿势后为 5,075,048 字节。这是站立纹理面积比较，不是整个游戏的实际内存测量，未计 mipmap，也不包含行走、环境或 UI 纹理。

## 审评资源隔离

新增 `docs/.gdignore`，停止将历史截图、概念图和预览工程作为正式游戏资源导入。原有运行时需要的四个 JSON 清单以原字节复制到 `data/presentation/`，并更新 v01/v02/v03 与物品展示的读取路径；正式脚本和配置已不再从 `res://docs/` 加载游戏资源。

原始图片、历史审评资料和旧配置兼容文件仍在项目。没有按文件名中的版本号批量删除素材。

导入缓存审计识别到 712,647,767 字节的文档资源派生缓存。批量删除请求被工具自动审批以“blocked by policy”拦截，未执行删除，旧缓存暂时保留；审评资源已排除出后续导入。
