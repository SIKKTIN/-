# P95 教程对话与任务提示

按用户确认的概念图区分交谈和行动：

- 教官、监工、商人讲话时隐藏底部任务板。气泡内直接点击：打字中先显示全文，再次点击进入下一句；末句继续原有教程流程。姓名、小色点、分隔线、页码和继续提示都位于气泡中，尾巴指向现场角色。
- 行动时显示 400×48 的单行任务提示和定位按钮；等待演员或观察演出时只显示简短状态。隐藏旧的大标题、重复说明和继续按钮。完整任务描述保留在工具提示，演出与完成条件保持原有逻辑。
- 时间区显示“第1天 · 入监日 1/6”等章节进度，正式日恢复原有日期说明。
- “跳过教程”移至暂停菜单中教程重玩的位置。跳过时关闭菜单并继续原有过夜演出；正式日恢复“重玩教程”。暂停、背包交易、普通对话等覆盖界面隐藏教程提示。
- 临时通知避开任务条。气泡文字高度按整句计算，结果按台词与宽度缓存，打字时不反复计算换行。

验证：

1. `qa/p95_tutorial_ui.gd`：完整入监日流程，改为通过气泡的 pressed 回调推进。29 项流程检查全部通过；15 次现场讲话、43 句台词在 1200×720 和 960×540 下共 86 项布局检查通过。包含真实工资、午餐、监管恢复、门禁、教官行走与第2天清理。
2. `qa/p95_dialogue_input.gd`：原生 D3D12 窗口，向 Viewport 注入鼠标事件，并使用 Input 的触摸事件/原生鼠标模拟。验证先显全文、单句推进、点击穿透、章节文本、两分辨率任务布局、暂停与恢复、定位、跳过及正式日恢复。
3. `docs/tests/p95-tutorial-headless.json`、`p95-dialogue-input.json` 和 p95 系列 PNG 为对应检查结果。UI 截图使用受控模拟，隐藏帧率标签；实机主场景另行启动确认。

`approved-concept.png` 为本次确认的 UI 概念参考；游戏场景和右下已有操作按钮保留当前实装样式。
