# 监控室美术设计方案

监控室按总地图概念改为紧凑的安保控制间：北侧两排监视屏与操作台构成视觉中心，右侧录像设备柜形成第二功能区，入口到操作位保持清晰通道。最终效果见 [概念图](concept-final.png)。

## 空间和建筑样式

改造前监控室区域标注为380×640世界单位，主要摆设为监控台、文件柜和公告板，纵向空地较多。已保留房间宽度和北侧位置，将室内可见净空收紧至380×420。人物维持现有1.4倍、约84单位高。可见区域数据为 `[4780,460,380,500]`，其中南侧包含墙体投影；墙体、门、地面与屋顶已同步校准。

建筑采用浅冷灰墙面、灰蓝金属护墙、深灰踢脚及窄钢压顶，转角用连续的方形金属包边。门采用灰蓝安保钢门、小观察窗和侧边门禁盒，门口悬挂“监控室”小牌。地面采用低反光灰绿小方砖，磨损集中在操作台前、椅子脚边与门口。

屏幕保持低亮度冷蓝灰，灯点用少量红、绿、琥珀色。灰蓝护墙与金属包边形成房间识别，屏幕不把整间房染成蓝光。表面保留旧漆、边角锈迹与使用痕迹，避免大量砂点底纹。

## 最终布局

| 位置 | 布置 | 比例和通行要求 |
|---|---|---|
| 北侧偏左 | 2排×4列，共8个厚边框监视屏 | 屏墙宽约250至260，保持横向阵列；画面显示走廊、放风院和装卸场，其中1屏待机 |
| 屏墙下方 | 1张金属操作台 | 宽约250至260、接地深度约60至70；键盘、按钮、电话与记录纸集中在台面 |
| 操作台前 | 1把旧操作椅 | 约42至48宽；留出人物接近台面的操作位置 |
| 东北侧 | 1座录像及配电设备柜 | 宽约50至60、脚底深度约45；柜前维护空间与屏墙前通道连通 |
| 西侧下段 | 1只低文件柜及小夹板 | 复用已有文件柜，纸张集中收纳；不形成高柜长墙 |
| 东南侧 | 1张小记录桌、台灯和日志 | 靠墙布置，沿东墙纵向放置；约65宽、90长，避开门口 |
| 南侧中央 | 1扇安保钢门及门禁盒 | 门洞目标净宽140至160，门扇开启后保留完整通路 |
| 中央 | 通道和看守站立位 | 主通道约100至120，入口不摆椅子；人物作为概念图尺度参考 |

屏墙和操作台靠北集中摆放，设备柜利用右侧余量。概念图中看守沿用已有看守形象；后续可给监控室安排独立值守点，不移动值班室已有看守。南北缩短后腾出的区域接回园区铺装步道，与办公室和装卸场边界协调。

## 接入方案

1. **记录地图当前状态。** 在实际制作开始时读取最新保存地图，核对监控室墙面、门图形、门洞和碰撞范围。保留办公室、值班室、装卸场及用户其他修改。
2. **校准净空。** 固定北侧及左右建筑位置，缩短南北长度，统一更新地面、房间区域、墙线、门及屋顶覆盖范围。按门内线校准净空，不仅修改区域矩形。
3. **登记新素材。** 每件记录原图尺寸、显示尺寸、接地范围、脚底锚点、排序高度和碰撞。保持长宽比例，并接入游戏与地图编辑器共用目录。
4. **重排室内摆设。** 替换旧监控台，移走北墙大公告板，文件柜靠西；加入设备柜、操作椅和记录桌。小物随所属台面排序。
5. **接入门和屋顶。** 保留 `monitor-entry` 的安保门语义，校准开关显示及锁门碰撞；更新专用屋顶，检查进屋淡出、出屋恢复以及角部遮挡。
6. **校验通行与运行效果。** 检查门口双向通行、操作台前站立、设备柜维护点、值守点可达和人物遮挡。交付游戏近景、全园区对比、屋顶关闭状态及编辑器截图。

8块屏幕首先采用静态画面与少量状态灯，显示内容可用有限帧切换；不为每块屏幕创建实时摄像机。地面、护墙和台面小物使用已有静态缓存。运行时纹理沿用尺寸上限及mipmap流程，原始PNG保留。

## 验收标准

- 房间接近方形，屏墙、操作台与设备柜能在正常镜头下一眼辨认。
- 北墙8屏为两排四列，屏幕亮度低，不覆盖人物和操作台细节。
- 灰蓝护墙、窄金属压顶和四向转角统一，没有错台、断缝或旧厚墙片残留。
- 门口和中央通道顺畅，无旧监控台、公告板或门框留下的隐形碰撞。
- 桌、椅、文件柜、屏墙、机柜和屋顶可在编辑器内独立选择、移动及删除。
- 保留监控室原有安保门行为；屏幕交互、录像检索、关闭摄像头等玩法另行设计。

新增监控值守看守，沿用现有 `patrol_guard` 人物及动画。保留值班室、医务室、放风院和办公室最新地图调整。桌椅、屏墙、设备柜、门和墙体素材已进入地图编辑器，监控室屋顶样式可以在房间属性中选择。
