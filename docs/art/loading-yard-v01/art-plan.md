# 仓库东侧装卸场美术方案

日期：2026-10-12。阶段：美术设计与整体概念图修订。版本：v09，将正确侧门方向应用到装卸场整体。

将用户红框内的仓库东侧区域设计为狭长的室外装卸场：北端物流门岗、东侧货车停车位、西侧装卸暂存区、南段集中堆货，中部内部通道贯通。南端通向监狱外部，必须由闭合铁门封住；北端物流门和两处仓库侧门也以关闭状态展示。最新整体效果见 [概念图v09](concept-final-v09.png)：两处侧门改为沿纵向墙体的蓝灰窄顶边与两端门框，删除正对屏幕的蓝色立面。侧门关闭和开启关系参考 [v08方向示意](door-orientation-v08.png)。v07方向错误，不作为接入依据。当前交付为概念图，没有修改地图与游戏。

## 现状和范围

当前地图中，装卸活动区为 `[5140,220,640,3420]`，地面铺装为 `[5120,200,680,4000]`；南侧较长的铺装还承担后勤通道衔接。室内仓库位于西侧，区域为 `[4340,1360,760,2160]`。当前场景已有货车、门岗、托盘、箱堆及看守，可用作尺寸和功能基准。

改造范围以红框中的室外区域为准。西侧仓库墙面补双面装卸门收口和场地标识；保留室内仓库布局及周边已完成的监控室、办公室。北端物流出口、东侧外围边界、南端对外封闭出口作为布局锚点。此前将南端理解为开放后勤连接有误，此版以用户指出的监狱外部边界为准。概念图用于确认构图、材质和摆设关系，接入时按最新地图坐标校准。

## 美术方向

采用现有游戏的俯视手绘工业风格，建筑保持横竖对齐；用灰米色磨损混凝土、褪色交通黄、旧灰蓝车体、棕色木箱和外围橄榄绿植物形成识别。人物复用现有大头短身比例，接地高度约84世界单位。

地面突出室外装卸使用痕迹：大块混凝土板缝、少量裂缝、轮胎磨痕、车位边缘的局部油污。大面积地面保持安静，避免细密噪点覆盖整个场地。植物集中在外围墙外和边角缝隙。箱堆按货物组团摆放，留出装卸操作空间。

装卸场没有整片屋顶。门岗亭单独配屋顶与低矮排风细节；货车篷布是车体的一部分。外围墙、入口和地面使用同一套光向与阴影尺度。

| 区域 | 设计内容 | 通行与尺度 |
|---|---|---|

| 东侧上中段 | 1辆旧篷布货车，车头朝南；地面画褪色黄色停车框 | 车辆显示宽约170–190、长约420–500；最终按原图比例与现场净空校准 |
| 西侧仓库侧门附近 | 两处食堂同系列材质的闭合蓝灰钢门；木箱托盘、空托盘及搬运车集中在门旁 | 门扇沿纵向墙体关闭，左右通行；两侧接近区域清空 |
| 南段东侧 | 2–3组高低错落的木箱货垛 | 靠边集中摆放，避免与车道、巡逻通道交叉 |
| 南段西侧 | 少量暂存箱与空托盘 | 与东侧箱堆错位，保持通向南端门内的连贯净空 |
| 中部纵向通道 | 褪色黄色虚线、装卸边界线与少量排水盖 | 主通道目标净宽220–260，侧门接近通道约120–160；必要时减少箱堆 |
| 东侧外围 | 连续外围墙、墙外草木、墙脚少量杂草 | 维持不可越界范围；不在墙内铺满绿化 |
| 南端对外出口 | 闭合双扇铁栅门、两侧门柱、中央锁扣与警示条 | 门横跨完整路口并接齐围墙；默认不可通行，柱边不留绕行缝隙 |

中央行走线、车辆停靠线与货物暂存区分别表达。黄色虚线只作场地标线；概念稿中的青色逃脱箭头不绘入环境资源。概念人物用于尺度展示，新增NPC数量不由这张图决定。

### 双面侧门的表现

食堂参考用于蓝灰钢门材质、窄金属框和简洁墙体收口；不能据此把侧门立面改成正对屏幕。此处墙体沿南北方向，通行方向为东西，即屏幕左右。关闭门扇所在平面必须沿南北方向与墙体一致，在固定斜俯视镜头下主要看到侧面与蓝灰顶边。门框端头和门槛位于真正的墙体断口，两侧都保留接近区域与识别线索。

门框位于墙体断口，米色压顶在两端停止；门框与墙面整齐连接。双侧门槛等宽，框架收口平衡。关闭时门扇贯穿断口；开启时门扇围绕北端合页旋转，示意向西侧开启90度，门洞获得左右通路。开启后才可能看到较宽的门面，镜头不随门旋转。此开启方向用于方向说明，实际铰接端及开启侧须按地图内外净空校准。门是一个整体，两侧共用门状态和资源，不另创建不同方向的重复门对象。

每个门洞使用一套共享资源及一个门状态。关闭时完整蓝灰门扇阻挡门洞；开启形态另行绘制，保留共用门框和双侧门槛。沿原地图门洞校准显示长宽与接地范围，不因概念图局部比例变化而擅自移动入口。用户给出的食堂概念图是本次外观依据；仓库新资源须在登记时复核，不能仅凭名称使用外观不相同的旧食堂栅栏门素材。

### 不可见区域下的门

门是相邻区域共用的边界建筑，不归属于某一侧的场地摆设。当任一相邻区域可见并能看到此门时，绘制整套共用门主体与门框；另一侧场地从门模块外缘开始被迷雾遮住。门模块边界须限定在门框及小门槛范围内，不能露出对侧货物、人物、地面路线或其他活动。

这种表示让玩家从左或右辨认相同的门洞与关闭状态，不能为了辨识而把完整立面正对屏幕。门状态、交互与碰撞两侧共享；禁止给内外两面创建重复门对象。v08是生成式空间方向示意，并非最终游戏美术、运行时截图或逐像素遮挡测试；实际接入后分别验证左右遮挡边界和正常游戏缩放下的可读性。

|---|---|---|

| 黄色停车及装卸标线 | 直线、虚线、转角、斜纹端头 | 制作可组合透明模块，或使用现有静态绘制方式；布局保持可编辑 |
| 旧篷布货车 | 1辆，车头朝南 | 以 `cargo_truck_v43` 为功能基准，新绘更接近概念的车体；篷布、驾驶室、车轮与阴影清楚分层 |
| 木箱货垛 | 3组高低变化，另加单箱1–2种 | 优先复核 `shipping_crates_v44` 和 `cargo_pallet_v43`，补紧凑组合；避免所有货垛同形 |

| 手动托盘搬运车 | 1件 | 复用并校准 `pallet_jack_v44`，放在货垛旁 |
| 桶装/袋装货物 | 少量 | 复用 `oil_drums_v44`、`sack_pallet_v44`；控制数量 |
| 门岗亭 | 亭体、独立屋顶 | 复核 `guard_booth_v43`；按概念补灰蓝墙面、窄窗和屋顶，分别登记 |
| 北端物流门及门柱 | 开/关形态、警示柱 | 默认关闭，视觉与门岗统一，柱脚不侵入净宽 |
| 南端对外铁栅门 | 关闭形态、开启形态、左右门柱与锁扣 | 新补边界出口资源，默认闭合；关闭态完整阻挡路口 |
| 仓库食堂材质侧门 | 共用蓝灰钢门、窄钢框和双侧门槛；沿墙关闭/绕合页开启形态 | 两处复用同一套资源；侧门朝向正确，两侧都能通过框、顶边及门槛识别 |
| 标牌与时钟 | “物流出口”“装卸场”、圆形时钟 | 标牌保持正常缩放可读，不做大面积地面文字；独立小装饰资源 |
| 排水盖与使用痕迹 | 排水盖1–2件、轮胎/油污贴花2–3种 | 独立透明PNG，无碰撞，局部使用 |
| 外围墙及植物 | 按实际边界 | 优先复用现有园区资源，只补端头和收口 |
| 看守及工人 | 使用现有角色 | 复用既有人物；不另做一套人物风格 |

所有新资源交付原始PNG：道具保留透明背景，地面可平铺；逐件记录源图尺寸、显示尺寸、接地锚点、排序高度和碰撞范围。最终概念图是设计参考，不能裁成一张覆盖场地的背景来代替可编辑资源。

## 接入方案

1. 制作开始时读取最新已保存地图，备份并核对用户编辑。锁定北端物流出口、西侧两处仓库侧门、东侧边界和南端对外出口。按用户要求核对所有路口的封闭状态，不能把南端当成无门开放道路。
2. 先换室外地面，划分停车位、货物暂存区和主通道；车辆及人物在原有尺度下检查净空。
3. 登记新货车和箱堆，再分组重排原有货物。保留可翻找对象及其物品数据，避免替换视觉时丢失交互。
4. 校准货车、货物和门岗的接地碰撞。车辆按实体车体阻挡；阴影、黄线、油污和墙牌不增加碰撞。箱堆组合有空隙时，碰撞跟随实物形状。
5. 门柱、双面侧门端头及外围转角逐一对齐，检查压顶、墙面与阴影接缝。侧门两面共享开关状态与实体碰撞，分别检查从仓库内侧、装卸场侧接近时的显示。南端铁门与门柱、外围墙连成完整封闭边界。绘制与实际阻挡采用相同边界，避免透明处仍有虚空阻挡。
6. 概念展示北端、南端和两处侧门全部关闭。实施时核对北端 `loading-exit` 既有16:00–17:00物流开放规则，开放由门状态控制，禁止无门绕行；南端保持默认封闭，不擅自套用北端开放时段。原有侧门如果仍是自由通路，需按本次封闭要求登记受控门状态。看守巡逻点在场地内部校准。
7. 登记到游戏和地图编辑器共用素材目录，保留选择、移动、旋转、擦除和保存能力。只给门岗亭配置独立屋顶，室外场地保持开放可见。

## 性能与验收

地面按现有可见区域绘制与缓存方式接入；标线和污迹作为静态内容，按编辑变更刷新。货垛优先使用少量可编辑组合，避免为每块木板、箱盖或表面污点创建节点。环境效果不使用实时粒子或灯光模拟。

实施后检查以下结果：

- 游戏正常缩放下，能明确识别物流出口、停车位、两处仓库侧门与南端闭合铁门。
- 场地内部通道连续，人物可到达门内接近点与货物交互位置；所有门关闭时不能穿过任一路口或门柱边缘。
- 两处侧门从仓库内侧和装卸场侧均可见，门面不会被连续墙面遮住；开关状态、交互和碰撞两侧一致。
- 分别遮住左侧和右侧场地，对称门轮廓保持一致，未知区域不泄露人物和货物。门主体不能被所属场地的迷雾切掉半边。
- 北端16:00–17:00物流开放规则与实际门状态对应；南端不因地面相连而自动成为对外通路。
- 车体、箱堆、门柱遮挡按接地排序；没有不可见碰撞，也没有覆盖全场的屋顶。
- 编辑器能逐组编辑资源，移动、擦除、撤销、保存重载结果一致。
- 全图浏览、缩放和平移时，与改造前同场景比较帧率和编辑响应；新增资源仅在相关区域更新。

本阶段已完成概念图视觉检查，尚未执行地图替换或运行时性能验证。
