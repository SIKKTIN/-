## 精确对接

原横翼以底线 B、121.5 高绘制；局部角起点 Y=B−115.02，等于原横翼起点+6.48。原图 y192 对应此角起点，角的立面原封裁取至 y537；墙脚位置与旧横翼完全相同。

横向角占 80 世界单位，纵臂长 150。左角立面 x[宽度,80] 逐点采原左翼；右角立面 x[0,80−宽度] 逐点采原右翼最后80单位，禁止镜像左翼替代右翼。原横翼只在接点裁掉80，其他部分维持原绘制比例和门柱位置。

纵向压顶来自普通石块源区 [232,192,245,74.074074]，真实高光、倒角和暗边都在原纹理里；不额外涂色或用新亮色带。原横墙中段比例144/573，对应一块石头61.5706806283世界单位；组件纵长123.1413612565恰为两块。纵循环逐段拆分到这个源区里，绝不能整张2170宽PNG横向wrap或追加U相位。

纵顶 tile_origin_y=角起点+24，绘制 clip 从角起点+150起；这样角内126长的纵段与续墙共享相位。24和20厚的纵向节距相同，仅压顶截面缩到20，不能把整个 L 横向缩放。右纵顶只翻转截面，纵向节距不反向。

所有 V27 组件在地图层传 mirror_x=false。左右定义已各自选取原图片段；右纵顶的截面镜像已包含在 patch.mirror_x 内，再镜像整个组件会把内侧暗边翻回外侧。

**Extended 长墙适配：** corner 中 role 为 `unaltered original wing fragment; source scale and Y registration identical` 的面片只适用于完整原门翼布局。长墙/厨房以原 `cafeteria_wall_mid_v24` 连续平铺时，必须跳过此面片，保留原中段跨过连接区的相位；替换范围仅遮纵臂的24/20截面，不遮整80。最右纵臂还应替掉原28宽角柱，让 middle 延伸至新纵臂起点。不能把原右翼的独特面片直接贴在任意长墙位置，第一轮右侧actual已观察到明显竖直黑缝，已要求纠正。

端面仍使用原源区[200,259,74,288]映射24/20×90，不沿整段纵墙重复立面。

## 局部验证与审美结论

native-preview.png 来自隔离 Godot Forward+ 实际绘制：左24、右20组合均保留原横墙、厚门柱和门楣，局部转角和纵顶已恢复原压顶的深边与倒角。10图标实际可见，native stderr 无错误，source-review.json 验证旧 A24/A25/A26 冻结文件不变。

这只是局部试拼，尚不能据此宣布完整游戏的左右/厨房接点通过。最终必须看制作人 P57 实际接入图并与用户第一版直接对照。功能资源检查只证明正确绘制，不代替美术判断。
