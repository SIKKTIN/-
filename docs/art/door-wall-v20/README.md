这版把门从独立摆设改为建筑的门洞：石砌门柱和收口包住窄铁边，墙顶在门洞侧面回转，门槛贴地。左侧禁闭室用关闭实心门，右侧食堂用开放栅栏门，栅栏叶收到左侧墙内，右边保留清楚的通行缝隙与地砖连续性。

门与墙采用统一的剖切表达，局部门洞有连贯柱头和顶面；前墙保留较低部分以便看到床、便器和室内。两处门洞没有巨型独立铁架，左右门与相邻墙体的厚度、材质、俯视方向相接。尺度按人物60为参照，目标是门洞约人物1.4～1.7倍；这只是概念视觉比例，真实世界单位与遮挡须在用户批准后另行标定。
