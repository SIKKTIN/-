## 后续制作基准

- 保留第一版横墙、门柱和门楣的深色轮廓、石块倒角、门柱厚度及墙脚分块。
- 以原始 art/architecture/v24/cafeteria_portal_v24.png 为造型与材质来源，优先保留完整原组件；只补足相匹配的转角、竖墙及接缝。
- 保留可重复拼接的组件结构，禁止再次整体替换为淡色平面材质条。
- 组件可采样同一原图，但重复范围必须限制在选定源区，不能整张 PNG 横向循环后误采到门洞或门柱。
- 转角顶面、墙厚、外轮廓和接触阴影应连续；横墙与竖墙同材质，同时保留相应方向的体积表达。
- 先做一个左转角和一段竖墙的实际局部试拼，与第一版同尺度对照，确认体积和风格后再批量替换。

## 沟通约定

用户要求减少沟通频率。将素材规格、反馈和验收依据合并交给制作人，不逐项询问、不重复汇报不变状态。向用户只报告明确成果、需要决定的问题或实际阻塞。
