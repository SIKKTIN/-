# A26 / P56 最终实际视觉核对

本轮验收针对用户新图中的明显风格差异：旧横墙较柔和、旧L转角描边硬且石缝密、旧续接纵顶变为浅暖材质带。必须实际消除换材质感，不能以共享文件路径或资源加载通过代替视觉判断。

## 实际结论

主美亲眼核对P56完整1200画面、960 HUD、真实2倍左右接点、厨房20厚接点、编辑器H/V/L摆放、运行中普通fixtures及隔离长横/长纵/L组件合集。母版统一后的横墙、角与纵顶呈现同一奶灰色石面、共同的柔细石缝和纹理尺度；墙面及墙脚同源。旧外观在转角80段、纵150段末不再切成另一幅画。门柱/门楣也从同coping取材，门金属主体保留可辨识层次。

左右角的暗侧位于内侧，普通角与长墙的顶部和基脚对齐。20厚专属角不缩窄横臂，横石粒度与24厚外墙相同；只减少纵腿cross宽并等比例裁其源V，sourceU跑向周期保留128。源UV在部分末块和非周期角位置保持同一相位，最后一块被裁切，没有整体拉长。

编辑器14个图标均实际可见，地图预览H/V/L和运行普通fixture都按组件几何绘制，L空缺处保留，竖墙没有塞进母版的墙面/墙脚三个带。这一项验证的是可用的拼接组件，而非只有原北翼的固定特例。

## 证据与限制

生产只有一张1536×1024母版PNG，14个assembly组件/14个2D MeshTexture图标的source一致。GPU原生组件合集native-preview.png包含长横/长纵、左右角及20/24比较；stderr空，14图标各有2016以上非背景像素。官方MeshTexture要求2D vertices，参考链接在README中；绘制资源持久引用已确认。

母版色彩和纹理属于柔和手绘石材，轮廓较旧金属道具柔，不增加原转角那种厚黑框。128采样周期可重复，并非无限随机；长墙仍可能辨认到纹理重复，这是组件重复的性质，不等同不同材质切换。图标缩略时粒度受过滤影响，实际游戏近景已另验。
