## 实装与接口

伙伴卡固定使用既有A10肖像，三卡164×82竖排在左侧摇杆上方，技能图标在右角、状态短标签居中、体力/饱腹两条及数值在底部，选中者沿用青绿描边。卡片保持既有选人回调；持续聊天/工作/撬锁的逻辑没有被HUD替换。摇杆移动时当前人物状态显示移动中。

| 控件 | 布局规格 |
|---|---|
| 左下pad | 1200×720为136×136，960×540为120×120；距竖排卡12 |
| 右下action_button | 104×104，青绿强调边框；标签/图标/可用性取互动组件 |
| ability_button、bag_button | 72×64，位于主键上方，相互间隔12，距主键12 |
| target_button | 56×48，主键左侧间隔12；附近多目标时才显示 |
| 背包物品槽/动作 | 槽56×56，动作高度48，停止48×48 |
| 时间/日常表 | 左上；日常表移至时钟右侧，避免960视口竖排栏重叠 |
| 目标/钱/暂停/小地图 | 右上；小地图窄屏200×160，正常220×174 |
| toast | 底部中央，位于左伙伴栏与右侧动作区之间 |

上述为画布逻辑尺寸，叠加已有safe_area物理显示安全区；没有把世界坐标用作HUD位置。MobileButton仍由原生Button处理GUI输入、禁用、焦点和纸卡Theme，图标与文字竖排绘制，避免辅助键因原生横排最小尺寸挤入主键。

公开字段：`action_button`、`ability_button`、`bag_button`、`target_button`、`bag_open`；公开方法 `toggle_bag()`。控制器：`game.mobile_controls.pad/cancel_input()/is_moving()`。互动：`activate_mobile()/mobile_label()/mobile_icon()/mobile_available()/cycle_mobile_target()/mobile_target_count()`。技能调用原 `game.use_selected_skill`，禁用状态跟随隐藏的原skill_button；辅助键显示当前技能或停止技能，tooltip保留原完整动作说明。

## 背包与遮挡

`bag_open`默认false。展开使用当前人物真实1/3格容量，选物品后显示使用/放下/交给其他两人；收起只改可见性，不改变物品与selected_item，不清空摇杆输入。普通展开位于辅键上方，不覆盖主键。原mini_map停止按钮移入背包头部，不另摆与摇杆冲突的常驻停止键。

商店打开时自动显示宽212的背包，靠安全区右下，保留物品选择；所有使用/放下/交接动作收起，停止禁用，离开商店后按原bag_open恢复。库存层在shop之后，其他模态时隐藏。日常表、日程、开发者设置、暂停、结束等世界输入阻挡时，pad隐藏并取消输入，移动和动作键隐藏，伙伴卡禁用；暂停入口不会在其他弹层上方抢触摸。
