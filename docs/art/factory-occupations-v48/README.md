# 职业人物素材 v48

按 `concept-review.png` 审评通过的概念制作：食堂师傅、医务人员、维修师傅、仓库管理员、货车司机、清洁人员。每人有 1 张站立姿势和 8 帧行走，共 54 个姿势。共用现有人物的脚底锚点、左右镜像、缩放和遮挡规则。

## 编辑器使用

选中伙伴、巡逻看守、门岗或商人标记，在右侧「人物形象」中选择职业外观并保存。形象库合并 v47 的 8 个形象与本次 6 个形象，共 14 种可选外观，另有默认选项。

本次交付为人物外观与行走素材库；没有在 R04 新增职业 NPC 或修改现有人物的日程、交互与身份。正式职业安排需要独立配置岗位和行为。原有玩家、同伴、看守、监工和商人的默认选择规则保持现状。

## 文件与来源

生成方式：内置 `image_gen.imagegen`，按已批准概念作为参考。原始 RGBA PNG 已复制到 `art/characters/factory_occupations_v48/`，与生成原图 SHA256 一致，保留透明背景；没有重绘、修图或修改原始像素。

- `prompts/`：六次生成的完整提示词。
- `register.py`：复制原图、读取透明区域并登记姿势区域、头部中心、脚底锚点及统一缩放。
- `registration.json`：原图路径、哈希和注册数据。
- `../../../art/characters/factory_occupations_v48/manifest.json`：运行时素材清单。
- `concept-review.png`：用户批准的概念图。
- `native-lineup.png`：Godot 原生渲染的站立/行走预览，包含游戏实际比例。
- `native-game.png`：游戏中的显示核对，人物临时排列和形象覆盖仅在内存中使用。
- `native-editor.png`：编辑器中的医务人员选择核对，仅用于预览，没有保存到 R04。
