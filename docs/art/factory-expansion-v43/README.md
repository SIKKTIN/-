# R04 黑工厂扩建 V43

按审评通过的概念扩建现有地图，范围由 2800×2200 增加为 4000×3000，约为原面积的 1.95 倍。保留现有寝室、车间、食堂、禁闭室和日常设施位置，向东增加仓库、装卸场，向南增加洗衣房、设备间和后勤回路。

## 地图与路线

- 正门：保留原锁门、门岗和通行规则；过门后沿独立通道前往北侧出口。看守、监工和增援也通过此处实际往返，不瞬移。
- 物流：仓库用错位货架形成遮挡和交错通道，放置两件工具、一把钥匙和一个可推箱；东侧连通装卸场。装卸出口首版设为每天 **16:00–17:00** 开放，门前保留集合位置并安排值守。即使关门时正在疏散，超过时段也不能判定物流逃脱。
- 后勤：现有钥匙、工具或撬锁技能可开启设备间检修门；进入后，从内侧操作侧门，联动打开后勤隔断及后勤出口。洗衣房和南侧通道形成后续往返的回路。
- 食堂增加受同一就餐时段控制的后门，连接南侧生活后勤空间；原取餐、用餐和劳动点未移动。

新增区域使用现有 20 单位建筑瓦片：横墙、纵墙、四向弧角、T 连接、门楣及门组件；横墙沿用多种变体。地图现在有 510 个墙体瓦片/既有墙段及 92 个摆设，其中 35 个为扩建新增摆设。三个出口与关联门禁可在编辑器选取修改。

## 美术素材

使用内置 imagegen 生成一张透明原始图集，原始 PNG 字节保留；通过区域裁切元数据注册八种独立素材：仓库纵向货架、托盘货堆、货车、工业洗衣机、晾衣架、设备泵组、电气柜、门岗亭。全部进入正式编辑器素材栏，并有独立缩略图；新增对象遵循现有斜俯视、平行边线的视角。
