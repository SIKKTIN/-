# 食堂重设计美术方案

以园区总概念图中的食堂为布局依据，恢复北侧连续配餐区与五组纵向长桌。食堂采用暖灰、灰橄榄瓷砖和旧木桌，形成与蓝绿浴室、浅色医务室不同的建筑辨识度。保持现有俯视手绘相机、人物 1.4 倍比例和朴素监狱伙食。

## 改造前布局与改动目标

改造前 R04 食堂室内范围为 [820,2520,1360,560]。四组横桌分成两列两排；北侧后厨和独立取餐台主要集中在东半侧，留出了较大的散乱空地。目标改为五组桌凳从西到东并排，每组长轴南北向，北侧配餐设备连续排列，取餐通道与南侧横向通道连通。

| 区域 | 设计目标 | 通行要求 |
| --- | --- | --- |
| 北侧设备带 | 灰金属储物、备餐、炉具、洗池、餐具架与朝南取餐台统一成连续服务区 | 保留工作人员通道与原北门进入路径；设备不得封住门 |
| 取餐走道 | 沿取餐台向东西贯通，排队位置用地面细线示意 | 主通道目标宽 90–110 世界单位，不依赖阻挡栏杆维持队列 |
| 就餐区 | 五组纵向旧木桌，两侧长凳，餐盘独立摆放 | 组间目标净距 90–100；两侧保留走道 |
| 西侧 | 靠墙饮水桶、浅餐具柜 | 靠墙收纳，不占用门口 |
| 东南侧 | 小型餐盘回收车、带盖桶 | 与配餐台分开，回收点前可站人 |
| 南侧 | 连续横向走道与后勤门 | 保留食堂后门及设备间检修门，不切断相邻区域 |

以现有范围为初始尺寸校准：北侧设备和工作区约 180 深，排队区约 90 深，桌凳区域约 210 深，南侧走道约 80 深。纵向桌凳组合初始脚印约 150×210，五组等间距摆放。以上是空间预算，最终尺寸应在素材注册后依据寻路、门口与人物避让检查调整。

概念图负责材质、比例和整体摆放效果；门洞精确数量、坐标、开闭方式以接入时的最新地图数据为准，不照着图片额外增加门。

## 美术语言

墙面上部为稍旧的暖白灰泥，下部为灰橄榄釉面瓷砖，薄深灰金属收边；取消厚石块压顶。四角、T 接头、门框和墙脚采用同一厚度，做出干净连续的接缝，避免转角贴图相互叠压。

地面用小尺度暖灰防滑砖，缝线清楚，局部有轻微磨损。设备采用低饱和旧不锈钢与灰蓝柜门，桌凳采用磨旧黄褐木板、细黑钢架。磨损集中在桌沿、柜脚和常用把手，不以满屏噪点表现旧感。

伙食沿用既有朴素方向：少量米饭、煮白菜、浅色土豆与清汤，开放配给盆控制为两种，其余加盖。餐盘、搪瓷杯、勺子以独立桌面配饰制作，不画成豪华自助餐。

## 接入方案

1. 先完成建筑角、桌凳和服务台单件样板，在当前人物旁检查比例与相机方向，再制作其余资源。
2. PNG 交付真实透明背景、清晰轮廓。按 region、ground_rect、footprint_world_size、world_size 和 elevation_world 注册；图像绘制范围与碰撞脚印分开，等比缩放。
3. 建筑、家具、地面、屋顶使用独立资源清单；加入地图编辑器分类与真实缩略图。保留旧 ID 给既有地图读取。
4. 基于最新已保存的 R04 修改食堂内资源引用和摆放。原门禁 ID、定时开关、后勤连接、相邻走廊、洗衣房、设备间与其他房间保持既有连接。
5. 更新五组桌凳对应就餐站位、取餐点和厨师工作点；复用现有用餐时间及取餐规则。概念图不引入新的收费或伙食数值。
6. 屋顶单独检查外观、遮挡和门口切换。静态地面与屋顶沿用现有缓存方式；小餐具不增加碰撞或独立每帧逻辑。

## 验收重点

- 五组纵桌、两侧长凳、连续配餐区与参考图一致，摆放密度与人物比例协调。
- 四角、墙体接头、门框无断缝、错位和额外隐形阻挡。
- 所有原门口、取餐点、就餐点可实际寻路到达；桌间可通行，碰撞不覆盖视觉空地。
- 餐盘完整落在桌面上，桌面配饰不被桌体遮住；人物与设施沿用统一深度排序。
- 屋顶外观与新食堂建筑一致，进出切换正常。
- 在实际运行窗口与地图编辑器分别检查清晰度和比例；性能比较使用相同视角和规模。
