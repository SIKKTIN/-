# 贴墙食堂设备与工作通道（实装待审评）

按用户批准的 concept-against-wall-v3.png 实装：浅俯视的后排设备贴后墙，前方取餐台单独摆放，中间有连续石板地面的工作通道。旧V14取餐台将前台和整个后厨合画在一张图里，本次以两件独立透明素材替换R04中的引用，旧PNG和定义保留给其他地图读取。

新素材由内置 imagegen 以批准概念图为参考分别生成：

- art/props/cafeteria_v40/counter_front_v40.png：取餐台、饭菜盘、盖盘、汤锅与餐盘堆，独立完整柜体。
- art/props/cafeteria_v40/backline_v40.png：储物柜、餐盘架、操作架与锅、水槽、置物架、冰箱，完整靠墙后排。

PNG完整复制并保留原始字节；只用裁切区域、等比落地锚点和透明边缘着色器注册，未用脚本编辑图像像素。完整生成提示词见 generation-prompts.txt。manifest.json记录原图SHA256和裁切参数。

“食堂设施→取餐/回收”提供两件新素材与原餐盘回收架；每件可独立选择、移动、复制。正常放置库隐藏旧的合并后厨图，旧ID继续读取兼容。新原生缩略图在 art/editor/v18/icons。

R04取餐台使用[1300,1540,600,20]落地碰撞，显示约600×107；后排设备使用[1300,1260,580,60]落地碰撞，显示约580×129，后缘接墙脚并遮挡下段墙面。原后厨[1290,1260,620,200]整块隐藏障碍改成可见后排设备碰撞，中间空间释放。壁灯上移到墙面，排序高于墙体避免被墙遮住；对应灯光位置同步调整。

取餐台底边相对原实装下移20单位（一格），并微调宽度到两侧墙之间。原因：旧墙端至台前的40单位入口虽然物理上容得下人物，但20单位导航网格的中心点被人物半径17挤掉，导致寻路失败；下移一格后入口60单位，有稳定可达路径。其余墙体、四向转角、定时门、就餐时间、取餐点及其他摆设均保持原数据。

r04-before-cafeteria.json为本次修改前备份。integration.json记录布局和通行余量。checks.json记录27项编辑器、纹理、正式素材库、等比缩放、透明背景、贴墙遮挡、工作通道寻路及运行时加载验证，全部通过。access-checks.json为73项管制门、食堂实际取餐、禁闭与逃脱回归，全部通过。

r04-cafeteria-editor.png、r04-backline-selection.png、r04-full.png是实际地图编辑器截图；r04-cafeteria-runtime.png是运行场景截图。旧素材字节和原有project.godot用户修改保留。未提交Git、发布或反馈制作人，待用户审评。
