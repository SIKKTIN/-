# 洗衣室美术设计方案

日期：2026-10-13。阶段：已按批准概念图接入R04并完成运行检查。游戏内名称沿用“洗衣房”。

按用户总地图概念中的洗衣房重组作业空间：北侧四台滚筒洗衣机、西侧收衣及用品架、东北净衣架、东侧手洗水池、南侧叠衣与转运区。入口和出口形成“北侧偏左进入、南侧偏右离开”的动线。批准效果见 [概念图](concept-final.png)，实际还原见 [游戏内截图](runtime-interior.png) 和 [接入记录](implementation-report.md)。

## 现状与改造边界

当前活动区域为 `[900,3440,880,440]`，室内可见区域为 `[900,3420,900,480]`，地面覆盖为 `[880,3400,940,500]`。现有四台洗衣机、布草架、分拣台、叠衣台、水池、布草车、供水管、墙体、双扇门及独立屋顶已经接入。

主要差异是设备集中在局部，叠衣台偏像普通木桌，布草周转物偏少，北门与南门位置未形成概念中的作业流向。以当前建筑外框为基础，不扩大房间；通过设备尺度、成组摆放和入口调整让空间紧凑。精确门洞坐标在实施时依据最新保存地图校准，保留东侧设备间及周边食堂、后勤通道的既有内容。

## 视觉与建筑

保持现有固定俯视镜头、浅立面及手绘工业风。主色为旧灰蓝钢材、米白布草和低饱和灰绿地砖。上墙浅米灰，下墙用冷灰蓝防水瓷砖，窄钢收口；与医疗室和浴室的绿色护墙区分。

洗涤设备用少量磨边和阀门锈迹体现使用年限。潮湿痕迹集中在水池、洗衣机排水和地漏旁，地面大部分保持低噪点、可读的防滑砖。门外铺装保持干燥。管线有供水阀和短连接，不画成淋浴喷头。

洗衣房保留独立屋顶。室内概念图展示屋顶隐去后的状态；外部使用现有灰蓝金属屋面、磨砂采光带和落水管，并根据新门洞、墙角与外围边界复核。屋顶的可见范围、淡出和恢复与房间可见区域同步。

## 最终布局与尺度

| 位置 | 布置 | 尺度与通行 |
|---|---|---|
| 北侧偏左入口 | 灰蓝单扇钢门、窄用品架及室外接近铺装 | 保留通往食堂侧通道的功能；门前清空 |
| 北侧中段 | 4台同系列工业滚筒洗衣机 | 单台接地宽约80–90、深约60–70；保持同高同宽，4台前方共用操作通道 |
| 北墙附件 | 四位供水管、阀门、短排水连接与排风格栅 | 随墙和机器成组；不侵入走道，不产生独立大碰撞 |
| 东北 | 2层金属净衣架 | 宽约170–190、深约40–50；米白布草分层叠放，蓝色用品箱点缀 |
| 西侧中下段 | 脏衣车、两只蓝色分拣桶及窄操作架 | 紧凑成组，避免脏衣桶占据中央；维持西侧现有入口的接近空间 |
| 东侧中段 | 双位搪瓷手洗水池及小排水格栅 | 沿用约150宽水池；操作位可从中央通道到达 |
| 南侧中段 | 低金属叠衣工作台、布草叠放和台下周转箱 | 宽约280–320、深约60–65；正面操作位朝中央，不横挡南门 |
| 工作台东侧 | 1只净衣帆布车 | 宽约60–65；停在台侧，留出南门路径 |
| 南侧偏右出口 | 灰蓝双扇钢门、小观察窗及“洗衣房”牌 | 门洞沿用约180净宽；门框、门槛和门外后勤步道接齐 |
| 东侧设备间连接 | 现有受控检修侧门 | 保留锁门功能；门前留空，不被水池、车或架子挡住 |
| 中央 | 连贯的操作及转运通道 | 主通道约100–140，主要转运处尽量120–160；以现有约84高人物校准 |

概念图人物仅用作尺度参考，实际复用现有角色素材。概念中的北门和南门采用关闭展示形态，用于看清门框与结构；游戏通行条件沿用现有设置。

南北门位于横向墙体，可表现浅立面。东西侧门位于纵向墙体，关闭门扇沿墙线，主要看到侧面和顶边；禁止把侧门画成正对屏幕的立面。门框、门槛、门状态与碰撞在相邻两侧共享；未知区域的遮挡不应切掉已可见的共用门边界。

## 接入方案

1. 制作开始时读取最新地图并备份，核对当前洗衣房及用户已保存的调整。只改洗衣房相关对象及必要的入口接近铺装。
2. 用现有外框校准净空，先排4台洗衣机、东北架、西侧分拣和南侧工作台，确认角色与推车的通道；不以填满地面为目标。
3. 将北门向西、南门向东调整到概念流向。同步门洞、墙段、门框、地面、门外接近点和寻路连通，旧门洞填回完整墙体。保留北门 `cafeteria-rear` 身份及现有12:00–14:00时段；其撤离点、房间矩形与门位置必须同步核对。南门保留当前通行语义。
4. 保留 `laundry-equipment` 受控检修连接，现有上锁状态及与 `maintenance-entry` 的关联继续有效。东侧门使用正确侧向投影，检查设备间内外两侧的识别与碰撞。
5. 替换金属叠衣台与脏衣组合时保留既有翻找ID、布草掉落配置及交互名；避免新旧物体重复叠放。
6. 门、墙、工作台和车按接地排序，管线和墙饰按归属绘制。排水盖、湿痕、门牌和台面小物不生成多余阻挡。
7. 屋顶仍作为独立遮挡资源，检查外部覆盖、进入淡出、退出恢复；验证入口调整后不会漏出房内信息或残留旧屋顶接缝。
8. 登记到游戏与地图编辑器共用目录，保持选择、移动、旋转、擦除、撤销和保存重载可用。

## 性能与验收

洗衣机复用同一纹理；架上瓶罐、台面布草与阀门采用少量静态组合。地面、排水与湿痕按可见范围缓存，不增加实时水面、蒸汽粒子或动态灯光。只在编辑相关对象时刷新其组合，避免每帧重新生成全房摆设。

实施后验证：

- 正常缩放下能区分洗涤、脏衣分拣、净衣收纳与叠衣转运区，4台机器数量和比例一致。
- 北侧偏左入口到南侧偏右出口连通，所有工作位与东侧检修门可到达，推车不堵门。
- 北门时段、东侧锁门及原有翻找功能保持正确；墙洞与碰撞同步，没有旧洞、虚空阻挡或重复物体。
- 东西侧门朝向正确；两侧与黑色遮挡下均能辨认门框，不出现正对镜头的侧门立面。
- 4个转角、门槛、护墙砖缝和屋顶边缘接齐；屋顶不会误覆盖室外后勤通道。
- 编辑器修改、擦除、撤销、保存重载一致；在相同视野与缩放下比较改造前后的平移和帧率。

运行验证已完成，包含门禁开放时段、四向通行、旧门洞封墙、布草翻找与转移、屋顶遮挡、编辑器擦除撤销及保存重载；详细结果见接入记录。
