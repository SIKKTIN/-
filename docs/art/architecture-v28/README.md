# A28 完整 L 转角瓦片

本轮新画一个完整连续的 L 形转角石。转弯内部是同一块连续顶面和经过设计的内侧倒角，去掉首稿的独立方头和横向断缝。原 V24 横墙、门柱和门楣、V27 直纵墙源图均保留。

## 组件与接口

源图网格 x=[142,458,1110]、y=[161,477,1093]。三块采样只是把已画好的完整 L 映射到接口规格，不能改成独立横条/竖条纹理；中间的连续顶面、转折倒角和凹角明暗都来自同一块专门绘制的原图。

24组件80×80：横臂80×24，纵臂24×80；下内侧56×56空区真实透明。20组件76×80：纵臂宽20，横臂深度仍24以接原横墙；两条出臂56长度不缩，原纵墙石块节距不变。其右侧放在旧80宽junction的x+4处，左侧x不变。

渲染起点保持旧角Y=底线−115.02=原横翼起点+6.48。完整L替掉旧矩形elbow和旧角纵向patch；继续保留原横墙立面，仅移除被新L北臂占用的旧横墙压顶。旧原翼face去掉北臂对应矩形y0..24，下面抹灰/墙脚仍保留；20左端保留旧face的x76..80压顶，20右端保留x0..4。

Extended长墙保留原middle连续相位，不能重新贴原门翼face。新L北臂跨度80/76的旧顶面需要单独裁掉，墙身仍沿原middle绘制。旧矩形压顶不能留在新角的外凸切角下面，否则切角会被填回。

新L南端在Y+80，直纵顶从这里开始，tile_origin_y和render_start均为Y+80；沿用V27的123.1413612565周期源，接口处开始新石块。不要继续绘制旧角24..150的纵臂，不要留下硬拼的旧elbow，不要把新PNG当成整幅墙身材质。

新L真实空区不允许被包围盒阴影填满。沿用V25安全alpha shader，保留密实轮廓与自然透明边缘。物理24/20、90立面、180门洞和规则不变。
