# P65 批准 C 实际完整墙复核

批准依据是 approved-concept-c.png。重点是两内角的小凹圆弧、纵墙顶接到横墙顶并覆盖交界砖、横墙下暗线不跨纵墙根部，整段纵墙同材质/同顶面侧影。不是只让同源数值通过，也不是凸T牌或正面柱石。

亲眼比较最终1200完整左右runtime、editor右、960完整左右runtime、两规格T+四规格V独立实绘及纵墙分类。两条厨房纵墙均由同高圆弧从H顶接出，暗线在两个凹内角停止，整段V延续同一母图的窄顶面/侧影，没有前轮上段正面柱石与下段窄顶面跳变。末端仍保留原front/endface方向变化。H原墙身、柱楣、墙脚和外围L层次保留。

首轮实际图的母图横条外端黑竖线/小圆帽与多余密砖缝造成贴板感，未接受。与制作人协商只修新PNG的UV：横臂采用内部source116..426与602..910，两个弧头独立8world列与contact相同source列接续，总9patch。最终实际外端已去终止帽，砖缝疏于首轮，圆弧/root和长V全部不改，H顶线与有效底沿保持同高读感；没有独立外框围整T。

新母图是按批准图用imagegen提取/重构，并非从批准图逐像素切下。磨损、部分石缝与细部高光有差别，纵墙周期75.818181818世界单位。当前主美判断圆弧一体同高构造和整体石材表现符合批准C方向，可交制作人独立审；不宣称人类已重新审过实际游戏截图。必要的取样/镜像元数据记录在interface.json。
