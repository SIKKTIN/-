# P63 实际画面主美复核

对照人类批准的 approved-reference.png，亲眼复核修正版左右厨房 game/editor。批准图的要点是普通压顶石与中央窄头石接续，中央通过正常石缝形成纵墙，不是完整凸起的 T 标牌。本版四块普通横石、中央普通头石与竖石体现这一构造，去掉 V29 的大三角肩部和密亮斑；保留原墙身、柱楣、暗色墙脚和外围 L 的立体层次。

初轮实际图的新横臂有效可见下沿多约3世界单位，产生矩形覆盖感。修正版仍使用原始新 PNG，横臂源窗口从142高改160高，利用源下方本有的透明像素使24逻辑高中的可见石体约21高；stem取同一源的y438续出，厨房两个 cap_cutouts 高改27.48，露出原H底沿接续，外围L不改。修正版实际两端底线比初轮平顺，不再悬出整条额外底边；中心纵臂与长竖墙对齐，没有透明带漏地和独立底板阴影。

石块顶面与旧H仍有轻微明暗、磨损和节奏差别。批准图也允许普通块的明暗变化；当前实际效果呈同套浅米灰石墙，而非 V29 的整块亮面覆盖。没有逐像素照搬批准图的墙面裂纹，也不把这个差别称为完全一致。主美判断此次自然砌接构造、有效厚度、底线与整体立体风格符合批准方向，可提交制作人独立审。

技术项与审美判断分别记录。资源可加载、两个图标GPU可见、game/editor一致、两尺寸放置和门禁回归均由对应 JSON 证明，检查数不构成风格通过的理由。旧 V24–29 冻结交付文件逐项 SHA256 检查未改，主美不修改 shared 代码、地图或 Git。
