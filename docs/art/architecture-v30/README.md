# A30 自然石墙接口

依据人类批准的自然砌接概念，以内置 imagegen 重绘一张 RGBA 主图。横向普通压顶石与中央窄头石、两块竖向普通砌石接合；取消 V29 的完整大 T 面、45 度肩部和亮色密斑。PNG 为原输出逐字节复制，未后期涂改。

入口：`art/architecture/v30/manifest.json`。两件 `cafeteria_t_20_v30` / `cafeteria_t_v30`，132×80 / 136×80，stem x56，横臂各56，北横深24，下接点 y80。右厨房整件镜像一次接 V27_r。没有旧 T 的4×4肩部。四个源区注册同一张新图；绝对源坐标，不使用 phase_axis。

两张独立 MeshTexture 图标在 `art/editor/v10/icons/`，原生 GPU 试拼和可见像素证据在本目录。旧 V24–29 全交付 hash 未变。原横墙立面、柱楣、外围 L 和长竖墙保持原资产。

候选自审：初轮实际图发现新横臂可见深度比旧 H 多约3世界单位，已用原图源注册纠正：横臂采样y278..438，逻辑高24内保留末部透明带，可见厚约21；stem从源y438续出。厨房cap_cutouts高27.48，保留旧H底沿，避免透明带露地。复跑原生近景下沿已对齐，中央是普通石缝。顶面略暗于旧H，保持自然石色变化，未调色shader。修正版实际game/editor左右厨房、两尺寸独立组件与分类图已复核，主美判断可提交独立验收。详细观察见p63-visual-review.md；待制作人正式独立验收。

集成只由制作人处理：两厨房 T29 替换 T30；新建白名单使用 V30，历史 ID 保持加载兼容。主美只写本版素材、图标、文档，不修改 shared 脚本、地图及 Git。
