## 统一视角和比例

场景家具沿用游戏现有的斜俯视手绘角度，纵向边基本竖直，横向边基本水平，少用明显斜向透视收缩。角色保持用户确定的 1.4 倍显示比例，头和身体共用排序。

目前标准医务人物高度为 `60 × 1.4 = 84` 世界单位。下表是新素材制作时的初始目标，按游戏视角比对调整：

| 对象 | 初始比例要求 |
| --- | --- |
| 横向诊疗床 | 长轴约角色高度的 2.0 至 2.3 倍，即 168 至 193 世界单位；顶面宽度、床腿高度分别绘制 |
| 操作台 | 台面高度视觉上接近角色腰部；长台沿墙长度约 250 至 320 世界单位 |
| 抽屉药柜 | 作为矮柜，柜顶接近角色腰部或胸下；先试约 90 至 110 世界单位的宽度 |
| 右侧玻璃药柜 | 采用高收纳柜的体量，顶面、正面和落地位置都应清楚；先与角色并排核对 |
| 医疗推车 | 台面约在角色腰部，保留原图长宽比 |

以上比例用于新医务室素材校准。现有 `prop_proportions.json` 的家具校准参考高度为 96，不应为了医务室单独调整整个园区的比例参数。每件新资产登记自己的渲染尺寸、落地面积和脚底锚点，保留素材长宽比。

颜色以米白、浅蓝灰、灰绿、暗钢灰为主，小面积使用暗红医疗标识。光线遵循场景现有方向；磨损集中在边缘和把手附近，台面和床单保持清晰。阴影由现有场景系统统一处理，透明原图避免重复画重阴影。

## 美术交付格式

独立 RGBA PNG，家具建议以 1024 像素级原图交付，长操作台可使用更长画幅。四周留透明边距，透视方向按用途绘制。横向床和纵向台面分别制作对应视角。

每件资源附名称、素材 ID、源文件、有效绘图区域、落地面积、显示尺寸和锚点。碰撞取地面占位，装饰顶面和柜体上半部交由渲染排序处理。地砖提供无缝平铺图；场景小件单独提供，便于在编辑器中摆放和替换。

建议资源目录为 `art/props/clinic_restoration/`，地面目录为 `art/environment/clinic_restoration/`。资源清单沿用项目现有 manifest 格式，保留编辑器图标和分类。

## 制作和接入顺序

1. 制作一张完整房间概念预览，把玩家和现有医务人物按实际比例放入，确认家具方向、材质和动线。
2. 制作三件主体家具和地砖，再根据预览补充短台和小件。
3. 登记到 `scripts/presentation/prop_catalog.gd` 使用的素材清单；配置渲染尺寸、落地面积、碰撞和编辑器分类。
4. 基于制作人最新保存的地图草稿调整医务室 fixtures 与地面区域，保留房间边界、入口和其他区域的修改。
5. 将可搜刮柜体连接现有 `medical` 掉落池，验证绷带、止痛药、消毒药水的搜刮、拖动、放回。
6. 将 `clinic_medic` 作为独立常驻医护接入岗位、站位和行走范围。治疗交互如需增加，再独立定义费用、恢复量与时间。
7. 在默认游戏镜头、地图编辑器和进入房间的状态分别检查遮挡、碰撞、比例及整体还原效果。
