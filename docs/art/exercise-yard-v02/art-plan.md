# 放风院美术设计方案

将编辑器红框区域调整为横向、紧凑的露天放风院，恢复总地图概念中的半场篮球、单杠、休息长椅和遮雨棚布局。主要调整是缩短纵向活动地面，把设施组成集中到红框内，保留东侧主路与南侧步道。最终效果见 [概念图](concept-v3.png)。

## 场地范围与布局

按约2比1的长宽关系设计。接入后的实际范围为 `[2140,220,1120,600]`，以医务室外墙、北侧围墙和东侧主路校准。人物维持1.4倍、约84单位高，道具按人物比例摆放；旧的纵向水泥区域已经替换。

北侧借园区外围墙与树带形成背景；西侧与医务室步道衔接；南侧通向车间前步道；东侧向正门主路开放。放风院不另外设置四面厚墙，也不增加房间屋顶。

西侧新增与右侧挡边相似的浅灰水泥矮栏，压顶窄而连续。矮栏从北侧边界延伸到南侧铺装，与南边收口接齐。近景校准后，横向段按200单位长度装配，消除转角接头的高度差。医务室外墙与矮栏之间的窄通道补齐灰绿铺装；东西两侧采用相近材质，东侧入口保持开放。

| 区域 | 设施安排 | 空间要求 |
|---|---|---|
| 中央偏东 | 1个紧凑篮球半场，1座旧篮球架 | 标线占位约400×300，篮架基座放在北端线外，球场外围可绕行 |
| 西侧 | 1组高低单杠 | 三根立柱清楚接地，前后留站立与通行区 |
| 北侧 | 2张横向旧木长椅 | 椅面朝院内，与北侧树带形成一组；避开篮架 |
| 南侧 | 2张横向长椅 | 不挡车间前步道，椅前可站立 |
| 东北角 | 1座波纹铁皮遮雨棚，棚下座椅及小木箱 | 棚下可进入，前柱与顶棚分层，外形保持轻巧 |
| 东侧 | 1张纵向长椅，上下两组灌木 | 中段向主路开放，不用连续绿篱封住入口 |
| 西南角 | 旧桶、水桶与矮灌木小组 | 集中放在边缘，不向中央散放杂物 |

东西主路和南侧连接口预留至少180单位；院内主要绕行路线预留120至160单位，器材旁次要通道至少96单位。尺寸是装配目标，最终以人物碰撞、NPC会车和寻路复核。

概念图中的人物用于比较尺度与活动氛围。图中大地图的“放风院”白色标签不作为地面装饰；室内地砖、额外货架和大量工业杂物不进入活动中心。

## 画面与材质

延续游戏的俯视手绘视角，建筑与地面坐标轴保持横纵向。主色为灰褐水泥、旧木棕、深灰绿金属、灰蓝棚顶和低饱和橄榄绿。地面用大块旧水泥关系表达空间，只在接缝、边角和设施根部加入裂纹、积土与磨损，避免整张底纹铺满砂点。

球场线采用褪色米白，局部断裂，独立于地面底纹。半场没有完整中圈；罚球区和弧线围绕北侧篮架对称排布。绿化集中在西北、东北、西南和东南，采用小树、低灌木、草边的高低变化，树冠不盖满球场，不平均摆放同款花盆。

放风院与主路之间以积土、草边、少量排水细节过渡，避免独立水泥贴片的硬矩形边。所有设施必须有明确接地位置，阴影方向与现有场景统一。

## 接入步骤

1. **确认草稿边界。** 以编辑器保存后的地图为准，记录放风院、周边墙、主路、门岗和车间步道的位置。保留用户当前地图调整，不用旧地图整份覆盖。
2. **重排空间。** 修改放风院地面与活动区范围，把现有篮球线、南侧长椅和小物收进横向场地。腾出的下方区域恢复为与车间前步道相连的地面。保持相邻医务室、门岗和车间原有边界。
3. **制作第一批素材。** 完成水泥、标线、泥尘草边和灌木组合；复核现有单杠、棚体、篮架、长椅和树盆，按概念图分组摆放。
4. **处理碰撞与遮挡。** 单杠只让立柱阻挡，棚下可走，树冠和阴影不产生碰撞。棚顶在人物进入时适当淡化，前柱按脚底深度排序。移走旧物时同步清除旧碰撞及视线阻挡。

   西侧矮栏使用连续模块与明确端头，碰撞仅覆盖窄基座，不把压顶阴影扩成大阻挡。保持外侧铺装通道可通行，并检查南北收口的贴合关系。
5. **调整活动点。** 沿用放风院区域标识，复核放风日程、囚犯休息点和看守巡逻点，避免NPC继续走向旧球场位置。保留主路通行。
6. **补小物与验收。** 加水桶及排水细节，检查正常镜头下的比例、通行、遮挡与性能，交付游戏总览、人物近景、棚下及地图编辑器截图。

素材同时登记到游戏与编辑器共用目录。保留静态地面与阴影缓存；草屑和碎石采用少量贴花，不逐个创建更新节点。PNG保留原尺寸，运行时纹理采用现有缩小与mipmap机制，小道具通常限制512像素，地面通常限制1024像素。

美术装配预留坐椅、健身及聊天的站立点。篮球、训练数值或新的小游戏作为后续玩法独立设计，不作为本次美术还原的验收条件。

## 验收标准

- 正常镜头下呈现横向、紧凑的室外院子；球场、单杠、长椅和棚体能一眼辨认。
- 篮架位于半场端线外，标线完整留在场内；北、南各两张露天长椅，东侧保留进入空隙。
- 人物保持1.4倍，穿行主路、院子和棚下都无隐形碰撞；NPC目标点可达。
- 棚顶、柱子与人物遮挡合理；盆树不形成整片阻挡；绿化不掩盖活动设施。
- 地面与周围步道、草边自然连接，不出现透明空隙或明显重复接缝。
- 编辑器内可独立选择、移动和删除素材，拆除设施后游戏与编辑器同步更新。
