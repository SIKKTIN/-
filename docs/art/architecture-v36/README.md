# 通用监狱建筑瓦片 V36

本轮按用户批准的完整计划交付正式素材库、编辑功能和R04外围迁移。复用批准的V33原母图，未改动PNG字节；新素材使用原生UV与公共接口shader。29种完整组件都进入正式建筑瓦片分类，不再依赖样段的left0/right1固定切片顺序。

## 素材与使用

- 横墙：A/B/C三种普通变化、D轻裂、E潮痕，40×120；短横墙A/B/C为20×120。普通横墙五种可以任意混拼，包括同款自接。
- 纵墙：A/B/C为20×60；长段20×120，短段20×20。共有同一纵向接口，可相互接长。
- 四个转角：40×120，分别连接右下、左下、右上、左上。按方向组合完整压顶、墙面和墙脚，保持摄影方向，不将横墙旋转成纵墙。
- 分叉：向上/下T与十字为60×120；向左/右T为40×120。
- 收口：横墙左/右端40×120；纵墙南端20×100，北端20×20。
- 门框：门柱20×120；门楣80×20与短门楣20×20。

在“家具/设施→建筑瓦片”选择对应子分类。指定款式直接点选；勾选“墙体随机款式”后，在同尺寸、同连接方向的款式内稳定选择，普通款权重高于破损款。选中现有墙，在右侧“墙体款式”更换同类变化；换款保持尺寸、连接方向及碰撞。移动不会重新随机。B绘墙拖动生成独立整格横/纵墙段，可一次撤销整个笔画；转角、分叉、端头和门框从素材库选取。

## 接口规范

格子20仅约束外边界与锚点，不要求每20/40单位画砖缝。横向公共边使用原母图x1030的完整安静材质截面，压顶、抹灰、墙脚均保留各自颜色与高度；不会取黑色砂浆缝作为公共边。变化保留在组件内部，砖缝可以跨格子。界面内0.7单位共用同一截面，向内2.5单位过渡回原画，没有额外黑竖线或亮柱。纵向公共截面是原母图y600、x710–830的同一石顶剖面；分叉只在实际有连接的方向使用相应接口。

所有瓦片拥有完整占格矩形，绘制和选择按整块执行；碰撞使用相对collision_parts，避免把120高的立面全部当成地面障碍。新建库仅保留V36，旧ID保留读取兼容，不混入正常放置库。

## R04与验证

R04食堂外围85块已迁移到本素材库，横墙按与编辑器相同的稳定选款算法混拼。墙体矩形、相对碰撞、家具、管制门、食堂规则均未改动。r04-before-universal.json是迁移前备份，migration-report.json记录对应关系。其余区域旧墙没有在本轮扩展迁移。

library-checks.json：146项原生检查，通过全部29种占格边界、五种横墙的25种有序混拼、短墙与各方向接头、素材库注册、图标、指定/随机放置、换款、序列化及B绘墙撤销。

r04-checks.json：182项实际编辑器检查，通过85块入库和碰撞保持、子分类数量、单块选择与换款面板；P66_ACCESS既有73项通行/食堂/管制门规则检查通过。

r04-full.png、r04-north.png、r04-selection.png、r04-southwest.png是实际R04编辑器截图；library-gallery.png展示完整29种瓦片，均为Godot原生绘制输出。
