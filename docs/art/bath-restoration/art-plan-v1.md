# 公共浴室美术设计方案

公共浴室按园区概念稿恢复成排淋浴位、中央通道和入口更衣区，采用与医务室同一套手绘表现和角色比例，另设浴室专用的瓷砖、管道与屋顶。房间概念图同时展示室内和屋顶关闭后的外观，随后制作可独立摆放的资源并接入地图。

## 当前场景与调整目标

当前 R04 浴室室内范围为 `[920,220,560,600]`，南侧入口为 `[1100,840,180,20]`。地图使用洗衣房地面 `laundry_floor_v46`，现有一组三联淋浴、一组更衣柜、一张长凳和一个布草篮。淋浴、更衣物件集中在左侧和中部，右侧留出较大空白；墙体仍采用普通园区的厚石压顶和深灰墙裙。

现有三联淋浴宽 210 世界单位，更衣柜宽 150、长凳宽 160、布草篮宽 48。角色保持当前 1.4 倍显示比例，以常用人物约 84 世界单位高作为物件的对照基准。新布局通过补齐淋浴位、集中更衣设施和校准通道宽度解决空旷感。

概念图先试排约 440×540 世界单位的紧凑室内，相比当前面积减少约 29%。这组尺寸是布局候选值；以淋浴位可站立、入口整身通行、柜门前可交互以及相邻建筑的衔接确定最终边界。相邻医务室、寝室和园区道路作为固定参照，避免缩小单个房间后出现零碎夹缝。

## 视觉方向

采用旧工厂公共澡堂的材质：米白墙面、灰蓝或浅青瓷砖、暗色金属水管与阀门、深灰蓝更衣柜、旧木长凳。延续园区柔和光照、手绘轮廓和适度磨损。水垢、锈迹与潮湿主要出现在管道接口、墙脚及排水处，大块表面保持清晰。

墙体改为薄直压顶，提供横墙、纵墙、四向转角和门洞收边。转角沿用医务室的连续拼接方式，瓷砖墙裙在横墙转角处对齐，减少突出立柱和重复金属条。浴室墙裙覆盖约墙面下半至三分之二，形成清楚的湿区建筑特征。

## 室内布局

北侧至中部安排成排淋浴位，首版候选为两列各三个单人位，中央保留连续通道。每个位置有独立喷头、阀门、浅色瓷砖地面和排水口，必要处加入矮隔板。单人位暂按约 80–90 世界单位宽试排，中央通道约 100–120 世界单位宽，最终以角色对照图和通行检查校准。

南侧入口集中更衣柜、长凳和布草篮，更衣柜贴墙，长凳靠入口侧或柜子前方侧边，入口到淋浴区保持直达路线。布草篮贴边摆放。地面用砖色和排水沟区分更衣区与淋浴区，避免用大面积深色水渍覆盖房间。

淋浴位的地面允许人物站入；管道、隔板、更衣柜和长凳分别标定实际实体范围。门洞按可见门框和门扇检查角色整身，不用透明图片的外接矩形扩大阻挡。更衣柜保留现有搜刮入口，交互点放在通道一侧。

## 美术资源清单

| 部分 | 制作要求 | 现有资源处理 |
| --- | --- | --- |
| 墙体 | 米白墙面与灰蓝瓷砖墙裙，直压顶及四向转角 | 复用拼装机制，制作浴室材质 |
| 地面 | 更衣区防滑砖、淋浴区湿砖及局部排水沟 | 替换现用洗衣房地面 |
| 淋浴 | 单人模块、成排组合、与布局匹配的不同朝向 | 保留旧组三联作为比例参考，重做主体 |
| 隔板 | 低矮瓷砖隔板、端头和接缝 | 新增独立模块 |
| 更衣柜 | 灰蓝柜门、通风孔、柜号及小范围锈迹 | 现有柜子轮廓可复用，校准材质与高度 |
| 长凳与布草 | 木长凳，毛巾、拖鞋和布草篮 | 优先复用现有长凳、篮子与布料资源 |
| 墙面设施 | 高位磨砂窗、公共浴室标牌、简易壁灯 | 窗框和灯具结构可复用，调整浴室外观 |
| 管道细节 | 喷头、阀门、墙管与排水口 | 关键细节独立，减少重复装饰 |
| 屋顶 | 浅灰蓝防水屋面、小排气管或通风帽，连续收边 | 独立浴室屋顶与配件，同批制作和接入 |

淋浴主体与瓷砖底面、装饰物与可站立地面分别交付，便于处理人物遮挡和碰撞。主体透明 PNG 保留真实透明像素；地面和屋面使用不透明材质。保存原图、提示词、来源与登记信息，尺寸和朝向由清单定义，避免直接拉伸整幅概念图。

## 制作与接入顺序

1. 制作房间概念图，展示两列淋浴、入口更衣区和人物比例；另配屋顶关闭视角。并排核对当前边界与紧凑布局后确定尺寸。
2. 制作浴室墙面、干湿地砖、淋浴主体和隔板，先核对它们与人物的尺度、光照及朝向。
3. 补齐更衣柜外观、窗牌灯、管道细节及屋顶资源，将布草和长凳摆放到更衣区。
4. 保存最新地图快照，登记浴室专用素材，在地图编辑器中加入中文名称与分类。基于最新保存的浴室摆放进行替换，保留其他房间的调整。
5. 同步更新地面范围、墙体拼装、实体碰撞、房间可见范围、屋顶配置和交互位置。边界缩小时，将释放出的地面与园区铺地连续衔接。
6. 原生游戏窗口核对室内、室外屋顶和编辑器三种画面，验证移动、搜刮、拖回、遮挡与保存重载。

## 验收条件

室内能看出成排淋浴和集中更衣区，角色与喷头、隔板、柜子及长凳的比例一致。喷头朝向与淋浴位置对应，人物能进入淋浴位，更衣柜前有交互站位。入口、通道和转角不出现透明区域阻挡，人物头部与身体沿相同深度排序。

四个墙角、瓷砖接缝、门洞铺地和缩小后释放出的地面连续。离开浴室后显示专用灰蓝屋顶与排风配件，返回室内时屋顶及配件一起隐藏。墙面与屋顶均在正常游戏显示尺寸核对清晰度，静态建筑不随每帧重复构建。

编辑器中的素材可放置、移动、复制、擦除和撤销，保存重载后外观、碰撞与屋顶样式一致。现有更衣柜搜刮保留；洗澡、换衣和卫生数值等玩法另行设计。
