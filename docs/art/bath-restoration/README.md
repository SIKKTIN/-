## 素材与接入

采用内置 `image_gen` 工具生成 8 张原始 PNG：瓷砖墙面、单人淋浴隔墙、四门更衣柜、公共浴室标牌、干区地砖、湿区小地砖、防水屋面和百叶排风帽。原图未经像素后处理，透明图保留真实 alpha；原图 SHA256、来源和完整提示词分别见 [registration.json](registration.json)、[generated-assets.json](generated-assets.json)。

游戏资源登记于 `art/architecture/bath_v1/manifest.json`，共 35 个定义。墙体沿用医务室的四向斜接转角结构，换成浴室自己的米白墙面、灰蓝瓷砖和细金属收边；门口保留两侧门框，移除旧灰色横梁。高位磨砂窗、壁灯、地漏、木凳与布草篮复用项目现有素材。

每个淋浴位分别放置主体、湿区地面和地漏；右列镜像喷头朝向。淋浴位的可站立地面没有实体碰撞，隔墙只在实际背板地面处阻挡。更衣柜保留布草搜刮，可以拿取物品并拖回。屋顶采用单幅灰蓝防水屋面、两个排风帽和后部排水口，进入房间时整体隐藏，离开后整体显示。

`tools/register_bath_restoration.py` 可基于最新地图重新登记浴室。它保存本次输入、输出快照并在写入前检查地图 SHA256，避免覆盖期间发生的其他调整；初次施工前地图保留在 `baseline/r04.json`。回归中的保留检查使用登记时的输入/输出快照，允许其他房间之后继续编辑。

## 验证

原生窗口中的浴室专项 **125 项全部通过**：六个淋浴位可达和可站立、隔墙实体、中央通道、实际移动进出、整身门框检测、柜子搜刮与拖回、室内人物显示、屋顶出入切换、静态绘制保留、编辑器素材与屋顶样式、地图数据校验及 QA 不写入地图。

相关回归中，编辑器、静态渲染、物品整理、头身遮挡、建筑接缝和医务室屋顶/门口均通过。寝室历史整身门洞测试有 1 项未通过：旧起点 x650 与新寝室洗漱台实体重叠，另外 28 项通过；本次没有修改寝室家具。详细结果见 [regression/results.json](regression/results.json)。
