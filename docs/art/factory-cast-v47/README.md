# 新人物素材库 v47

按已审评的形象概念制作并接入 8 个外观：年轻工人、壮实工人、年长工人、女工、搬运工、巡逻看守、车间监工、后勤人员。每个外观包含 1 张站立姿势与 8 帧行走，共 72 个姿势；游戏按脚底锚点绘制，并支持左右镜像。

## 使用

地图编辑器选择伙伴、巡逻看守、门岗或商人标记，在右侧「人物形象」中选择外观，保存地图即可保留选择。外观不会改变该人物原有的技能、日程和交互角色。

玩家及商人默认沿用原有形象；现有同伴从四种工人形象中选择不同外观，巡逻看守和监工使用对应形象。搬运工、后勤人员也已作为可选外观接入。本次没有增加人物数量或新行为。

外观保存于地图顶层 `character_appearances`：伙伴使用 `actor:<index>`，巡逻看守使用 `guard`，门岗使用 `gate:<id>`，商人使用 `merchant:<id>`。编辑器的「默认形象」移除对应覆盖值，恢复上述默认规则。

## 素材来源

生成方式：内置 `image_gen.imagegen`。原始图片保存在 `art/characters/factory_cast_v47/`，保留生成 PNG 原字节和透明背景；未对像素进行重绘或后期处理。`register.py` 仅复制原图、读取透明区域并登记裁切区域与锚点，运行时按登记信息取帧。

- `approved-concept.png`：审评通过的概念参考。
- `prompts/`：8 次实际生成提示词。
- `registration.json`：原图路径、SHA256、姿势区域及注册信息。
- `../../../art/characters/factory_cast_v47/manifest.json`：游戏运行时素材清单。
