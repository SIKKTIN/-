# 墙体风格修正样段

用户批评V34压顶和墙脚的砖缝过密，批准先做横墙、T接口、纵墙样段。本目录只做样段，尚未替换R04地图，也未向制作人发送消息。

样段复用批准的V33原PNG，字节不变，不生成新的画风。改动为原生UV切分与独立的保留原画shader：横墙取连续190px宽截面，对齐40世界单位整格块；每块不再覆盖边缘颜色或额外画黑缝。右横墙由三个相邻截面与逆序镜像构成连续周期，压顶、抹灰和墙脚保持各自原有砖缝位置，砖缝可以跨格子。T取三个连续120px原图截面，各占20单位；T末端source y500衔接纵墙y500，纵墙末端y670衔接完整端面y670。统一整格外边界，内部砖石不强行按20单位切开。

sample-clean.png为Godot原生绘制的干净样段实图；comparison.png上排为V34，下排为修正样段，两排以相同视图倍率显示；sample-detail.png和sample-selected.png来自实际编辑器。没有对截图做后期图像处理。sample-map.json为独立审阅文件，编辑器保存不会覆盖R04。

build-sample.py仅生成UV配置，不修改图片。sample-preview.gd加载临时素材定义并使用正式WorldVolume绘制；所有拼块仍在墙图层独立选取、移动、复制，完整矩形占整格。样段通过后再设计门框与四角、确认自动选择相邻截面的规则，最后迁移外围。

当前限制：横墙变体暂由样段显式排列，尚未接入日常素材库的自动选片；现阶段证明美术效果和独立拼块可以同时成立，不表示全地图已经替换。
