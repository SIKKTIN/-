# R04 · 分区地面、自然外围与概念图墙线

这轮仅围绕三项请求改动：区域地面材质、外围自然地表、墙体规划。已接入 `data/rooms/r04.json`，原生编辑器和游戏使用同一份地面与建筑数据。

## 地面材质

使用内置 imagegen 生成六种独立材质，按区域铺设。生活区与食堂使用浅暖灰旧地砖，车间使用冷灰大板混凝土，仓库和设备间使用深灰水泥，装卸场与公共通道使用浅灰粗骨料地面，洗衣房使用浅绿小砖，外围使用土、砂砾和稀疏草地。已移除上一版仅给同一地板加透明颜色的做法。

- [原始材质图](../../../art/environment/factory_v45/floor_atlas.png)
- [六种材质提示词](floor-prompt.txt)

## 自然外围

另生成四种透明、不规则地表组合，使用原图软透明边缘、自由尺寸、旋转、镜像和错位组合成 36 处自然地表。草地、泥土、碎石与灌木采用自由形状，架构的 20 单位规则不约束这些地表。编辑器吸附网格仅显示在铺装区域，草土地面不再被网格线切分。

## 墙体规划

依据 [已批准的概念图](../factory-expansion-v43/approved-concept.png) 的墙线节点重排，按每参考像素约 2.9 世界单位转到 20 单位建筑网格。

- 西侧三间寝室和三间禁闭室连接为连续建筑，开口朝东侧生活通道。
- 加工车间、活动走廊、食堂、洗衣房及设备间采用相邻墙线，移除旧版食堂内部不属于概念图的厨房隔墙。
- 西南外围沿禁闭室底部转折，再向南连接整段南侧围墙，恢复参考图的折线边界。
- 正门放在北侧门岗，生活区从门岗通道西侧接入。
- 仓库按概念图的比例与位置重排，东侧设置两处装卸场开口，南墙封闭；移除旧版额外的南门与堆货位置。
- 仓库南侧保留土草庭院，庭院南墙与装卸场南墙形成后勤通道的转折。设备间侧门、物流出口与后勤出口沿此规划注册。

完整墙线记录见 [wall-plan.json](wall-plan.json)，全部 660 个建筑组件保持 20 单位网格。随墙线移动了区域内物件与日常位置，给仓库右侧保留真实的 80 单位通行宽度；将邻近南墙的桌子和晾衣架移开，避免被墙面遮住。

配套调整正门的横向交接班通行，给双车间门和双检修门共享原有门禁规则；物流 16:00–17:00 时段及后勤内侧开门条件保留。
