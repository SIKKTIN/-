## 墙体差异对照

`E:/Project/Godot/这次怎么逃/art/concepts/prison-roof-v21/wall-studies-v21.png`

1. 禁闭室：深色厚砌墙、封死屋顶、实心门。
2. 食堂：浅色高墙、整齐压顶、较深石质勒脚。
3. 普通寝室：低石墙、较粗块缝、可剖切看到内部。
4. 走廊：薄矮边墙、简单倒角、较少纹理。

四种只改变构造厚度、高度及材质轻重，共用灰绿/暖浅色系、深墨描边、柔和受光与手绘笔触，不做四套互不相干的风格。对照图中的人物用于视觉比例参考，不是新增角色或生产尺寸。封屋顶可能改变实际遮挡与信息显示，用户认可后另行制定门边交互、屋内状态提示与地图碰撞，当前概念不实现这些逻辑。
