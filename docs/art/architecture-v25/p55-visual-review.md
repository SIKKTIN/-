# A25 实际运行视觉核对

本轮修正目标是用户圈出的北横墙与纵墙连接，不接受仅宽度/功能通过后宣称概念还原。原失败图见 rejected-connection-user.png，目标见 connection-concept-target.png。

## 最终视觉判断

亲眼核对完整运行图、真实2倍相机近景及右外角/厨房右接点后，L形连接的主要问题已经修正：普通浅色压顶从横向连续转为纵向，窄暗侧面沿内侧延伸，横墙立面位于纵臂内侧；原独立正面外柱已通过绘制裁切让位，纵顶不再从柱脚起头。横压顶和灰基脚的高度对齐。右侧镜像的暗侧位于西内侧，24单位外墙与20单位内隔墙均匹配原物理宽度。

新素材按完整原图坐标分12块采样。游戏运行纹理预先裁切时减去region起点一次；镜像使用正尺寸几何并反射UV，避免负目标矩形造成脱节。这两项程序接入错误已在运行截图发现并修正；隔离原图正确与接口测试通过都不能代替游戏视觉核对。

材质仍有小差异：转角短段的石缝较密、描边略重；模块下沿接后续纵顶处颜色稍暖。它们不影响本轮连续连接、侧面与墙脚关系，也不作为已完全逐像素复制概念图的结论。食堂两侧高度统一的既有要求保留；用户此次目标用于连接形状与空间关系，不再恢复早期左低右高。

## 透明边缘

原横墙、门柱与门洞PNG保持。安全边缘shader保留真实透明门洞、抗锯齿和正常黑描边，只衰减低alpha杂点、提升实体核心。alpha8/17孤立分量由旧输出1.809/27.233下降至0.006/6.166；alpha251~253实体仍输出255。实际同相机old/safe对照中，没有旧散点被明显放大的毛边。制作人实测14世界单位AA带亮像素增加764、差值约73.635，是降低暗边噪声的辅助证据，不等同自动证明每个黑点消失。
