# A25 L形连接返修

用户最新否定的是连接结构：北横墙的完整正面外柱画到地脚，纵顶条只能从其脚下开始，压顶并未连续拐弯。此项在功能/尺寸测试通过后仍未达美术验收。当前不接受旧P55截图。

新模块 `cafeteria_corner_l_v25` 为内置imagegen生成并原样复制的透明PNG，916×1717。外左角按 `corner-interface.json` 的十二块Atlas源区配准，合成80×150世界尺寸。横墙门框及其余段保留原图，只有外80单位绘制裁切让位给转角。纵臂24单位=20单位浅顶+4单位内侧暗面，正面墙仅位于其右侧；不再有正面外立柱垫在顶条上方。源PNG不修改，十二块配准不产生新烘焙图片。

普通横压顶共线起点由北翼region普通cap源y196与region y172差24源像素派生：
北翼render121.5 / source375 = 0.324；
普通cap起点 = baseline1261.5 -121.5 +24×0.324 =1147.776。
转角front底相对113.724，对齐1261.5；纵顶接续起点1147.776+150=1297.776。右外角可镜像；20单位内隔墙按24基准派生。最终消费实际值以制作人数据与运行图为准。

`corner-prompts.json`记录初稿和针对比例的单项编辑提示词，`corner-source-review.json`记录source-copy及hash、配准。全部A24交付文件hash仍未变。v25入口目前三个asset，v05增加对应第三项图标；隔离Godot资源加载3/3通过。此前新版edge shader已实际Forward+编译绘制成功；新增转角的实际场景视觉验收仍进行中。

验收必须亲眼检查：
- 左L角的压顶一笔连续，纵顶不从柱脚冒出；
- 横墙正面在纵顶内侧终止，内暗侧沿拐弯不断；
- 右外角和厨房20单位隔墙接点没有同类脱节；
- 转角与原横墙接缝高度一致，无重叠旧柱、透明裂口或漂浮边；
- 窄暗side与后续纵顶相接，场景整体对照概念图。
