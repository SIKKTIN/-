# 这次怎么逃 · Godot 原型 v0.2

启动：在 Godot 按 F5，或双击本目录 `start-playtest.cmd`。项目 `E:\Project\Godot\这次怎么逃`；Godot 4.7.2。

## 新操作

- 左键点人物或卡片，或1/2/3选人。
- 右键地面下达移动命令。人物自动寻路，不用按住鼠标；换人后此前的命令继续，可以分别安排多人行动。
- E启停选中人的聊天/撬锁；开始技能会停下此人的移动。给操作中的人下达新移动命令会中断其技能，保留撬锁进度。
- S停止选中人的移动和操作；其他人的命令与技能继续。
- 大力气右键箱子另一侧的地面，身体接触后自动推箱；墙和伙伴仍会挡住箱子，推不动时需换站位/目标。
- 右键绿色出口符号或出口线进行撤离。三人全部逃脱完成；R重开并重抽，顶部切换房间/声音。

## 本轮修正

狱警巡逻重算曾将已走过的格点重新放到路径前方，R01走完一圈后在两点往返。修正共用路径推进，并避免反复重置正常巡逻路径。箱子占据某个巡逻点时狱警改走可达的下一点，继续遵守碰撞与视线规则。

三友军和狱警向左时水平翻转身体，向右恢复；脚底原点、编号、技能提示和真实警戒方向独立。停止后保留朝向。

无路可走、目标在实体内或路线后来被占据时，界面显示原因。保留三技能、警戒距离110、120度前向、即时追击、抓回保留进度、随机允许无解等规则。

狱警能走完巡逻后，旧版一些固定时机路线会遇到它。本版验证了替代路径；这属于危险时机恢复正常，不能依靠旧版卡住的狱警通关。
