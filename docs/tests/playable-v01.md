# 这次怎么逃 · Godot 原型 v0.1

2026-10-04，Godot 4.7.2，纸片风资产 art-v01-20261004-a8676014f0d4。

## 启动

在已打开的 Godot 项目按 F5，或双击本目录的 `start-playtest.cmd`。启动器使用本机 E:\Godot\4.7 的 Godot，不需要编辑器导出模板。主场景为 `scenes/main.tscn`。

顶部选择 R01「双通路」或 R02「门边掩护」。每次开局三人各随机一项技能，允许重复，暂不保证可解。

## 操作和目标

拖动单个伙伴移动，包括点击头部。点击右侧人物卡或按1/2/3选人；E启停此人的聊天/撬锁。大力气接触箱子后拖动自动施力。操作中的人可以留在原地，换其他人行动。

三人全部到达东侧出口完成本局。被抓仅该人物回起点：门的进度、箱子位置、已逃脱伙伴及本局技能都保留。R或右上按钮重抽并恢复房间；顶部声音开关可静音。

聊天让当前狱警驻足并转向聊天者，其他伙伴仍会被看到。固定警戒距离110、前方120度，发现即追击；墙、门和箱子既挡路也挡视线。移动操作人会打断其持续技能，撬锁进度保留。

## 当前版本边界

- R01完整验证撬锁路线与力量路线；R02验证聊天掩护撬锁与下方推箱路线。
- 54项初始化/种子复现通过，仅4个有序配置具有完整通关证据；全聊天两项规则无解，另外48项尚未证明。
- 1280×720与960×540原生窗口、逐人物操作/切换、脚底锚点、真实位移动画、声音起止与双关规则有技术检查。
- 人耳对音色/音量的偏好、玩家能否读懂并自主安排分工、乐趣尚待真人试玩。自动通关不回答这些问题。
- 本轮只保留聊天、撬锁、力量三技能；还未增加新机关、角色技能或更多关卡。
