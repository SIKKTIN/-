# 人物素材目录

正式人物 PNG 全部保存在本项目，运行时没有依赖 Codex 图片目录或系统临时目录。

## 可选形象

统一入口：`data/presentation/character_libraries.json`。地图编辑器选中人物后，可在「人物形象」中切换，保存后的覆盖值位于地图 `character_appearances`。

- `factory_cast_v47/`：年轻工人、壮实工人、年长工人、女工、搬运工、巡逻看守、车间监工、后勤人员。
- `factory_occupations_v48/`：食堂师傅、医务人员、维修师傅、仓库管理员、货车司机、清洁人员。

共 14 套，每套 1 张站立姿势和 8 帧行走，共 126 个姿势。每个目录的 `manifest.json` 登记裁切区域、脚底锚点、统一比例、动画速率和源图哈希。原图 PNG 保留生成时的字节及透明背景。站立与行走的纹理在运行时按需准备并共享，先取帧再生成 mipmap，避免相邻姿势串色。

## 现有兼容素材

根目录 v01、v03 和 `walk_v09/`：历史展示配置及默认玩家的兼容素材。
`merchant/`、`thug_v17/`、`dog/`：现有商人、备用看守和警犬素材。
这些文件仍有配置或备用展示用途，不凭“旧版本”命名删除。

## 概念、原图来源与审评记录

- `docs/art/factory-cast-v47/`：第一批人物概念、完整提示词、原图路径及注册记录。
- `docs/art/factory-occupations-v48/`：六种职业概念、完整提示词、原图路径及注册记录。
- `docs/art/factory-antagonists-v49/`：办公室主管、监控值班员、看守和监工的新反派概念。本组仍为概念稿，尚未注册为新的行走形象。

`docs/.gdignore` 将审评图、历史记录和预览文件排除出 Godot 导入；文件继续保存在项目中，供审评和后续制作。正式游戏所需的交付/物品清单位于 `data/presentation/`。

资源优化和验证记录：`docs/dev/p109/`。
