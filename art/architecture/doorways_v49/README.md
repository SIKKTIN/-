# 平齐门框素材 v49

使用内置 imagegen 生成两张透明 RGBA PNG，原图保留；manifest 的 region 排除透明留白和 alpha < 8 的零散像素，不改写原图。

- `free.png`：自由通行。两端深灰钢端框和铜铆钉，中间平齐、磨损的灰钢门槛；无门扇、锁扣或控制灯。
- `grille.png`：开关铁门。同族端框和磨损材质，中间栅栏及小锁扣。关闭显示完整门体，开启由渲染器将门体收至一端。

资源按水平门绘制，侧门旋转90度；保留端部比例，再伸展中段，适配20×40侧门和160×24横门。所有端框都在既有门洞范围内。寝室1 `dorm-0` 配置为 `kind: open`，无需交互、始终通行；其他寝室和管制门仍消费既有状态。独立上锁钢门继续使用v48素材。

最终生成提示和参考路径见 `generation.json`。运行及编辑器均经 `doorway_view.gd` 使用该manifest，纹理/切片预载、可见性切换不重建门框。
