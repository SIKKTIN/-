# 医务室建筑素材

依据 `docs/art/clinic-restoration/architecture-concept-v1.png` 制作。米白墙面、灰绿釉面瓷砖墙裙、蓝灰金属收边与护角，配磨砂双扇窗、搪瓷医疗标牌、壁灯和打开的双扇玻璃门。

内置 imagegen 交付六张独立 RGBA PNG。保留原文件与真实透明像素；素材来源、目标路径与完整提示词见 `docs/art/clinic-restoration/architecture-assets.json`，哈希见同目录 `architecture-registration.json`。manifest 的 region 和 assembly_patches 仅记录游戏中的取样与拼装，不改变原始图片。

共 30 个登记项，包括横墙连续取样变体、长短纵墙、四向 L 转角、长短门楣及五个独立设施。墙顶与墙面共用一张源图，纵向压顶从同一压顶纹理转向拼装。四个转角采用 45° 三角接缝，使内外蓝灰收边连续转向；南侧纵墙延伸到横墙压顶的交点，去掉原先突兀的全高护角叠层。原始金属护角素材仍保留为可独立放置的附件。屋顶关闭时的墙边也使用同样的拼装数据。编辑器可以放置墙片和门窗。

专用建筑仅替换医务室的绘图与附属设施。520×500 房间边界、所有实体墙碰撞、家具尺寸与摆放均保留。双开门目前固定打开，按可见门扇的范围检测角色整身；中央留出约 112 世界单位净空。门洞铺地读取医务室自己的地砖清单，并遵循地面区域的绘制顺序。

执行 `python tools/register_clinic_architecture.py` 可重新登记。初始地图存于 `architecture-map-before.json`，每次输入存于 `architecture-last-input-map.json`。登记前后核对磁盘哈希，保留医务室外的数据。重新运行旧的家具登记脚本也会保留这套专用建筑样式。

门扇碰撞现在由原始 PNG 的可见 alpha 轮廓生成细分矩形，排除透明边缘和斜门下端的空白区域；头部、躯干与鞋采用分段整身宽度，避免一块最大外接矩形延伸到空白处。碰撞数据在素材登记阶段预生成，运行时沿用空间索引，不逐帧读取图片。`--definitions-only` 只更新素材定义，不改当前保存地图。
